## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | B | PC とルータはどちらも MDI(1,2 で送信)。同種の機器はクロス。 |
| 2 | B | 速度は信号から検出できる。デュプレックスは検出できず、10/100 Mbps では半二重になる。 |
| 3 | D | 全二重側は相手の送信中にも送るため、壊れたフレームを受け取り CRC と runts が増える。late collisions は半二重側。 |
| 4 | C | 半二重で late collision が多いのはデュプレックス不一致の典型。up/up なので、ケーブル抜けや対向の shutdown は該当しない。 |
| 5 | D | administratively down は管理者による shutdown。未接続は down/down、BPDU ガードは err-disabled。 |
| 6 | C | LR はシングルモードで 10 km。SR は数百 m、10GBASE-T は 100 m、SX は 1 Gbps。 |
| 7 | D | 受信光レベルの低下は、経路上の損失(汚れ、曲げ、距離)が原因。光ファイバにデュプレックス不一致の典型症状は当てはまらない。 |
| 8 | C | giants は最大長超過。64 バイト未満は runts、FCS の不一致は CRC。 |
| 9 | D | Type 1 はベアメタル。ホスト OS のアプリケーションとして動くのは Type 2。 |
| 10 | C | コンテナはカーネルを共有するため軽量で起動が速い。必要なのはコンテナエンジン。 |
| 11 | A | vNIC は仮想スイッチに接続し、物理 NIC 経由で外部へ出る。複数 VLAN を運ぶのでトランク。 |
| 12 | A | /20 は第3オクテットを 16 刻みで区切る。45 は 32〜47 の範囲。 |
| 13 | B | /26 は 62 台。/27 は 30 台で不足。 |
| 14 | C | /26 のブロックは 64。130 は 128〜191。190 は同じ範囲のホストアドレス。127 は別サブネットのブロードキャスト。 |
| 15 | A | /27 のブロックは 32。64〜95 の範囲で、95 がブロードキャスト、最後のホストは 94。 |
| 16 | B | クラス B のプライベートは 172.16.0.0〜172.31.255.255。 |
| 17 | D | ゲートウェイは自分と同じサブネットになければ到達できない。 |
| 18 | C | 100 台 → .0/25(0〜127)、50 台 → .128/26(128〜191)、20 台 → .192/27(192〜223)。 |
| 19 | A | 同一ルータの複数インターフェースに重なるサブネットは設定できない。 |
| 20 | D | `::` は1か所だけ。同じ長さの 0 の連続が2つあるときは左側に使う。00a0 の末尾の 0 は省略できない。 |
| 21 | A | 中央に fffe を挿入し、先頭バイト 00 の 7 ビット目を反転して 02。0250:56ff:feab:cdef。 |
| 22 | D | `ipv6 unicast-routing` がないとルータは RA を送らない。 |
| 23 | C | NS がアドレス解決の要求、NA が応答。 |
| 24 | C | M=1 はステートフル DHCPv6。アドレスは SLAAC で、DNS などの情報だけ DHCPv6 で取得するのは O=1。 |
| 25 | A | SLAAC のインターフェース ID は 64 ビット。LAN は /64 にする。 |
| 26 | B | 2.4 GHz で重ならないのは 1、6、11。 |
| 27 | B | SAE。TKIP は WPA の暗号化、EAP-TLS はエンタープライズの認証方式。 |
| 28 | C | SNR = RSSI − ノイズ = −67 − (−92) = 25 dB。 |
| 29 | A | 電子レンジは 2.4 GHz を使う。DFS は 5 GHz。 |
| 30 | A | `ipconfig /all` は DHCP とリース、DNS、MAC アドレスまで表示する。 |
| 31 | B | 認証は成功している。169.254.x.x は DHCP の取得失敗。 |
| 32 | B | リレーはクライアント側のインターフェースに設定し、サーバのアドレスを指定する。 |
| 33 | C | Windows は `ipconfig /all` と `route print`、macOS は `ifconfig` と `netstat -rn`。`scutil --dns` は macOS の DNS 設定。 |
| 34 | B | Windows は `ipconfig /all`、Linux は `resolvectl status` や `/etc/resolv.conf`。 |
| 35 | D | 近くから順に確かめる。ゲートウェイまでは届いているので、ゲートウェイより先を疑う。名前で失敗するなら DNS。 |
| 36 | B | DORA。Discover と Request はブロードキャスト。サーバは UDP 67、クライアントは UDP 68。 |
| 37 | C | `ip dhcp excluded-address` はプールの中ではなく、グローバルコンフィグで設定する。 |
| 38 | `ip address dhcp` | 受け取ったデフォルトゲートウェイは AD 254 のデフォルトルートとして入る。確認は `show dhcp lease`。 |
| 39 | D | リース期間の短縮、範囲の拡大、不要なバインディングの消去で対処する。リレーがなければ別サブネットのクライアントは誰も取得できない。 |
| 40 | B | リレーは Discover をユニキャストに変え、giaddr に受信インターフェースのアドレスを入れて転送する。サーバは giaddr あてに返信するので、戻りの経路が要る。 |
| 41 | `67` | クライアントは UDP 68。ACL が UDP 67 / 68 を遮断すると取得できない。 |
