### 3.4 FHRP

**問29** R1 と R2 は HSRP グループ 1 を構成する。R1 のプライオリティは 110、R2 は 100 である。R1 が障害から復旧した後も、R2 が Active、R1 が Standby のままである。原因はどれか。

- A. R1 のプライオリティが低い
- B. R1 でプリエンプトが有効になっていない
- C. HSRP は IP アドレスが小さいほうを Active にする
- D. グループ番号が一致していない

**問30** 次の出力から読み取れることとして正しいものはどれか。

```
GigabitEthernet0/0 - Group 10
  State is Active
  Virtual IP address is 192.168.1.1
  Active virtual MAC address is 0000.0c07.ac0a
  Hello time 3 sec, hold time 10 sec
  Preemption enabled
  Active router is local
  Standby router is 192.168.1.3, priority 100
  Priority 90 (configured 110)
```

- A. HSRP バージョン 2 で動作している
- B. トラッキング対象の障害でプライオリティが 110 から 90 に下がっている。それでも Active なのは、Standby ルータ側でプリエンプトが有効でないなどの理由が考えられる
- C. このルータは Standby である
- D. ホストのデフォルトゲートウェイは 192.168.1.3 にする

## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | C | 一致する経路は /0、/16、/24、/25。最長の /25(128〜255)を使う。AD は関係しない。 |
| 2 | A | 100 は /25(128〜255)の範囲外。一致する最長は /24。 |
| 3 | B | 10.10.30.5 は /24 のどちらにも一致しない。/16 に一致。 |
| 4 | D | [AD/メトリック]。OSPF のメトリックはコスト。 |
| 5 | B | 同じプレフィックスなら AD が最小の情報源。EIGRP 90 < OSPF 110 < RIP 120。 |
| 6 | D | 直接接続 0、スタティック 1、EIGRP 90、OSPF 110、RIP 120。 |
| 7 | D | プレフィックス長が違う経路は両方テーブルに載る。転送は最長一致。 |
| 8 | A | L はローカルルート。自分のインターフェースのアドレス(/32)。C が接続ネットワーク。 |
| 9 | D | `ip route <ネットワーク> <サブネットマスク> <ネクストホップ>`。ワイルドカードやプレフィックス表記は使わない。 |
| 10 | C | フローティングスタティックは AD を主経路(OSPF 110)より大きくする。 |
| 11 | A | ネクストホップへの経路がないと、スタティックルートはテーブルに載らない。 |
| 12 | C | R1 発の ping の送信元は 10.0.12.1 で、R2 は直接接続で返せる。PC 発は送信元が 192.168.1.10 で、R2 に戻りの経路がない。 |
| 13 | A | 同じ AD・メトリックなので両方載る。予備に `… 198.51.100.1 5` のように大きい AD を付ける。 |
| 14 | D | ホストルートのマスクは 255.255.255.255。 |
| 15 | A | リンクローカルをネクストホップにするときは出力インターフェースも指定する。 |
| 16 | A | `ipv6 unicast-routing` がないと IPv6 パケットを転送しない。 |
| 17 | B | `router-id` がなければ、ループバックの中で最大のアドレス。物理より優先。 |
| 18 | C | MTU 不一致は DBD 交換で止まる(ExStart / Exchange)。A、B はそもそもネイバーにならない。 |
| 19 | D | プロセス ID はルータ内だけで意味を持つ。 |
| 20 | C | /30 のワイルドカードは 0.0.0.3。 |
| 21 | D | プライオリティ最大の R4 が DR。残りで最大は R1 と R2(同値)なのでルータ ID が大きい R1 が BDR。R3 は 0 で不参加。 |
| 22 | C | R3 も DROTHER。DROTHER 同士は 2-Way が正常。 |
| 23 | B | 1(GE)+ 1(FE)+ 10(10 Mbps)= 12。既定では 100 Mbps 以上はすべて 1。 |
| 24 | A | Hello / Dead は一致が必要。hello-interval を変えると Dead は自動で4倍になる。 |
| 25 | B | パッシブは Hello を止めるだけ。サブネットは広告される。 |
| 26 | B | ポイントツーポイントでは DR / BDR を選出しない。 |
| 27 | C | OSPFv3 はリンクローカルを送信元に使い、ff02::5 / ff02::6 に送る。ルータ ID は 32 ビット。有効化はインターフェース単位。 |
| 28 | A | ルータ ID は 32 ビットで、IPv4 アドレスがないと自動で決まらない。 |
| 29 | B | HSRP のプリエンプトは既定で無効。R1 に `standby 1 preempt` が要る。 |
| 30 | B | 0000.0c07.ac0a は v1 のグループ 10。`Priority 90 (configured 110)` は減算されている状態。ゲートウェイは仮想 IP の 192.168.1.1。 |
