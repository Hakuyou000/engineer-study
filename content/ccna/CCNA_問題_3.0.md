## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | C | 10.10.10.200 に一致する経路は、/0、/16、/24、/25(10.10.10.128〜255)の4つです。ルーターは最もプレフィックスの長い経路(最長一致)を使うので、/25 のネクストホップ 10.0.14.4 に転送します。AD の大小はここでは関係ありません。 |
| 2 | A | 10.10.10.100 は /25(128〜255)の範囲に入りません。一致する経路のうち最も長いのは 10.10.10.0/24 なので、そのネクストホップ 10.0.12.2 に転送します。 |
| 3 | B | 10.10.30.5 は、10.10.10.0/24 にも 10.10.20.0/24 にも入りません。一致する経路のうち最も長いのは 10.10.0.0/16 なので、ネクストホップ 10.0.13.3 に転送します。 |
| 4 | D | 角かっこの中は [アドミニストレーティブディスタンス/メトリック] です。110 は OSPF の AD、30 は OSPF のメトリック(コスト)で、あて先までの距離の目安です。 |
| 5 | B | 同じあて先への経路を複数のプロトコルから学習したときは、AD が最も小さい情報源の経路だけがテーブルに載ります。EIGRP(内部)は 90、OSPF は 110、RIP は 120 なので、EIGRP の経路が使われます。 |
| 6 | D | 主な AD は、直接接続 0、スタティック 1、EIGRP(内部)90、OSPF 110、RIP 120 です。小さいほど信頼度が高く、優先されます。 |
| 7 | D | プレフィックスの長さが違う経路は、別のあて先として両方ともテーブルに載ります。パケットを転送するときは最長一致で選ぶので、172.16.5.9 には /24 の RIP の経路が使われます。AD は、まったく同じあて先の経路同士を比べるときにだけ使います。 |
| 8 | A | L はローカルルートで、ルーター自身のインターフェース(G0/0)に設定したアドレスを /32 で表したものです。G0/0 につながるネットワーク全体は、C(直接接続)の行として別に表示されます。 |
| 9 | D | IPv4 のスタティックルートは `ip route ネットワーク サブネットマスク ネクストホップ` の順に書きます。ワイルドカードマスク(0.0.0.255)や /24 のような表記は使えず、ネットワークとネクストホップを逆にしても正しく動きません。 |
| 10 | C | スタティックルートに、OSPF の AD(110)より大きい AD(130 など)を付けると、OSPF の経路がある間はテーブルに載らず、OSPF の経路が消えたときだけ使われます(フローティングスタティックルート)。AD を付けないと 1 になり、OSPF より優先されてしまいます。 |
| 11 | A | スタティックルートは、ネクストホップに到達できる経路がないとテーブルに載りません。10.1.15.5 につながるインターフェースが down になっていないかを確認します。設定はすぐに有効になり、保存は関係ありません。ルーターでは `ip routing` は既定で有効です。 |
| 12 | C | R1 から普通に ping すると、送信元は出ていくインターフェースの 10.0.12.1 で、R2 は直接つながっているので返信できます。PC からの ping の送信元は 192.168.1.10 で、R2 にそのネットワークへの経路がないため、返信できずに失敗します。R2 にも 192.168.1.0/24 への経路が必要です。 |
| 13 | A | 2つのスタティックルートは、AD もメトリックも同じなので、両方がテーブルに載って負荷分散されます。予備の経路に `ip route 0.0.0.0 0.0.0.0 198.51.100.1 5` のように 1 より大きい AD を付けると、メインの経路が消えたときだけ予備が使われます。 |
| 14 | D | 1台のホストだけをあて先にする経路(ホストルート)は、サブネットマスクを 255.255.255.255(/32)にします。0.0.0.0 のマスクはデフォルトルートの書き方で、`host` というキーワードはありません。 |
| 15 | A | リンクローカルアドレスは、どのリンクでも同じアドレスが使われることがあるため、ネクストホップにするときは出力インターフェースも一緒に指定します。書き方は `ipv6 route プレフィックス/長さ インターフェース ネクストホップ` です。IPv6 では `ip route` ではなく `ipv6 route` を使います。 |
| 16 | A | Cisco のルーターは、`ipv6 unicast-routing` を設定しないと IPv6 のパケットを転送しません。ルーター自身の通信(ping)はできるので、気づきにくい点に注意します。`ip routing` は IPv4 の設定です。 |
| 17 | B | `router-id` を設定していない場合、OSPF のルーター ID は、up しているループバックインターフェースの中で最も大きい IPv4 アドレスになります。ループバックは物理インターフェースより優先されるので、192.168.1.1 ではなく 10.10.10.10 です。 |
