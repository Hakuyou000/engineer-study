## 解答・解説

### 問1 `CCNA-4.0-001`

**正解**: D

**テキスト**: 2. パスワードの種類

タイプ 9(scrypt)のハッシュが最も強く、推測されにくい保護です。タイプ 5 は MD5 のハッシュで、タイプ 9 より弱くなります。タイプ 7 は簡単に元に戻せる暗号化で、`enable password` は設定によっては平文のまま保存されます。

### 問2 `CCNA-4.0-002`

**正解**: C

**テキスト**: 4. SSH の設定

SSH の通信を暗号化するには RSA の鍵が必要で、`crypto key generate rsa` で作ります。鍵の名前にホスト名とドメイン名が使われるので、その2つは先に設定しておく必要があります。`ip ssh version 2` は鍵を作った後に使うバージョンの指定です。

### 問3 `CCNA-4.0-003`

**正解**: D

**テキスト**: 3. ローカルのユーザー名による認証

`login local` で、ルーターのローカルのユーザーデータベースを使って認証します。`transport input ssh` で、VTY への接続を SSH だけに限定します。`transport output` は VTY から外へ接続するときの設定、`no login` は認証をしない危険な設定です。

### 問4 `CCNA-4.0-004`

**正解**: A

**テキスト**: 5. AAA

TACACS+ は TCP の 49 番を使い、パケットの本体全体を暗号化し、認証・認可・アカウンティング(AAA)を別々に扱えます。UDP 1812 を使う、パスワードだけを暗号化する、認証と認可をまとめて扱う、802.1X でよく使われる、という特徴は RADIUS のものです。

### 問5 `CCNA-4.0-005`

**正解**: C

**テキスト**: 6. AAA クライアントの設定

設定とログインの流れを順に追います。
① `aaa new-model`:AAA を有効にします。
② `aaa authentication login default group tacacs+ local`:ログインの認証は、まず TACACS+ サーバー、次にローカルのデータベースの順で使います。
③ 次の方式に進むのは、前の方式が応答しなかった(エラーになった)ときだけです。
④ 今回は TACACS+ サーバーが稼働していて、「認証失敗」と応答しています。
⑤ 応答があったので結果が確定し、ローカルのデータベースは使われません。ログインは拒否されます。

ローカルで再度認証されると考えるのは、「失敗したら次へ進む」と覚えた誤りです。この設定には enable の認証や、認証なしの方式(none)は含まれていません。

### 問6 `CCNA-4.0-006`

**正解**: D

**テキスト**: 6. AAA クライアントの設定

設定とログインの流れを順に追います。
① `aaa authentication login default group tacacs+ local`:ログインの認証は、TACACS+ サーバー、ローカルのデータベースの順で使います。
② TACACS+ サーバーがダウンしていて応答しないので、エラーになります。

### 問19 `CCNA-4.0-019`

**正解**: A

**テキスト**: 2. レコードの種類

MX レコードを読みます。
① 書式は `ドメイン IN MX 優先度 メールサーバー` です。
② mail-b の優先度は 20、mail-a の優先度は 10 です。
③ MX の優先度は、数値が小さいほど優先されます。
④ そのため、まず 10 の mail-a に配送を試み、届かないときに 20 の mail-b を使います。

数値が大きいほど優先されると考えるのは、STP や HSRP のプライオリティ(HSRP は大きいほど優先)と混同した誤りです。ファイルに書かれた順番は関係ありません。優先度が同じなら、ランダムに選ばれて負荷が分散されます。

### 問20 `CCNA-4.0-020`

**正解**: D

**テキスト**: 4. 症状から原因を絞り込む

### 問27 `CCNA-4.0-027`

**正解**: B

**テキスト**: 2. ワイルドカードマスク

サブネットマスクからワイルドカードマスクを求めます。

### 問28 `CCNA-4.0-028`

**正解**: C

**テキスト**: 4. 拡張 ACL

拡張 ACL の書式に当てはめます。
① 書式:`access-list 番号 permit プロトコル 送信元 ワイルドカード あて先 [eq ポート]` です。ポートはそのポートを使うアドレスの後ろに書きます。

④ 送信元:192.168.1.0 0.0.0.255(ワイルドカードマスク)です。
⑤ あて先とポート:`host 10.1.1.80 eq 443` です。
⑥ そのため `access-list 110 permit tcp 192.168.1.0 0.0.0.255 host 10.1.1.80 eq 443` です。

### 問38 `CCNA-4.0-038`
