## 解答・解説

### 問1 `LinuC3SS-6.0-001`

**正解**: B

**テキスト**: 2. tcpdump

`-w` は、取り込んだパケットを、そのままの形でファイルに書きます。このファイルを Wireshark で開けます。

- A. `-r` は、保存したファイルを読むオプションです。取り込みはしません。
- C. 画面に出す文字の表示をリダイレクトしても、テキストが保存されるだけです。pcap の形式ではないので、Wireshark で開けません。
- D. `-c` は、取り込む個数の上限です。ファイル名を渡すオプションではありません。

### 問2 `LinuC3SS-6.0-002`

**正解**: C

**テキスト**: 5. Suricata

ミラーポートのコピーを見ているだけの構成では、通信の経路の途中にいないので、通信を止められません。`drop` にしても、検知の記録が残るだけで、元の通信はサーバーに届きます。通信を止めるには、IPS として経路の途中(インライン)に置きます。

- A. 通信の経路の途中に置いたときの動きです。この構成では、止められません。
- B. 規則は有効のままです。検知の記録は残ります。
- D. `drop` は正しいアクションです。文法の誤りにはなりません。

### 問3 `LinuC3SS-6.0-003`

**正解**: `-w`

**テキスト**: 2. tcpdump

`-w ファイル名` で、パケットをファイルに保存します。保存したものは、`-r` で読み直したり、Wireshark で開いたりできます。

### 問4 `LinuC3SS-6.0-004`

**正解**: A

**テキスト**: 7. ModSecurity

`DetectionOnly` は、ルールで調べて記録するだけで、要求を止めません。導入の初期に、誤検知を確かめるために使います。推奨の設定ファイルも、この値で始まります。

- B. `On` は、ルールに合う要求を実際に拒否します。
- C. `Off` は、ルールの処理をしないので、記録も残りません。
- D. `RelevantOnly` は、`SecAuditEngine` に指定する値で、`SecRuleEngine` の値ではありません。

### 問5 `LinuC3SS-6.0-005`

**正解**: D

**テキスト**: 7. ModSecurity

誤検知が、1 つの検知のルールと 1 つのフォームに絞れています。そこで、その検知のルール ID を、そのフォームの URL と入力欄に限って例外にします(`ctl:ruleRemoveTargetById` など)。ほかの場所の防御は、そのまま残ります。点数の合計を判定する 949110 は、外しません。外すと、ほかの検知でも拒否できなくなります。

- A. WAF 全体を止めると、すべての機能の防御がなくなります。
- B. CRS と ModSecurity を外すのも、同じ理由で過剰です。
- C. ブラウザー側の検査は、WAF の拒否には関係がありません。送られた要求を、WAF が調べて拒否しています。

### 問6 `LinuC3SS-6.0-006`

**正解**: A、C

**テキスト**: 8. 攻撃の種類と、見つけ方、防ぎ方

SYN クッキーは、SYN を受けただけでは接続の情報をためない仕組みで、SYN フラッドへの対策になります。大規模な攻撃は、自分のサーバーだけでは受けきれないので、手前の CDN や ISP の防御サービスで吸収します。

- A. SYN クッキーを有効にすると、SYN だけを大量に送られても、サーバーの接続の枠がすぐには埋まりません。
- B. ModSecurity は HTTP の中身を見る WAF です。接続の最初の段階の SYN には、働きません。
- C. 手前で攻撃の通信を吸収すると、サーバーに届く量が減ります。
- D. Wireshark は、通信を取り込んで見る道具で、通信を止める機能はありません。

### 問7 `LinuC3SS-6.0-007`

**正解**: B

**テキスト**: 8. 攻撃の種類と、見つけ方、防ぎ方

1 台だけが、一定の間隔で、業務で使っていない同じ外部の宛先へ小さな通信を続けるのは、マルウェアが指令サーバー(C2)へ定期的に連絡する動き(ビーコン)によく見られる特徴です。

- A. DDoS は、外から大量の通信を受ける攻撃です。ここでは出ていく小さな通信が問題です。
- C. SQL インジェクションは、外から Web アプリへ送られる要求への攻撃です。出ていく定期的な通信の説明にはなりません。
- D. OS の更新の確認は、業務で使うリポジトリの宛先への通信です。ここでは、業務で使っていない宛先で、1 台だけに起きています。

### 問8 `LinuC3SS-6.0-008`

**正解**: `-T`

**テキスト**: 5. Suricata

`suricata -T -c /etc/suricata/suricata.yaml` のように指定すると、起動せずに、設定と規則を検査します。規則を更新したあとの確認に使います。

### 問9 `LinuC3SS-6.0-009`

**正解**: D

**テキスト**: 3. Wireshark

Wireshark の表示フィルターは、取り込んだあとに、プロトコルの項目で絞ります。`http.request.method == "POST"` で、HTTP の POST だけを表示します。

- A. `post` という書き方は、どちらのフィルターにもありません。
- B. tcpdump の取り込みフィルターの書き方で、SYN フラグのあるパケットを選びます。HTTP の POST ではありません。
- C. tcpdump の取り込みフィルターの書き方です。Wireshark の表示フィルターでは `ip.addr == 192.0.2.10` と書きます。
