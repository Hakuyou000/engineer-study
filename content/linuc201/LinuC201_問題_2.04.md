## 解答・解説

### 問1 `LinuC201-2.04-001`

**正解**: C

`git checkout タグ名` で、作業ディレクトリをそのタグの時点のソースにします。`git clone` した直後は開発中の最新なので、安定した版を使うときにタグへ切り替えます。

- A. `git clone` は、リポジトリを手元に写すコマンドで、引数は URL です。
- B. `git tag v2.1.0` は、今の位置に `v2.1.0` という新しいタグを付けます。
- D. `git tag -l` は、タグの一覧を表示するだけで、切り替えません。

### 問2 `LinuC201-2.04-002`

**正解**: D

GNU tar は、展開のときに圧縮の形式を自動で見分けるので、`tar -xf` で展開できます。`-x` は展開、`-f` はファイル名の指定です(xz を明示するなら `-xJf`)。

- A. `-z` は gzip の指定なので、xz のファイルには合いません。
- B. `-j` は bzip2 の指定なので、xz のファイルには合いません。
- C. `-t` は、中身の一覧を表示するだけで、展開しません。

### 問3 `LinuC201-2.04-003`

**正解**: C

`--dry-run` を付けると、実際にはファイルを変えずに、パッチが当たるかどうかだけを確かめます。

- A. `-R` は、すでに当てたパッチを取り消す(reverse)オプションです。
- B. そのまま実行すると、実際にパッチを当ててしまいます。
- D. `make -n` は、make が実行するコマンドを表示するだけで、patch の動作とは関係がありません。

### 問4 `LinuC201-2.04-004`

**正解**: B

`--prefix` は、`make install` でファイルを入れる場所の、土台のディレクトリを決めます。指定しなければ、多くのソフトウェアで `/usr/local` になります。

- A. 展開する場所は、`tar -C` や、展開するときのディレクトリで決まります。
- C. 実行ファイルの名前は、ソースの作りで決まります。
- D. 中間ファイル(`.o` など)は、`make` を実行したソースのディレクトリに置かれます。

### 問5 `LinuC201-2.04-005`

**正解**: A

`make install` は、Makefile の `install` の目標(ターゲット)で、ファイルを prefix の下にコピーします。prefix が `/usr/local` や `/opt` のときは、root の権限が要るので、`sudo make install` とします。

- B. `make clean` は、ビルドで作ったファイルを消します。
- C. `make -n` は、実行するコマンドを表示するだけです。
- D. `configure` に、`--install` というオプションはありません。

### 問6 `LinuC201-2.04-006`

**正解**: A、C

`./configure` は、コンパイラやライブラリがあるかを調べ、Makefile を作ります。`--prefix` を指定しなければ、autotools の `configure` では、多くの場合 `/usr/local` が入れる場所になります。

- B. `make install` で入れたものは、パッケージ管理に登録されません。消すときは、`make uninstall`(用意されていれば)か、手で消します。
- D. `make clean` は、ビルドで作ったファイルを消します。入れたファイルは消しません。

### 問7 `LinuC201-2.04-007`

**正解**: `bunzip2`、`bzip2 -d`、`bzip2 --decompress`

`bunzip2` は、`bzip2 -d` と同じです。gzip なら `gunzip`(`gzip -d`)、xz なら `unxz`(`xz -d`)、zip の形式なら `unzip` で展開します。

### 問8 `LinuC201-2.04-008`

**正解**: C

差分バックアップは、最後のフルバックアップとの違いをすべて含みます。水曜の差分には、月曜と火曜の分も入っているので、日曜のフルと水曜の差分の 2 つで足ります。

- A. フルだけでは、月曜から水曜までの変更が戻りません。
- B. 月曜と火曜の差分は、水曜の差分に含まれるので、要りません。
