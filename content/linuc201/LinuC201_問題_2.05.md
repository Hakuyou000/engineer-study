**問7** `LinuC201-2.05-007` ホストで、VM を管理するサービス libvirtd を、いますぐ起動し、ホストの起動のときにも自動で起動するようにしたい。正しいコマンドはどれか。

## 解答・解説

### 問1 `LinuC201-2.05-001`

**正解**: B

VirtualBox は、Windows や Linux などの OS の上のアプリとして動きます。このような方式をホスト型と呼びます。

- A. Xen は、ハードウェアの上で直接動くハイパーバイザー型です。
- C. VMware ESXi は、ハードウェアの上で直接動くハイパーバイザー型です。
- D. Microsoft Hyper-V は、有効にすると、OS 自身もハイパーバイザーの上で動く構成になります。ハイパーバイザー型として扱います。

### 問2 `LinuC201-2.05-002`

**正解**: A

Intel の CPU の仮想化支援機能(VT-x)は、`vmx` のフラグで表されます。

- B. `svm` は、AMD の CPU の仮想化支援機能(AMD-V)のフラグです。Intel の CPU には現れません。
- C. `lm` は、64 ビットで動かせること(long mode)を表すフラグです。
- D. `nx` は、データの領域で命令を実行させない機能(NX ビット)のフラグです。

### 問3 `LinuC201-2.05-003`

**正解**: `lscpu`

`lscpu` は、CPU の情報を読みやすい形で表示します。仮想化支援機能に対応していると、`Virtualization:` の行に `VT-x`(Intel)や `AMD-V` と表示されます。`/proc/cpuinfo` の `flags` の行で、`vmx` と `svm` を探しても確かめられます。

### 問4 `LinuC201-2.05-004`

**正解**: D

KVM は、`kvm` のモジュールと、CPU の種類ごとのモジュールで構成されます。AMD の CPU では `kvm_amd`、Intel の CPU では `kvm_intel` です(`kvm-amd` や `kvm-intel` と書かれることもあります)。

- A. `kvm_intel` は、Intel の CPU 用です。AMD の CPU では読み込めません。
- B. `vboxdrv` は、VirtualBox のカーネルモジュールで、KVM とは関係ありません。
- C. `xen_blkfront` は、Xen のゲストが使うディスクのドライバーです。

### 問5 `LinuC201-2.05-005`

**正解**: C

KVM は CPU を速く動かす役割で、QEMU が仮想のディスク、ネットワークカード、画面などの周りのハードウェアをまねます。ふつうは、VM 1 台につき QEMU のプロセスが 1 つ動きます。

- A. libvirtd は、VM を管理するサービスです。ハードウェアはまねません。
- B. bridge-utils は、ブリッジを作る道具(`brctl`)です。
- D. virt-manager は、VM を画面で作る、管理するための道具です。

### 問6 `LinuC201-2.05-006`

**正解**: B、D

CPU が仮想化支援機能に対応していること(`vmx` または `svm` のフラグがある)と、`kvm` のモジュールが読み込まれていることの 2 つで、KVM が使える状態だと分かります。

- A. `brctl show` は、ブリッジの一覧です。KVM が使えるかどうかとは関係ありません。
- C. `virsh net-list` は、libvirt の仮想のネットワークの一覧です。KVM が使えるかどうかとは関係ありません。

### 問7 `LinuC201-2.05-007`

**正解**: C

`enable --now` は、次回からの自動起動の設定と、いまの起動を一度に行います。

- A. `start` は、いま起動するだけです。ホストを再起動すると、起動しません。
- B. `enable` は、自動起動の設定だけです。いまは起動しません。
- D. `reload` は、動いているサービスに設定を読み直させるものです。止まっているサービスを起動するものではありません。

### 問8 `LinuC201-2.05-008`

**正解**: `brctl show`

`brctl` は bridge-utils パッケージのコマンドです。`brctl show` で、ブリッジの名前と、そこにつながっているデバイス(`eth0` や VM の `vnet0` など)が表示されます。新しい環境では、`ip link show type bridge` や `bridge link` でも調べられます。

### 問9 `LinuC201-2.05-009`

**正解**: B

準仮想化は、ゲスト OS が仮想環境だと分かった上で、ハイパーバイザーと直接やり取りします。ハードウェアをまねる手間が減って、速くなります。

- A. 完全仮想化は、ゲスト OS を変えずに動かす方式です。ハードウェアを全部まねるので、ゲスト OS は仮想環境だと気づかず、遅くなりやすいです。
- C. ホスト型は、ハイパーバイザーが動く場所(OS の上のアプリ)の分け方で、ゲスト OS とのやり取りの方式ではありません。
- D. コンテナは、ホストのカーネルを共有してプロセスを分ける仕組みで、仮想マシンの方式ではありません。

### 問10 `LinuC201-2.05-010`

**正解**: D

virtio は、KVM などで使う準仮想化のドライバーです。ディスクは virtio-blk、ネットワークカードは virtio-net です。Linux のゲストは、最初から使えます。

- A. e1000 は、Intel のネットワークカードをまねた仮想の部品です。どのゲストでも動きますが、virtio より遅いです。
- B. ide は、古い形のディスクをまねたものです。virtio より遅いです。
- C. vga は、画面の仮想の部品で、ディスクにもネットワークカードにも関係ありません。

### 問11 `LinuC201-2.05-011`

**正解**: B

`--memory` の単位は MiB です。4 GiB は 4096 MiB なので、`--memory 4096` と指定します。

- A. `--memory 4` は、4 MiB です。少なすぎて、OS が動きません。
- C. 4194304 は KiB の値です。`--memory` の単位は MiB なので、約 4 TiB の指定になります。
- D. `--ram` は古い名前のオプションで、`4gb` のような単位つきの書き方もできません。

### 問12 `LinuC201-2.05-012`

**正解**: C

`virsh destroy` は、VM の電源を強制的に切ります。VM の定義やディスクは消えません。名前は紛らわしいですが、VM を消すコマンドではありません。

- A. `virsh shutdown` は、ゲスト OS に終了を頼む方法です。ゲスト OS が応答しないと止まりません。
- B. `virsh undefine` は、VM の定義を消すコマンドです。起動中の VM を止めるものではありません。
- D. `virsh suspend` は、VM を一時停止します。メモリは残り、電源は切れません。

### 問13 `LinuC201-2.05-013`

**正解**: `virsh list --all`

`virsh list` は、動いている VM だけを表示します。`--all` を付けると、止まっている VM も表示します。`--inactive` を付けると、止まっている VM だけを表示します。

### 問14 `LinuC201-2.05-014`

**正解**: A、C

virtio は準仮想化のドライバーです。Linux のカーネルには最初から含まれているので、Linux のゲストでは、そのまま使えます。

- B. Windows には、virtio のドライバー(virtio-win)が入っていません。別に入れます。
- D. virtio は準仮想化の方式です。ハードウェアをそっくりまねる完全仮想化とは反対です。

### 問15 `LinuC201-2.05-015`

**正解**: A

`virt-install` は、`--name`、`--memory`、`--disk`、`--cdrom` などの引数だけで、VM を作ってインストールを始めます。画面のないサーバーでも使えます。

- B. `virt-manager` は、ウィンドウで操作する道具です。
- C. `virt-top` は、VM ごとの CPU やメモリを表示する道具で、VM は作れません。
- D. `virt-viewer` は、VM の画面を表示する道具で、VM は作れません。

### 問16 `LinuC201-2.05-016`

**正解**: `virsh dominfo vm1`

`virsh dominfo` は、VM(ドメイン)の状態、メモリ、仮想 CPU の数などを表示します。CPU の時間やディスクの数値まで見たいときは、`virsh domstats vm1` を使います。
