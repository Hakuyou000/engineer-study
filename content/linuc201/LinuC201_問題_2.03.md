## 解答・解説

### 問1 `LinuC201-2.03-001`

**正解**: A

`ip addr` は、インターフェースのアドレスを表示、設定します。`ifconfig` の代わりです。

- B. `ip route` は、ルーティングテーブルを表示、設定します。古い `route` に当たります。
- C. `ip neigh` は、ARP の表を扱います。古い `arp` に当たります。
- D. `ip rule` は、経路を選ぶ規則(ポリシールーティング)を扱います。アドレスの表示ではありません。

### 問2 `LinuC201-2.03-002`

**正解**: C

`ip route add default via ゲートウェイ` で、デフォルトルートを足します。ゲートウェイは `via` で指定します。

- A. `gw` は、古い `route` コマンドの書き方(`route add default gw ...`)です。`ip route` では使いません。
- B. `ip addr` はアドレスを扱うもので、経路は足せません。
- D. `ip link` は、インターフェースの有効・無効などを扱うもので、経路は足せません。

### 問3 `LinuC201-2.03-003`

**正解**: B、D

`ip neigh show` と `arp -n` は、どちらも ARP の表(IP アドレスと MAC アドレスの対応)を表示します。`arp` は古い net-tools のコマンドで、`ip neigh` が新しい書き方です。

- A. `ip route show` は、ルーティングテーブルを表示します。
- C. `ip addr show` は、インターフェースのアドレスを表示します。

### 問4 `LinuC201-2.03-004`

**正解**: D

`nmcli connection modify` は、設定ファイルを書き換えるだけです。`nmcli connection up` で、新しい設定を実際に反映します。

- A. `nmcli device status` は、デバイスの状態を表示するだけで、設定は反映されません。
- B. `nmcli connection show` は、接続の設定を表示するだけです。
- C. `nmcli connection delete` は、接続の設定を消します。反映ではありません。

### 問5 `LinuC201-2.03-005`

**正解**: B

`iw` は新しい道具で、`iw dev wlan0 scan` で周りのアクセスポイントを探します(root の権限が必要です)。

- A. `iwlist` は古い wireless-tools のコマンドです。問題は、新しい道具を求めています。
- C. `iwconfig` は古い wireless-tools のコマンドで、`scan` という使い方はありません。
- D. `rfkill` は、無線機能が止められていないかを見る道具で、`scan` はありません。

### 問6 `LinuC201-2.03-006`

**正解**: A

`NO-CARRIER` は、NIC がリンクを検出できていない状態です。ケーブルが抜けている、相手のスイッチが止まっているなどを疑います。切り分けの最初の段階(リンク)の問題です。

- B. デフォルトルートがなくても、リンクは上がります。`NO-CARRIER` にはなりません。
- C. DNS は、リンクが上がった後の、名前解決の問題です。
- D. ファイアウォールが止めるのは、リンクが上がった後の通信です。

### 問7 `LinuC201-2.03-007`

**正解**: C

Debian 12 の ifupdown は、`/etc/network/interfaces`(と `/etc/network/interfaces.d/`)から設定を読みます。

- A. Red Hat 系で使われる、ifcfg ファイルの置き場所です。
- B. Ubuntu の netplan の設定です。問題は netplan を使わないとしています。
- D. DNS サーバーを書くファイルで、IP アドレスの設定は書きません。

### 問8 `LinuC201-2.03-008`

**正解**: `ip link set eth0 up`、`ip link set dev eth0 up`

`ip link set` で、インターフェースの状態を変えます。`up` で有効、`down` で無効です。`dev` は省略できます。`ifconfig eth0 up` や `ifup eth0` でも有効にできますが、問題は `ip` コマンドを求めています。

### 問9 `LinuC201-2.03-009`

**正解**: `route add default gw 192.168.10.1`、`route add -net default gw 192.168.10.1`、`route add -net 0.0.0.0 netmask 0.0.0.0 gw 192.168.10.1`

古い `route` では、ゲートウェイを `gw` で指定します。`ip route` の `via` に当たります。`default` は `-net 0.0.0.0 netmask 0.0.0.0` と同じ意味です。

### 問10 `LinuC201-2.03-010`

**正解**: D

`ip route add あて先ネットワーク via ゲートウェイ` の形です。あて先に `10.20.0.0/16`、ゲートウェイに `192.168.10.254` を書きます。

- A. あて先とゲートウェイが逆になっています。
- B. `gw` は古い `route` の書き方です。`ip route` では `via` です。また、プレフィックス長(`/16`)がないと、あて先が 1 つのホストと見なされます。
- C. `ip addr` はアドレスを扱うもので、経路は足せません。

### 問11 `LinuC201-2.03-011`

**正解**: B

当てはまる経路が複数あるときは、プレフィックス長が最も長い(範囲が最も狭い)経路が優先されます(ロンゲストマッチ)。10.20.1.5 は `10.20.0.0/16` と `10.0.0.0/8` と `default` に当てはまり、このうち最も長いのは `/16` です。

- A. デフォルトルートは、ほかに当てはまる経路がないときだけ使います。
- C. `10.0.0.0/8` にも当てはまりますが、`/16` のほうが長いので、使われません。
- D. 192.168.10.0/24 は、10.20.1.5 を含みません。

### 問12 `LinuC201-2.03-012`

**正解**: C

`/etc/sysctl.conf` か `/etc/sysctl.d/*.conf` に書いた設定は、起動時に読み込まれます。書いた後に `sysctl --system` で、すぐに読み込めます。

- A. `sysctl -w` の変更は、今動いているカーネルにだけ効き、再起動で戻ります。
- B. `/proc/sys/` に書く方法も同じで、再起動で戻ります。
- D. `ip route` に、IP 転送を有効にする `forward` という使い方はありません。

### 問13 `LinuC201-2.03-013`

**正解**: `sysctl -p`、`sysctl --load`

`sysctl -p` は、ファイルを指定しなければ `/etc/sysctl.conf` を読み込みます。`sysctl --system` は、`/etc/sysctl.d/` などもすべて読み込むので、別のコマンドです。

### 問14 `LinuC201-2.03-014`

**正解**: A

`-i` で NIC、`-nn` でホスト名とポート名の変換をやめ、`-c 10` で 10 個で止め、`port 53` で条件を絞ります。

- B. `-w` はファイルに保存するオプションで、`-w 10` は「10 というファイルに保存する」の意味になります。
- C. `-r` は保存したファイルを読むオプションで、取り込みではありません。
- D. `-p` は、ポートの指定ではなく、promiscuous モードを使わないというオプションです。ポートの条件は `port 53` と書きます。

### 問15 `LinuC201-2.03-015`

**正解**: D

nmap の `filtered` は、ファイアウォールなどが探査のパケットを止めていて、開いているかどうか判断できない状態です。

- A. 待ち受けているときは `open` と表示されます。
- B. ホストには届くが待ち受けていない場合は、`closed` と表示されます。
- C. ホストが止まっているときは、ポートの結果は出ません。ホストが応答しないと表示されます。

### 問16 `LinuC201-2.03-016`

**正解**: B

`-t` は TCP、`-l` は待ち受け中、`-n` は番号のまま、`-p` はプロセスの表示です。古い `netstat -tlnp` も、同じ内容を表示します。

- A. 待ち受けと接続中のすべてを表示します。`-p` がないので、プロセスは出ません。
- C. `-s` は、接続の数の統計(集計)を表示します。
- D. `-u` は UDP です。問題は TCP を求めています。

### 問17 `LinuC201-2.03-017`

**正解**: A、D

`nc -zv` は、相手のポートに接続できるかだけを試します。`nmap -p 22` は、相手のポートが `open` か `closed` か `filtered` かを調べます。どちらも、このホストから相手に向けて、実際に接続を試します。

- B. `ss -tlnp` は、このホスト自身が待ち受けているポートを表示します。相手のホストは調べられません。
- C. `tcpdump` は、このホストの NIC を流れるパケットを見るだけで、接続を試しません。

### 問18 `LinuC201-2.03-018`

**正解**: A

eth0 にはパケットが届き、eth1 から出ていないので、ルーターが転送していません。標準では `net.ipv4.ip_forward` が 0 で、転送は無効です。1 にすると転送が始まります。

- B. NIC の故障なら、PC2 に届かないだけです。ルーターの eth1 には、エコー要求が出るはずです。
- C. ping で IP アドレスを直接指定しているので、DNS は関係ありません。
- D. `/etc/hosts` は名前を解決するためのファイルで、パケットの転送には使われません。

### 問19 `LinuC201-2.03-019`

**正解**: `nc -l 9000`、`nc -l -p 9000`、`nc -lp 9000`、`ncat -l 9000`、`ncat -l -p 9000`、`ncat -lp 9000`、`netcat -l 9000`

`-l` で待ち受けます(listen)。`nc` の版によって、ポートの前に `-p` が要るものと、要らないものがあります。

### 問20 `LinuC201-2.03-020`

- B. `/var/log/dmesg.log` という標準のファイルはありません。カーネルのメッセージは `dmesg` コマンドか、`journalctl -k` で見ます。

### 問21 `LinuC201-2.03-021`

`lspci` に出るのは、PCI のデバイスとして、ハードウェアは見つかっているという意味です。`ip link` に出ないのは、ドライバーが読み込まれず、インターフェースが作られていないためと疑います。`dmesg` に、ドライバーの読み込みに失敗したメッセージが出ていることがあります。

- C. デフォルトルートは、インターフェースがあって初めて設定できるものです。

### 問22 `LinuC201-2.03-022`
