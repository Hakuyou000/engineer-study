## 解答・解説

### 問1 `LinuC3PS-2.0-001`

**正解**: B

**テキスト**: 1. VM をネットワークにつなぐ 3 つの形

NAT は、VM から外へ出る通信の送信元を、ホストの IP アドレスに変換します。外から VM に向けて新しく始める通信は、どの VM に届けるかが決まらないので、そのままでは届きません。VM に入るには、ホストで DNAT(宛先の変換)のポート転送を設定するか、ブリッジにします。

- A. VM から外のインターネットに出られているので、外へ出られない形ではありません。ホストオンリーは、そもそも外へ出られません。
- C. MTU の大きさは、通信が届くかどうかとは関係がありません。SSH の通信は、小さなパケットでも始められます。
- D. `virbr0` は、VLAN のタグを付けていません。VLAN の問題なら、NAT の外に出る通信も通りません。

### 問2 `LinuC3PS-2.0-002`

**正解**: C

**テキスト**: 1. VM をネットワークにつなぐ 3 つの形

ブリッジは、物理 NIC をポートとして取り込み、VM の仮想 NIC と同じ L2 のネットワークにします。VM は LAN の IP アドレスを持ち、LAN の機器から直接通信できます。ホストの IP アドレスは、物理 NIC ではなく、ブリッジに付けます。

- A. NAT では、VM は 192.168.122.0/24 の別のネットワークになり、LAN から直接は届きません。
- B. ホストオンリーは、外のネットワークにつながりません。
- D. 送信元を変換する NAT の形です。VM に LAN の IP を付けても、物理のネットワークとは L2 でつながっていないので、LAN の機器から直接は届きません。

### 問3 `LinuC3PS-2.0-003`

**正解**: A

**テキスト**: 1. VM をネットワークにつなぐ 3 つの形

libvirt では、`<forward>` を書かないネットワークが、ホストオンリー(isolated)になります。VM 同士と、ホストとだけ通信できます。

- B. NAT です。VM から外へ出られます。
- C. 既存のブリッジを使う形で、外のネットワークとつながります。
- D. ホストが、ルーターとして外へ中継する形です。外へ出られます。

### 問4 `LinuC3PS-2.0-004`

**正解**: D

**テキスト**: 2. NIC bonding(NIC の冗長化と束ね)

active-backup は、1 本だけを使い、障害が起きたら別の NIC に切り替えます。スイッチ側の設定が要らないので、スイッチを分けた冗長化にも使えます。帯域は増えません。

- A. 802.3ad(LACP)は、スイッチ側で LACP を設定する必要があります。また、通常は 1 台のスイッチ(または MLAG などの対応)が前提です。
- B. balance-rr は、スイッチ側で静的な束ね(ポートチャネル)が要ります。
- C. balance-xor も、スイッチ側で静的な束ねが要ります。

### 問5 `LinuC3PS-2.0-005`
