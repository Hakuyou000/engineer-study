## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | C | ログイン時の個人用ファイルは `~/.bash_profile`、`~/.bash_login`、`~/.profile` の順に探し、最初に見つかった1つだけを読む。 |
| 2 | D | ssh、`su -`、`bash -l` はログインシェル。ログイン後に `bash` を起動すると非ログインシェルになる。 |
| 3 | A、C | `source` と `.` は今のシェルで実行する。`bash` や `./` は子シェルで実行し、終わると消える。 |
| 4 | D | 子プロセスに引き継がれるのは export した環境変数だけ。 |
| 5 | B | 代入では `=` の前後に空白を入れない。空白があると MYVAR をコマンド名として実行しようとする。 |
| 6 | C | シングルクォートの中では変数を展開しない。展開するのはダブルクォート。 |
| 7 | A | `$PATH:` を付けないと既存の値を上書きする。追加するなら `export PATH=$PATH:/opt/tools/bin`。 |
| 8 | C | `set` はシェル変数と関数まで表示する。`env` と `printenv` は環境変数だけ。 |
| 9 | B | `&&` は左のコマンドが成功(終了ステータス 0)したときだけ右を実行する。 |
| 10 | A | 先頭に `\` を付けると alias が展開されない。`unalias -a` はすべての alias を削除する。 |
| 11 | B | `$#` は `$0` を含まない引数の個数で 3。`$2` は2番目の引数で 7。 |
| 12 | C | shift で `$1` の a が捨てられ、左に1つずれる。`$1` は b、`$#` は 2。 |
| 13 | D | `$?` は終了ステータス。`$$` は今のシェルの PID、`$!` は直前のバックグラウンドプロセスの PID、`$#` は引数の個数。 |
| 14 | A | `[` は test コマンドなので、`[` と `]` の内側に空白が必要。 |
| 15 | B | 数値の比較は `-gt` などの英字の演算子を使う。`[ $n > 10 ]` の `>` はリダイレクトとして解釈される。 |
| 16 | C | case 文は `esac` で閉じる。if は `fi`、ループは `done`。 |
| 17 | B | `until` は条件が偽の間くり返す。`while` は真の間。 |
| 18 | C | 関数はコマンドと同じく名前だけで呼び出す。`greet()` は定義の書き出しになる。 |
| 19 | A | 関数内の変数は既定でグローバルなので count は 5 になる。`local` の tmp は関数の外では空。 |
| 20 | C | `-n` は文法チェックだけを行う。`-x` は展開後のコマンドを表示しながら実行、`-v` は読み込んだ行をそのまま表示する。 |
| 21 | A | シェルスクリプトは bash が中身を読むため、実行権に加えて読み取り権が要る。711 では他人が実行できない。スクリプトの SUID は無視される。 |
| 22 | D | KILL(9)と STOP は trap できない。 |
| 23 | B | `*` はシェルがファイル名に展開する。expr に `*` を渡すためにエスケープする。 |
| 24 | A | `${変数:-既定値}` は変数が空なら既定値を使う。 |
| 25 | C | select のプロンプトは PS3。PS1 は通常のプロンプト、PS2 は継続行のプロンプト。 |
| 26 | C | if はコマンドの終了ステータスで分岐する。`grep -q` は見つかれば 0、なければ 1 を返す。 |
| 27 | C | `/etc/bash.bashrc` は全ユーザー共通で、bash の起動のたびに読まれる。`/etc/profile` はログイン時に全ユーザー、`~/.bashrc` は自分用。 |
| 28 | `~/.bash_logout`、`.bash_logout`、`$HOME/.bash_logout` | ログイン時は `~/.bash_profile` 系、起動のたびは `~/.bashrc`、ログアウト時は `~/.bash_logout`。 |
| 29 | B | コマンド置換。バッククォートで囲んでも同じ。整数の計算は `$(( ))`、変数の参照は `${ }`。 |
| 30 | D | `/etc/` で始まる設定は全ユーザー用。名前に profile が付くものはログイン時に1回読まれる。 |
| 31 | `#!` | シバン。`#!/bin/bash` のように書く。実行するには実行権も要る。 |
| 32 | C | cron から実行すると PATH が最小限しかない。`~/.bashrc` は cron では読まれない。スクリプトの SUID は無視される。 |
