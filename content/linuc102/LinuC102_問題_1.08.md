## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | B | `/etc/passwd` の各行は「ユーザー名:パスワード:UID:GID:コメント:ホームディレクトリ:シェル」の順です。4番目の 1001 がプライマリグループの GID で、3番目の 1000 は UID です。 |
| 2 | C | `x` は、暗号化されたパスワードが `/etc/shadow` に保存されていることを表します。`/etc/passwd` は誰でも読めるため、パスワードの情報は root しか読めない `/etc/shadow` に分けて置かれています。 |
| 3 | C | `/etc/shadow` には暗号化されたパスワードが入っているので、root しか読めません。`/etc/passwd`、`/etc/group`、`/etc/hosts` は一般ユーザーも読めます。 |
| 4 | D | `-m` を付けると、ホームディレクトリを作り、`/etc/skel` の中身をコピーします。`-d` はホームディレクトリのパスを指定するだけで、作成はしません。`-s` はログインシェル、`-k` はひな形のディレクトリの指定です。 |
| 5 | D | `usermod -G` は、所属するセカンダリグループを指定したものに「置き換える」ため、`-G wheel` だけでは sales から外れてしまいます。`-a` を付けた `-aG` なら、今のグループに追加できます。`-g` はプライマリグループの変更で、`useradd` は新しいユーザーを作るコマンドです。 |
| 6 | A | `/etc/skel` に置いたファイル(`.bashrc` など)は、新しいユーザーのホームディレクトリを作るときにコピーされます。コピーは作成時の1回だけなので、後から中身を変えても、すでにいるユーザーには反映されません。 |
| 7 | A | `useradd -D` を実行すると、`/etc/default/useradd` に書かれた既定値(シェル、ホームディレクトリの場所、スケルトンディレクトリなど)が表示されます。 |
| 8 | D | `userdel -r` は、ユーザーと一緒にホームディレクトリとメールの保存場所(メールスプール)も削除します。`-r` を付けないと、ホームディレクトリは残ります。 |
| 9 | A、B | `passwd -l` と `usermod -L` は、どちらも `/etc/shadow` のパスワードの先頭に `!` を付けて、パスワードでログインできないようにします。`passwd -d` はパスワードを空にするだけでロックではなく、`usermod -U` はロックを解除するオプションです。 |
| 10 | B | どこかのユーザーがプライマリグループとして使っているグループは、削除できません。先にそのユーザーのプライマリグループを変えるか、ユーザーを削除します。セカンダリグループとして所属しているユーザーがいるだけなら削除できます。 |
| 11 | A | getent は `/etc/nsswitch.conf` の設定に従って情報を引くので、ローカルのファイルだけでなく、LDAP などで管理されるユーザーも表示できます。grep はローカルの `/etc/passwd` しか見ません。getent は一般ユーザーでも実行できます。 |
| 12 | C | `id -G` は、そのユーザーが所属するすべてのグループの GID を表示します。`id -u` は UID、`id -g` はプライマリグループの GID だけを表示します。 |
| 13 | D | crontab の時刻は「分 時 日 月 曜日」の順に書きます。0 分 9 時、日と月は毎日・毎月、曜日の 1-5 は月曜から金曜なので、平日の 9:00 に実行されます。 |
| 14 | A | `/` は間隔を表し、分の欄に `*/10` と書くと 10 分ごとになります。`10 * * * *` は毎時 10 分に1回、`* */10 * * *` は 10 時間ごとの毎分、`0 10 * * *` は毎日 10:00 です。 |
| 15 | B | 日(13)と曜日(5 = 金曜日)の両方を指定すると、どちらか一方に当てはまる日(OR)に実行されます。そのため、毎月 13 日と、毎週金曜日の 0:00 に実行されます。 |
| 16 | C | `crontab -r` は、確認なしで、自分の crontab に登録したジョブをすべて削除します。表示は `-l`、編集は `-e` です。削除した内容を復元する機能はないので、`-e` と打ち間違えないよう注意します。 |
| 17 | B | ジョブを実行するユーザーの欄があるのは、`/etc/crontab` と `/etc/cron.d/` の下のファイルです。`crontab -e` で編集する個人の crontab は、そのユーザーで実行されるので欄はありません。`/etc/cron.daily/` にはスクリプトそのものを置き、`/etc/anacrontab` の書式にもユーザー欄はありません。 |
| 18 | A | `/etc/cron.allow` があるときは、そこに書かれたユーザーだけが crontab を使えます。このとき `/etc/cron.deny` は見られません。そのため sato だけが使えます。 |
| 19 | C | anacron は、前回の実行から何日たったかで判断し、電源が切れていて実行できなかったジョブを、起動後に実行します。cron は決まった時刻にしか実行しないので、そのとき電源が切れていると実行されません。 |
| 20 | A | anacron で指定できる実行の間隔は、日単位(1日が最小)です。時間や分の単位は指定できないため、細かい時刻の指定が必要なら cron を使います。 |
| 21 | B | at で予約したジョブは、`atq`(`at -l` と同じ)で一覧を表示し、`atrm`(`at -d` と同じ)で取り消します。crontab のコマンドは cron 用で、`jobs` と `kill` はシェルのジョブやプロセスを扱うコマンドです。 |
| 22 | D | `batch` は、システムの負荷(ロードアベレージ)が下がったときにジョブを実行します。`nice` はプロセスの優先度を変えるコマンド、`at now` はすぐに実行、anacron は日単位で実行する仕組みです。 |
| 23 | B | 最も優先されるのは LC_ALL です。LC_ALL が設定されていなければ、LC_TIME などの個別の LC_* が使われ、それも設定されていない項目には LANG が使われます。 |
| 24 | C | LC_ALL が設定されていると、LANG や LC_TIME などの設定はすべて無視されます。そのため date の表示には、LC_ALL の C ロケールが使われます。 |
| 25 | B | l10n(localization)は、ソフトウェアを特定の言語や地域に合わせること(日本語への翻訳など)です。複数の言語や地域に対応できる作りにすることは i18n(internationalization)と呼びます。 |
| 26 | A | iconv では、`-f` に変換元の文字コード、`-t` に変換先の文字コードを指定します。変換の結果は画面(標準出力)に出るので、`>` でファイルに保存します。 |
| 27 | A | `locale -a` で、使えるロケールの一覧を表示します。`locale -m` は使える文字コードの一覧、`iconv -l` は iconv が対応する文字コードの一覧、`echo $LANG` は LANG の現在の値を表示します。 |
| 28 | B | UTF-8 は、Unicode の文字を 1〜4 バイトで表す可変長の符号化方式で、英数字は ASCII と同じ1バイトで表せます。世界中の文字に番号を割り当てた文字集合は Unicode そのもの、7 ビットの日本語の符号は ISO-2022-JP、Windows で使われてきた日本語の符号は Shift_JIS です。 |
| 29 | A | 新しいグループを作るのは `groupadd` で、`-g` で GID を指定します。`groupmod -g` は既存のグループの GID の変更、`-G` は groupadd にはないオプションで、`useradd` はユーザーを作るコマンドです。 |
| 30 | `groupmod -n marketing sales` | グループ名を変更するには `groupmod -n 新しい名前 古い名前` の順で書きます。GID を変更するときは `groupmod -g` を使います。 |
| 31 | `/etc/skel` | `/etc/skel` はスケルトンディレクトリと呼ばれ、ここに置いたファイルが新しいユーザーのホームディレクトリにコピーされます。後から変更しても、すでにいるユーザーのホームディレクトリには反映されません。 |
| 32 | B | `/etc/at.allow` がなく、`/etc/at.deny` があるときは、deny に書かれたユーザー以外は at を使えます。deny が空なので、全ユーザーが使えます。 |
| 33 | D | `crontab -e` で登録した内容は、Red Hat 系では `/var/spool/cron/` の下にユーザー名のファイルとして保存されます(Debian 系は `/var/spool/cron/crontabs/`)。このファイルは直接編集せず、必ず `crontab -e` で編集します。 |
| 34 | `atq`、`at -l` | at のジョブの一覧は `atq` または `at -l` で表示します。取り消すときは `atrm`(または `at -d`)にジョブの番号を指定します。 |
| 35 | C | ISO-8859 は 8 ビットの文字コードで、ASCII の英数字に西ヨーロッパなどの文字を加えたものです(代表は ISO-8859-1、通称 Latin-1)。7 ビットの英数字だけのものは ASCII、日本語の 7 ビットの符号は ISO-2022-JP、Unicode の可変長の符号化方式は UTF-8 です。 |
| 36 | `locale -a` | `locale -a` で、システムで使えるロケールの一覧を表示します。`locale` だけなら現在の設定、`locale -m` は使える文字コードの一覧を表示します。 |
