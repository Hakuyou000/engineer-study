## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | D | `-perm -4000` は指定したビットがすべて立っているもの。`-perm 4000` は完全一致なので、通常は何も見つからない。 |
| 2 | B | `/` はどれか1つ、`-` はすべて、記号なしは完全一致。 |
| 3 | C | `-M` は有効期限の最長日数。`-m` は最短日数、`-E` はアカウントの失効日、`-W` は警告日数。 |
| 4 | A、B | 最終変更日を 0 にするか、passwd で期限切れにすると、次回ログイン時に変更を求められる。`passwd -l` はロック、`chage -l` は表示。 |
| 5 | B | `-E` はアカウントそのものの失効日。過ぎるとパスワードが有効でもログインできない。 |
| 6 | C | nmap は外からポートスキャンする。ss、lsof、fuser は自ホストの状態を調べる。 |
| 7 | A | fuser はファイルやマウントポイントを使っているプロセスを特定する。`-k` で終了もできる。 |
| 8 | B | w はログイン中のユーザー、実行中のコマンド、負荷を表示する。last は履歴。 |
| 9 | D | ソフトリミットが適用される値で、ハードリミットまで上げられる。ハードリミットは一般ユーザーには上げられない。 |
| 10 | B | ulimit はそのシェルの中だけで有効。恒久的な設定は `/etc/security/limits.conf`。 |
| 11 | C | sudo は自分のパスワードを入力する。su は切り替え先のパスワード。 |
| 12 | A | visudo は文法を確認してから保存し、同時編集も防ぐ。 |
| 13 | B | `%` はグループを表す。 |
| 14 | A | ハイフンなしの su は元の環境変数やカレントディレクトリを引き継ぐ。1コマンドだけなら `su -c`。 |
| 15 | D | `/etc/profile` で TMOUT を readonly にして export すると、全ユーザーに適用され解除できない。 |
| 16 | C | `/etc/nologin` はファイル。`/sbin/nologin` はシェルで、特定アカウントをログイン不可にする。 |
| 17 | C | stop は今止めるだけ、disable は自動起動を無効にするだけ。`--now` で両方を行う。 |
| 18 | A | SysVinit の自動起動は chkconfig で設定する。`--list` は一覧の表示。 |
| 19 | B | `disable = yes` で無効になる。`disable = no` は有効。 |
| 20 | C | INPUT は自ホストあて、OUTPUT は自ホストから出るもの、FORWARD は転送されるもの。 |
| 21 | D | DROP は黙って破棄する。REJECT は拒否したことを通知する。 |
| 22 | B | `--permanent` を付けると恒久的な設定に書く。今すぐ反映するには `--reload` も行う。 |
| 23 | A | 暗号化は相手の公開鍵で行い、相手の秘密鍵で復号する。署名は自分の秘密鍵。 |
| 24 | D | `.pub` の公開鍵をサーバーの `authorized_keys` に登録する。秘密鍵は手元から動かさない。 |
| 25 | C | known_hosts はホスト認証に使う。ログインを許可する公開鍵を登録するのは、サーバー側の authorized_keys。 |
| 26 | D | ed25519 は鍵長 256 ビットで固定。dsa は非推奨。 |
| 27 | B | 秘密鍵は所有者だけが読み書きできる 600。緩いと SSH が使用を拒否する。 |
| 28 | A | PermitRootLogin で root の直接ログインを制御する。PasswordAuthentication はパスワード認証の可否。 |
| 29 | A | `-L` はローカル転送。接続先は SSH サーバー(gateway)から見たアドレス。gateway 側のポートを転送するのは `-R`、SOCKS プロキシは `-D`。 |
| 30 | D | `--detach-sign`(`-b`)は .sig ファイルを作る。`--clearsign` は本文を読める形のまま署名を付ける。 |
| 31 | C | IaaS では OS から上が利用者の責任。基盤と施設は事業者が負う。 |
| 32 | A | 揮発性ストレージは停止や削除で中身が消える。消えて困るデータは永続ストレージに置く。 |
| 33 | B | 多要素認証は異なる要素の組み合わせ。パスワード(知識)と端末(所持)。パスワードと秘密の質問はどちらも知識なので、多段階認証だが多要素認証ではない。 |
| 34 | D | ファイアウォールはクラウド側とサーバー側の二重。つながらないときは両方を確認する。 |
