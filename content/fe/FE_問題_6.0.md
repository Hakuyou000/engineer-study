## 解答・解説

### 問1 `FE-6.0-001`

**正解**: C

**テキスト**: 1. 脅威の種類

人の心理や行動の隙を突いて、パスワードなどの情報を聞き出す手口を、ソーシャルエンジニアリングといいます。電話で管理者を装う、肩越しに画面をのぞく(ショルダーハッキング)、ごみ箱をあさる(スキャビンジング)なども同じ仲間です。技術的な弱点を突く攻撃ではないので、技術だけでは防げず、社員への教育や確認の手順が対策になります。

脅威にはほかに、ネットワークや機器への侵入、通信の盗聴、他人へのなりすまし、データの改ざん、アクセス権の誤設定による情報漏えいがあります。侵入された機器は、別の攻撃の踏み台にされることもあります。

- A. ブルートフォース攻撃は、パスワードを総当たりで試す攻撃です。人に聞き出す手口ではありません。
- B. バッファオーバーフローは、プログラムの領域を超えてデータを書き込む攻撃です。
- D. SQL インジェクションは、入力欄に SQL 文を紛れ込ませる攻撃です。

### 問2 `FE-6.0-002`

**正解**: B

**テキスト**: 2. マルウェア・不正プログラム

ボットは、感染した端末を外部から遠隔操作できるようにする不正プログラムです。操られた端末の集まりをボットネットといい、DDoS 攻撃、迷惑メールの送信、ほかの機器への攻撃の踏み台に使われます。

- A. キーロガーは、キーボードの入力を記録して盗む不正プログラムです。
- C. ランサムウェアは、ファイルを暗号化して、元に戻すための身代金を要求します。
- D. マクロウイルスは、文書ファイルのマクロ機能を使って感染を広げます。

### 問3 `FE-6.0-003`

**正解**: D

**テキスト**: 2. マルウェア・不正プログラム

ファイルレスマルウェアは、PowerShell や WMI など、OS に入っている正規のツールを悪用して、メモリ上で動きます。ディスクに実行ファイルが残りにくいので、ファイルを調べるだけのウイルス対策ソフトでは見つけにくくなります。端末の挙動を見る EDR のような対策が有効です。

- A. 実行ファイルを書き込むのは、従来型のマルウェアの特徴です。ファイルレスはこれを避けます。
- B. 金銭を要求するのは、ランサムウェアの特徴です。
- C. 画面を偽装して入力させるのは、フィッシングの手口です。

### 問4 `FE-6.0-004`

**正解**: A

**テキスト**: 2. マルウェア・不正プログラム

ルートキットは、侵入後に、攻撃者のプロセス、ファイル、通信の痕跡を隠すための道具です。管理者が異常に気づきにくくなります。侵入口を残して再侵入できるようにするものはバックドアといいます。

- B. スパイウェアは、利用者の情報を、本人に気づかれないように外部へ送るプログラムです。
- C. ランサムウェアは、ファイルを暗号化して金銭を要求します。
- D. マクロウイルスは、文書のマクロ機能を使って感染します。

### 問5 `FE-6.0-005`

**正解**: C

**テキスト**: 2. マルウェア・不正プログラム

有用なソフトウェアに見せかけて入り込み、裏で不正な動作をするものを、トロイの木馬といいます。自分から感染を広げる性質は持たず、利用者が自分で実行してしまうことで入り込みます。

- A. ワームは、ネットワークを通じて、自分自身で複製して広がります。利用者の実行を必要としません。
- B. スパイウェアは、情報を外部へ送ることが目的です。操作を受け付けるのが目的のものはバックドアやボットです。
- D. マクロウイルスは、文書のマクロ機能を悪用します。

### 問6 `FE-6.0-006`
