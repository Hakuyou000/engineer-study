### 問2 `FE-5.0-002`

**正解**: D

ライフサイクルプロセスでは、開発や運用の対象になるシステムを「対象システム(SoI)」、それを作ったり動かしたりするのを支えるシステムを「イネーブリングシステム」と呼びます。開発環境、テスト環境、ビルドの仕組みなどが例です。

### 問3 `FE-5.0-003`

**正解**: C

応答時間や処理量など、速さに関する要件は性能要件です。機能そのものではなく、品質に関するものなので、非機能要件の一つです。システム要件には、このほかに移行、運用、保守、セキュリティ、テストなどの要件があります。

### 問4 `FE-5.0-004`

**正解**: D

要件から、設計、実装、テストまでをたどれる(追跡できる)ように対応づけた表が、トレーサビリティマトリクスです。要件が設計やテストから漏れていないか、要件を変えたときにどこへ影響するかを確かめられます。

- B. 条件の組合せと、それに対する動作を整理する表です。

### 問15 `FE-5.0-015`

**正解**: A

①命令網羅: すべての命令を 1 回以上実行します。a > 0 かつ b > 0 の 1 ケースで、処理 P と Q の両方を実行できます。
②判定条件網羅: 各 if が真と偽の両方になるようにします。(a > 0, b > 0)と(a ≦ 0, b ≦ 0)の 2 ケースで、どちらの if も真と偽を経験します。
