## 解答・解説

### 問1 `LinuC101-1.05-001`

**正解**: B

**テキスト**: 5. カーネルのモジュール

`modprobe` は、依存関係を調べて、必要なモジュールもまとめて読み込みます。`modprobe -r` で外します。

- A. `insmod` は、ファイルを指定して 1 つだけ読み込み、依存関係は解決しません。
- C. `lsmod` は、読み込まれているモジュールの一覧を表示するだけです。
- D. `rmmod` はモジュールを外すコマンドです。

### 問2 `LinuC101-1.05-002`

**正解**: C

**テキスト**: 4. デバイスを調べる

`lspci` は PCI のデバイスを表示します。`-k` で、使っているカーネルのドライバーも表示します。

- A. `lsusb` は USB のデバイスです。
- B. `lsblk` は、ディスクとパーティション(ブロックデバイス)です。
- D. `lsmod` は、読み込まれているカーネルのモジュールです。

### 問3 `LinuC101-1.05-003`

**正解**: A

**テキスト**: 6. udev と D-Bus

udev は、カーネルからデバイスの追加と削除の知らせを受け、`/dev` のデバイスファイルを作ったり消したりします。名前の付け方などの規則は `/etc/udev/rules.d/` に書きます。

- B. D-Bus は、プログラム同士が情報をやり取りする仕組みです。
- C. sysfs は、デバイスの情報を `/sys` に見せる仮想のファイルシステムで、udev はこれを使って情報を得ます。
- D. GRUB はブートローダーです。

### 問4 `LinuC101-1.05-004`

**正解**: D

**テキスト**: 3. /proc と /sys

`/proc/cpuinfo` に、CPU ごとの型番、周波数、flags などが入っています。`/proc` はメモリの上の仮想のファイルシステムで、カーネルの情報を見せます。

- A. `/dev` はデバイスファイルの置き場所で、CPU の情報のファイルはありません。
- B. `/etc` は設定ファイルの置き場所です。
- C. `/sys` にも CPU の情報はありますが、`cpuinfo` というファイルはありません。

### 問5 `LinuC101-1.05-005`

**正解**: `lsmod`

**テキスト**: 5. カーネルのモジュール

`lsmod` は、`/proc/modules` の内容を見やすく表示します。モジュールの名前、大きさ、使っているほかのモジュールが分かります。

### 問6 `LinuC101-1.05-006`

**正解**: A

**テキスト**: 1. パーティションの方式

MBR では基本パーティションは 4 つまでです。それ以上が必要なら、1 つを拡張パーティションにして、その中に論理パーティション(番号は 5 から)を作ります。

- B. MBR で扱えるのは 2 TiB までです。大きいディスクには GPT を使います。
- C. UEFI では GPT と ESP を使うのが普通です。
- D. 128 個は GPT の既定の数です。

### 問7 `LinuC101-1.05-007`

**正解**: C

**テキスト**: 1. パーティションの方式

UEFI は、ESP の中のブートローダーのファイルを読んで起動します。ESP は FAT(VFAT)で作ります。

- A. スワップは、メモリが足りないときの書き出し先で、起動には使いません。
- B. `/boot` はカーネルを置く場所で、ESP とは別です。
- D. 拡張パーティションは MBR の仕組みです。

### 問8 `LinuC101-1.05-008`

**正解**: C

**テキスト**: 2. パーティションを作る道具

parted は、1 つずつの操作がすぐにディスクに反映されます。誤った操作を取り消せないので注意します。

- A. fdisk は、`w` で書き込むまでディスクを変えません。`q` で書き込まずに終われます。
- B. gdisk も、`w` で書き込むまで変えません。
- D. lsblk は一覧を表示するだけで、編集はできません。

### 問9 `LinuC101-1.05-009`

**正解**: A

**テキスト**: 4. LVM

まずパーティションやディスクを物理ボリューム(PV)にし、PV をまとめてボリュームグループ(VG)を作り、VG から論理ボリューム(LV)を切り出し、LV にファイルシステムを作ります。

- B. VG は PV から作るので、PV が先です。
- C. 逆の順です。
- D. ファイルシステムは、最後に LV の上に作ります。

### 問10 `LinuC101-1.05-010`

**正解**: D

**テキスト**: 4. LVM

`lvextend` で LV を広げます。`-r`(`--resizefs`)を付けると、上のファイルシステムも一緒に広げます。付けないときは、後から ext4 なら `resize2fs`、XFS なら `xfs_growfs` を実行します。

- A. `vgextend` は、VG に PV を足すコマンドです。
- B. `lvcreate` は新しい LV を作るコマンドです。
- C. `pvresize` は、PV の大きさを、下のパーティションに合わせて変えるコマンドです。

### 問11 `LinuC101-1.05-011`

**正解**: B

**テキスト**: 4. LVM

スナップショットは、作った時点の LV の状態を、変更された部分だけを記録して保つ LV です。作るのは一瞬で、元の LV を止めずに、一貫した状態でバックアップを取るのに使えます。

- A. すべてをコピーするのではなく、変わった部分だけを記録します。
- C. 同じ VG の空きを使い、別のディスクは要りません。
- D. 元の LV はそのまま読み書きできます。

### 問12 `LinuC101-1.05-012`

**正解**: C

**テキスト**: 1. ファイルシステムの種類

XFS は RHEL と AlmaLinux の既定で、広げることはできますが、縮めることはできません。

- A. ext4 は、マウントしていなければ縮められます。
- B. VFAT は Windows と共通の FAT で、USB メモリや ESP に使います。
- D. tmpfs はメモリの上のファイルシステムで、再起動で消えます。

### 問13 `LinuC101-1.05-013`

**正解**: A、B

**テキスト**: 2. 作る

`mkfs -t 種類` と `mkfs.種類` は同じです。`mkfs` は、`-t` に合う `mkfs.ext4` などを呼び出します。

- C. `mount` は作ったファイルシステムをつなぐコマンドで、作りません。
- D. `fsck.ext4` は、ファイルシステムを調べて直すコマンドです。

### 問14 `LinuC101-1.05-014`

**正解**: C

**テキスト**: 2. 作る

`mkswap` でスワップの領域として初期化し、`swapon` で使い始めます。起動のたびに使うなら `/etc/fstab` に書きます。

- A. スワップは `mkswap` で作り、`mount` ではなく `swapon` で使います。
- B. 初期化の前には使えません。
- D. `swapoff` は使うのをやめるコマンドです。

### 問15 `LinuC101-1.05-015`

**正解**: B

**テキスト**: 4. /etc/fstab

`/dev/sdX` の名前は、カーネルがディスクを見つけた順に付くので、ディスクを足したり外したりすると変わることがあります。ファイルシステムを作ったときに付く UUID は変わらないので、別のディスクを誤ってマウントすることを防げます。UUID は `blkid` や `lsblk -f` で調べます。

- A. 速さは変わりません。
- C. `/dev/sdb1` の名前でもマウントできます。
- D. fsck を行うかどうかは、6 番目の欄で決まります。

### 問16 `LinuC101-1.05-016`

**正解**: A

**テキスト**: 4. /etc/fstab

5 番目の欄は dump でバックアップするか(0 はしない)、6 番目の欄は起動のときに fsck で調べる順番です。ルートは 1、ほかは 2、調べないものは 0 にします。

- B. 6 番目の欄は回数ではなく順番です。
- C. マウントするかどうかは、4 番目の欄のオプション(`noauto` など)で決めます。
- D. 読み取りだけは `ro` のオプションで、時間の指定はありません。

### 問17 `LinuC101-1.05-017`

**正解**: D

**テキスト**: 3. マウント

マウントしたファイルシステムの中のファイルを開いているか、その中をカレントディレクトリにしているプロセスがあると、外せません。`lsof /mnt/data` や `fuser -m /mnt/data` で探し、終わらせてから外します。自分のシェルがその中にいるだけ、ということもよくあります。

- A. `df` は使用量を表示するだけです。
- B. `du` はディレクトリの使用量です。
- C. `blkid` はデバイスの UUID と種類を表示します。

### 問18 `LinuC101-1.05-018`

**正解**: A

**テキスト**: 5. 使用量と修復

小さいファイルが大量にあると、容量より先に inode を使い切ることがあります。`df -i` で inode の使用量を確かめます。

- B. `df -h` は容量の使用量で、問題文から空きがあることは分かっています。
- C. `free` はメモリの使用量で、ディスクとは関係ありません。
- D. `lsblk` はディスクとパーティションの一覧で、使用量は分かりません。

### 問19 `LinuC101-1.05-019`

**正解**: `mount -a`、`mount --all`

**テキスト**: 3. マウント

`mount -a` は、`/etc/fstab` のうち、`noauto` の付いていないものをまとめてマウントします。`/etc/fstab` を書き換えた後に、書き間違いがないかを確かめるのにも使います(誤りがあると、再起動したときに起動できなくなることがあります)。

### 問20 `LinuC101-1.05-020`

**正解**: `blkid`、`lsblk -f`

**テキスト**: 4. /etc/fstab

`blkid` は、ブロックデバイスごとに UUID、LABEL、ファイルシステムの種類(TYPE)を表示します。`lsblk -f` でも木の形で確かめられます。
