# 問題の網羅性調査

> この調査の集計スクリプトは、全試験を対象にした `npm run coverage`(`scripts/coverage/`)に置き換えた。今の数値は `npm run coverage` と [指標.md](指標.md) を見る。

調査日: 2026-11-18
対象: sre-drill の問題(LinuC 102 161問、CCNA 154問)
基準: LinuC レベル1 102試験 Version 10.0 の出題範囲(LPI-Japan 公式)、CCNA 200-301 v2.0 Exam Topics(Cisco 公式)

## 1. 結論

この章から6章までは調査時点の結果。同日に行った問題の追加と、その後の数値は7章にある。

| 試験 | 問題数 | 公式の用語・要素の出現率 | 主な不足 |
|---|---|---|---|
| LinuC 102 | 161 | 168 / 208(81%) | 1.10.4 クラウドセキュリティ、1.10.3 の鍵管理コマンド、1.07.2・1.07.3 の問題数。入力問題の形式がない |
| CCNA | 154 | 153 / 161(95%) | 1.7 DHCP(1問)、1.6・3.4・4.7・5.6(各2問)。VRRP、macOS / Linux のクライアント確認。シミュレーション形式がない |

- 全小項目に1問以上ある。空白の小項目はない
- LinuC は重要度と問題数の配分がずれている。1.10.1 と 1.11.1 が多く、1.10.4 と 1.07.2・1.07.3 が少ない
- CCNA は用語の出現率は高いが、1〜2問しかない小項目が5つある
- 調査中に、他の問題を前提にした問題が7問見つかった。修正済み(4章)

## 2. 方法

- 公式の出題範囲から、小項目ごとの用語・要素の一覧を作った
- 各用語が、その小項目の問題(問題文、選択肢、解説)に出てくるかを正規表現で判定した
- 問題数を、重要度(LinuC)・配点(CCNA)から求めた目安と比べた
- 集計スクリプトの出力を、この報告の数値の根拠とした

判定は文字列の出現だけを見る。出現していても、浅い問い方の場合がある。CCNA は公式が小項目の下の用語一覧を出していないため、小項目の記載とテキストの見出しから要素を作った。ここには判断が入る。

### 3.2 配分

- 多すぎる: 1.10.1(15問、目安8)、1.11.1(11問、目安5)、1.09.1(8問、目安5)
- 少なすぎる: 1.10.4(4問、目安8)、1.07.2・1.07.3(各8問、目安11)、1.08.3(6問、目安8)

多い小項目を減らす必要はない。少ない小項目に足す。

### 3.3 形式

- 出力や表を読ませる問題: 5問(3%)
- 複数選択: 5問
- 入力問題(コマンド名などを書かせる): 0問。本番には一部入力問題がある。アプリの計算ドリルは数値の入力だけで、コマンド名の入力は扱っていない

## 5. 見つかった欠陥(修正済み)

出題順は入れ替わるため、他の問題を前提にした問題は解けない。

| 問題 | 内容 | 修正 |
|---|---|---|
| CCNA 3.0 問1〜問4 | 共通のルーティングテーブルが問題文に入っていなかった | 小項目の前置きを問題文に付けるようパーサを修正 |
| CCNA 1.0 問3 | 「問2 の状態で」と書いていた | 条件を問題文に書いた |
| CCNA 4.0 問6 | 「問5 と同じ設定で」と書いていた | 設定を問題文に書いた |
| CCNA 4.0 問30 | 「問29 の ACL で」と書いていた | ACL を問題文に書いた |

他の問題を参照する問題文が混ざるとテストが失敗するようにした。

## 7. 対応後(2026-11-18)

6章の 1〜6 の問題を追加し、入力問題の形式を加えた。

| 試験 | 問題数 | 用語・要素の出現率 | 入力問題 | 入力でも解ける選択問題 |
|---|---|---|---|---|
| LinuC 102 | 161 → 204 | 81% → 99%(205 / 208) | 15 | 32 |
| CCNA | 154 → 177 | 95% → 100%(161 / 161) | 4 | 6 |

小項目ごとの変化:

| 小項目 | 問題数 |
|---|---|
| LinuC 1.10.4 クラウドセキュリティ | 4 → 9 |
| LinuC 1.10.3 暗号化 | 8 → 12 |
| LinuC 1.07.2 / 1.07.3 | 8 / 8 → 11 / 13 |
| LinuC 1.06.1 | 10 → 14 |
| LinuC 1.08.3 | 6 → 8 |
| CCNA 1.7 DHCP | 1 → 7 |
| CCNA 1.6 クライアント | 2 → 5 |
| CCNA 3.4 HSRP / VRRP | 2 → 5 |
| CCNA 4.7 L2 セキュリティ | 2 → 7 |
| CCNA 5.6 syslog | 2 → 6 |

残っている課題:

- LinuC 1.11.2 の掲示板と開発サイト(重要度 1)
- LinuC の出力を読む問題が少ない(204 問中 5 問)
- LinuC 1.10.1(17 問)と 1.11.1(12 問)は、重要度に比べて多いまま
- CCNA のシミュレーションとドラッグ&ドロップは未対応

入力問題は、選択肢を書かず、解答の `**正解**:` の後ろに答えをコードで書く。入力として認める答えが複数あれば `、` で並べる。

```
**問28** ログアウトするときに読み込まれる、ユーザー個人の設定ファイルの名前を答えよ。

| 28 | `~/.bash_logout`、`.bash_logout` | 解説 |
```
