# FE テキスト 8.0 科目B プログラミング

基本情報技術者試験の科目 B のうち、プログラミングの出題範囲(目標とする技能の大項目 1〜4)を学びます。プログラムを読んで動きを追う力と、誤りを見つける力が中心です。この教材のプログラムは、すべて擬似言語で書きます。

## 擬似言語の記法

プログラムは、IPA の試験で使う擬似言語に似せた記法で書きます。この教材の約束は次のとおりです。`mod`、制御構文、配列の `{ }` と `[ ]`、`未定義の値` は、IPA の「擬似言語の記述形式」と同じです。`print`、`長さ(s)`、文字列の `s[i]`、`&` と、整数どうしの `÷` の結果は、この教材の約束です。IPA の試験では、必要なときに問題文で定めます。

| 書き方 | 意味 | 例 |
|---|---|---|
| `整数型: x, y` | 変数の宣言(`○` は付けない)。型は 整数型、実数型、論理型、文字列型 | `実数型: avg` |
| `整数型の配列: a ← {5, 3, 8}` | 配列の宣言と、初期値の設定 | 要素は `a[1]`、`a[2]` … |
| `整数型の二次元配列: m` | 二次元配列。要素は `m[行, 列]` | `m[2, 1]` |
| `大域: 整数型: g` | 大域変数の宣言。どの手続や関数からも使える | 下の 8.2 の 4 |
| `x ← 式` | 代入。右の式の値を、左の変数に入れる | `x ← x + 1` |
| `+`、`-`、`×`、`÷`、`mod` | 算術演算。`÷` は、整数どうしでは商の整数部分。`mod` は余り | `7 ÷ 2` は 3、`7 mod 2` は 1 |
| `=`、`≠`、`>`、`<`、`≧`、`≦` | 比較演算。結果は真か偽 | `x ≧ 60` |
| `and`、`or`、`not` | 論理演算 | `x > 0 and y > 0` |
| `if (条件)`、`elseif (条件)`、`else`、`endif` | 選択処理 | 下に例 |
| `while (条件)`〜`endwhile` | 前判定の繰返し。条件が真の間、繰り返す | 本体を 0 回も実行しないことがある |
| `do`〜`while (条件)` | 後判定の繰返し。本体を先に 1 回実行し、条件が真の間、繰り返す | 本体を必ず 1 回は実行する |
| `for (i を 1 から n まで 1 ずつ増やす)`〜`endfor` | 回数が決まっている繰返し。「減らす」もある | `for (i を 10 から 1 まで 3 ずつ減らす)` |
| `○整数型: f(整数型: n)` | 関数の宣言。値を返す | `return n × n` |
| `○proc(整数型: x)` | 手続の宣言。値を返さない | `proc(3)` で呼び出す |
| `return 値` | 関数の戻り値を返して、関数を終える | |
| `print(x, y)` | 値を出力する。複数の値は空白で区切って 1 行に出力する | `print(s)` |
| `長さ(s)`、`s[i]`、`&` | 文字列 s の文字数、s の i 番目の文字(1 番目から数える)、文字列の連結 | `"AB" & "C"` は "ABC" |
| `未定義の値` | 何も入っていない状態を表す | 連結リストの末尾の「次」など |

`○` は、手続と関数の宣言にだけ付けます。

```
整数型: p
p ← 70
if (p ≧ 90)
  print("S")
elseif (p ≧ 60)
  print("B")
else
  print("C")
endif
```

- 配列の要素番号は **1 から始まります**。多くのプログラム言語(0 から始まる)と違うので、注意します。
- `x ← 5` は、数学の「x = 5」の主張ではなく、「x に 5 を入れる」という命令です。`=` は、等しいかどうかを比べる記号です。
- `÷` は、整数どうしでは小数点以下を切り捨てます。どちらかが実数型のときは、実数の除算になります。問題ごとに、約束が書いてあります。

## 8.1 プログラミング全般

### 1. 要求事項の把握

プログラムを書く前に、**要求事項**(そのプログラムに求められること)を正確につかみます。次の 4 つに整理します。

| 種類 | 内容 | 例 |
|---|---|---|
| 機能 | プログラムが何をするか | 点数から合否を判定する |
| 入出力の内容 | 何を入力し、何を出力するか。形式や範囲 | 入力は 0〜100 の整数、出力は CSV |
| 性能 | 処理の速さや、扱うデータの量 | 1 万件を 3 秒以内に処理する |
| 制約条件 | 守らなければならない条件 | 使えるメモリは 64 MB まで |

あいまいな要求は、プログラムを書く前に確かめます。作った後で気づくと、直す手間が大きくなります。

### 2. 詳細設計

**詳細設計**では、要求事項に基づいて、プログラムの次の内容を決めます。

- 入出力(何を受け取り、何を返すか)
- 処理の手順
- 処理の効率(速さ、メモリ)
- 使うデータ構造とアルゴリズム(次の 8.3 で学びます)

設計した処理は、**擬似言語**や**流れ図**(処理の流れを記号と線で表した図)で表します。擬似言語は、特定のプログラム言語に縛られずに、処理の手順を文章に近い形で書く方法です。

### 3. 実装

詳細設計を、使うプログラム言語の**仕様**に沿って**実装**(コードにすること)します。処理の流れは、3 つの基本構造の組合せで組み立てます(**構造化プログラミング**)。

| 基本構造 | 内容 | 擬似言語 |
|---|---|---|
| 順次 | 上から順に実行する | 文を並べる |
| 選択 | 条件で処理を分ける | `if` |
| 繰返し | 条件を満たす間、または決めた回数だけ繰り返す | `while`、`do`、`for` |

`goto` で別の場所へ飛ぶ書き方は、流れを追いにくくするので避けます。

### 4. 既存のプログラムの解読と変更

既存のプログラムを読むときは、**処理の流れ**と**変数や配列の値の変化**を、順に追跡(**トレース**)します。トレースは、表に書くと間違えにくくなります。

次のプログラムを例にします。

```
整数型: s, i
s ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  s ← s + i × i
endfor
```

| i | s |
|---|---|
| (開始前) | 0 |
| 1 | 1 |
| 2 | 5 |
| 3 | 14 |

プログラムを**変更**するときは、変更したい箇所だけでなく、**ほかの処理への影響**も考えます。たとえば、配列の要素数を 5 から 8 に変えるなら、要素数の 5 を使っているすべての箇所(繰返しの終了値、平均を求める割り算)を直します。要素数は、変数にして 1 か所で決めると、直し忘れを防げます。

### 5. テスト

**テストケース**(テストの入力と、期待する結果の組)を、仕様から設計します。すべての入力を試すことはできないので、効率のよい選び方が必要です。

**同値分割**は、入力を「同じ結果になるはずの範囲(同値クラス)」に分け、各クラスから代表値を 1 つずつ選びます。**正常な場合**だけでなく、**異常な場合**(範囲外の値など)のクラスも作ります。

**限界値分析**は、クラスの**境界**の値と、その両側の値を選びます。誤りは、境界(`>` と `≧` の取り違えなど)で起きやすいためです。

例: 「点数(0〜100 の整数)が 60 以上なら合格、60 未満なら不合格、範囲外ならエラー」

| 方法 | 選ぶ値 |
|---|---|
| 同値分割 | 不合格(0〜59)から 30、合格(60〜100)から 80、範囲外から -5 と 120 |
| 限界値分析 | -1、0(下の境界)、59、60(合否の境界)、100、101(上の境界) |

テストは、仕様から作る**ブラックボックステスト**(同値分割、限界値分析)と、内部の構造を見て作る**ホワイトボックステスト**(すべての命令や分岐を通す)に分けられます。変更の後に、ほかの部分が壊れていないかを確かめるテストを回帰テストと言います。

### 6. デバッグ

**デバッグ**は、テストの結果や、実行時に出たエラーの内容を手掛かりに、誤りのある箇所と原因を特定し、修正することです。

1. 期待した結果と、実際の結果の違いを確かめる
2. 変数の値を追跡して、おかしくなる最初の箇所を探す
3. 原因を特定する(初期値、境界、条件の記号など)
4. ほかの処理に影響しないように直す
5. 同じテストをもう一度行い、誤りが解消したことを確かめる

よくある原因を挙げます。

| 原因 | 例 |
|---|---|
| 初期値の誤り | 最大値を求めるとき、max の初期値を 0 にして、負の数だけのデータで 0 が残る(正しくは `max ← a[1]`) |
| 繰返しの回数の 1 つ違い | `for (i を 1 から n - 1 …)` で、最後の要素を処理しない |
| 比較の記号の誤り | `>` と `≧` の取り違え |
| 配列の範囲外 | 要素数 5 の配列で `a[6]` を使う |

## 8.2 プログラムの処理の基本要素

### 1. 型、変数、配列、代入

**データ型**は、データの種類です。

| 型 | 持てる値 | 例 |
|---|---|---|
| 整数型 | 整数 | 42、-3 |
| 実数型 | 小数点以下を含む数 | 3.14 |
| 論理型 | 真か偽 | 合否 |
| 文字列型 | 文字の並び | "ABC" |

**変数**は、値を入れておく名前のついた箱です。**配列**は、同じ型の値を番号(要素番号)で並べたものです。`a[2]` は、配列 a の 2 番目の要素です。要素番号は 1 から始まります。

**代入**は、右の式の値を、左の変数や配列の要素に入れることです。代入すると、前の値は消えます。

```
整数型: x, y
x ← 3
y ← x
x ← 10
```

この後、y は 3 のままです(y ← x は、その時点の x の値を入れるだけです)。

2 つの変数の値を入れ替えるには、一時的に値を預ける変数が要ります。

```
t ← a
a ← b
b ← t
```

### 2. 算術演算、比較演算、論理演算

**算術演算**は、足し算、引き算、掛け算、割り算、余りです。整数どうしの `÷` は、小数点以下を切り捨てます。

**比較演算**は、2 つの値を比べて、真か偽を返します。**論理演算**は、真偽の値を組み合わせます。

| 演算子 | 結果が真になるとき |
|---|---|
| `a and b` | a も b も真 |
| `a or b` | a か b の少なくとも一方が真 |
| `not a` | a が偽 |

演算には**優先順位**があります。高い順に次のとおりです。

| 順位 | 演算 |
|---|---|
| 1 | かっこ `()`、メンバの参照 `.` |
| 2 | 単項の `not`、`+`、`-`(例: `-x`) |
| 3 | `×`、`÷`、`mod` |
| 4 | `+`、`-` |
| 5 | 比較(`=`、`≠`、`>`、`<`、`≧`、`≦`) |
| 6 | `and` |
| 7 | `or` |

同じ順位のときは、左から計算します。かっこは、最も先に計算します。たとえば `2 + 3 × 4` は 14 です。`x < 5 and y > 0 or x mod 2 = 0` は、`(x < 5 and y > 0) or (x mod 2 = 0)` の意味になります。式を読むときは、迷わないようにかっこを補って読みます。

### 3. 選択処理、繰返し処理

**選択処理**は、条件によって処理を分けます。`if` を並べるときは、`elseif` でつなぐか、独立した `if` にするかで、結果が変わります。

- `elseif` でつなぐ: 最初に成り立った条件の処理だけを実行する
- 独立した `if` を並べる: 条件を 1 つずつ確かめ、成り立ったものをすべて実行する

**繰返し処理**には、3 つの種類があります。

| 種類 | 条件を確かめる時点 | 本体の実行回数 |
|---|---|---|
| `for` | 回数が決まっている | 決めた回数 |
| `while` | 本体の**前** | 0 回以上 |
| `do`〜`while` | 本体の**後** | 1 回以上 |

繰返しの**継続条件**(続ける条件)と**終了条件**(終わる条件)は、表裏の関係です。`while (n > 10)` は「n が 10 より大きい間、続ける」という意味で、終了条件は「n が 10 以下」です。

例: 条件が最初から偽のとき

```
n ← 0
while (n > 0)
  n ← n - 1
endwhile
```

本体は 1 回も実行されません。`do`〜`while` なら 1 回実行され、n は -1 になります。

繰返しの結果は、変数の値をトレース表に書いて求めます。回数を数えるときは、終了条件を確かめる位置に注意します。

### 4. 手続・関数の呼出し

処理に名前をつけて**手続**や**関数**としてまとめると、同じ処理を使い回せ、プログラムが読みやすくなります。

| 種類 | 値を返すか | 使い方 |
|---|---|---|
| 関数 | 返す(`return`) | `s ← s + sq(k)` のように、式の中で使う |
| 手続 | 返さない | `addTwo(n)` のように、文として呼ぶ |

呼出し元が渡す値を**引数**、関数が返す値を**戻り値**と言います。

引数の渡し方は、プログラム言語によって違います。値だけを渡す(呼出し先で引数を変えても、呼出し元の変数は変わらない)場合と、変数そのものを渡す場合があります。この教材では、問題ごとに約束を書きます。

**変数の有効範囲**は、その変数を使える範囲です。手続や関数の中で宣言した変数(局所変数)は、その中だけで使えます。外で `大域:` を付けて宣言した変数(大域変数)は、どこからでも使えます。

```
大域: 整数型: g

○addTwo(整数型: x)
  x ← x + 2
  g ← g + x
```

```
整数型: n
g ← 1
n ← 10
addTwo(n)
print(g, n)
```

x は手続の中だけの変数です。値だけを渡すので、n は 10 のままです。g は手続の外の変数なので、変更が残り、g は 13 になります。出力は「13 10」です。

呼出し元と呼出し先での値の受け渡しは、1 つずつ表に書いて追います。

## 8.3 データ構造とアルゴリズム

### 1. 再帰

**再帰**は、関数が自分自身を呼び出す書き方です。再帰を止める条件(終了条件)が必要です。

```
○整数型: fact(整数型: n)
  if (n ≦ 1)
    return 1
  endif
  return n × fact(n - 1)
```

fact(3) の動きを追います。

① fact(3) は 3 × fact(2) を計算しようとして、fact(2) を呼ぶ。
② fact(2) は 2 × fact(1) を計算しようとして、fact(1) を呼ぶ。
③ fact(1) は 1 を返す(再帰が止まる)。
④ fact(2) は 2 × 1 = 2 を返す。
⑤ fact(3) は 3 × 2 = 6 を返す。

fact(3) を呼んだときの、呼出しと戻り値の流れを表した図です。

```text
呼出し(上から下へ)
  fact(3)
    +-- fact(2)
          +-- fact(1)      1 を返す。ここで再帰が止まる

戻り値(下から上へ)
  fact(1) = 1 --> fact(2) = 2 --> fact(3) = 6
```

終了条件がないか、満たされないと、呼出しが止まりません。

### 2. スタックとキュー

| データ構造 | 取り出す順 | 操作 |
|---|---|---|
| **スタック** | 最後に入れたものから(後入れ先出し、LIFO) | `push`(積む)、`pop`(取り出す) |
| **キュー** | 最初に入れたものから(先入れ先出し、FIFO) | `enqueue`(入れる)、`dequeue`(取り出す) |

スタックは、本を積み重ねて上から取る様子に似ています。関数の呼出しの記録にも使われます。キューは、窓口に並ぶ行列に似ています。

スタックとキューで、値の入る口と出る口がどこにあるかを表した図です。

```text
スタック: 入れる口と出す口が同じ。最後に入れたものが、最初に出ます
  top
   |
   v
  [3]    最後に入れた
  [2]
  [1]    最初に入れた

キュー: 後ろから入れて、前から出す。最初に入れたものが、最初に出ます
  dequeue <-- [1] [2] [3] <-- enqueue
```

操作は、表にして追います。

| 操作 | スタックの中身(右が上) |
|---|---|
| push(1) | 1 |
| push(2) | 1、2 |
| pop() → 2 | 1 |

### 3. 木構造

**木構造**は、根から枝分かれして、節点(ノード)がつながるデータ構造です。子が最大 2 つの木を**二分木**と言います。

二分木をたどる(**走査**する)順は、3 種類あります。

| 走査 | 順 |
|---|---|
| 前順(行きがけ順) | 節点 → 左の部分木 → 右の部分木 |
| 中間順(通りがけ順) | 左の部分木 → 節点 → 右の部分木 |
| 後順(帰りがけ順) | 左の部分木 → 右の部分木 → 節点 |

二分木の例と、3 種類の走査の順を表した図です。

```text
[5]
 +-- [3]
 |    +-- [1]
 |    `-- [4]
 `-- [8]
      `-- [9]

前順: 5, 3, 1, 4, 8, 9
中間順: 1, 3, 4, 5, 8, 9
後順: 1, 4, 3, 9, 8, 5
```

この木は、二分探索木にもなっています。中間順にたどると、小さい順になります。

**二分探索木**は、どの節点でも「左の部分木の値 < 節点の値 ≦ 右の部分木の値」になるように作った二分木です。値の**追加**は、根から比べながら進み、空いている位置に置きます。中間順でたどると、小さい順に値が取り出せます。**探索**も同じように、比べながら進みます。

### 4. グラフ

**グラフ**は、頂点と、頂点どうしをつなぐ辺でできたデータ構造です。道路網や、人のつながりを表せます。

グラフの**探索**には、2 つの方法があります。

| 方法 | 進み方 | 使うデータ構造 |
|---|---|---|
| 深さ優先探索 | 行けるところまで進み、行き止まりで戻る | スタック(再帰でも書ける) |
| 幅優先探索 | 近い頂点から順に広げる | キュー |

### 5. 連結リスト

**連結リスト**は、各要素(ノード)が「値」と「次のノードを指す情報」を持つデータ構造です。要素を途中に**追加**したり**削除**したりするとき、指す先を付け替えるだけで済みます。末尾のノードの「次」は、`未定義の値` にします。

ノード p の次にノード q を挿入する手順です。

```
q.次 ← p.次
p.次 ← q
```

上の 2 行を実行する前と、1 行ずつ実行した後の、つながり方を表した図です。

```text
実行する前: p の次は x
  [p] ----> [x]

1 行目の後: q の次が、x になる
  [p] ----> [x]
             ^
  [q] ------+

2 行目の後: p の次が、q になる
  [p] ----> [q] ----> [x]
```

順序を逆にすると、p の次だったノードへの手がかりが失われます。

削除するときは、削除するノードを飛ばして、1 つ前のノードの「次」を付け替えます。

```
p.次 ← p.次.次
```

### 6. 整列

**整列**(ソート)は、データを大小の順に並べ替えることです。

| アルゴリズム | 手順 | 計算量(比較の目安) |
|---|---|---|
| バブルソート | 隣り合う要素を比べて、前が大きければ入れ替える。これを繰り返す | n の 2 乗に比例 |
| 選択ソート | 残りの中の最小値を選び、先頭と入れ替える | n の 2 乗に比例 |
| 挿入ソート | 整列済みの部分に、1 つずつ正しい位置へ挿入する | n の 2 乗に比例(ほぼ整列済みなら速い) |
| クイックソート | 基準値より小さい群と大きい群に分け、それぞれを同じ方法で整列する | 平均は n × log n に比例 |

バブルソートの 1 回の通過を追います。

| 比べる 2 つ | 配列 |
|---|---|
| (開始前) | {5, 1, 4, 2} |
| 5 と 1 | {1, 5, 4, 2} |
| 5 と 4 | {1, 4, 5, 2} |
| 5 と 2 | {1, 4, 2, 5} |

### 7. 探索と計算量

| 探索 | 方法 | 比較の回数の目安 |
|---|---|---|
| 線形探索 | 先頭から 1 つずつ比べる | n に比例(最悪 n 回) |
| 二分探索 | 整列済みのデータで、中央と比べて範囲を半分に絞る | log n に比例 |

**計算量**は、処理に必要な時間や手間が、データの量 n に対してどう増えるかを表します(処理効率の違い)。要素が 1,000 個のとき、線形探索は最悪 1,000 回ですが、二分探索は約 10 回で済みます。ただし、二分探索は、整列済みのデータにしか使えません。

### 8. 文字列処理

文字列に対する基本の処理です。

| 処理 | 内容 |
|---|---|
| 探索 | 文字列の中に、ある文字や文字列があるかを調べる |
| 比較 | 2 つの文字列が等しいか、辞書順でどちらが先かを調べる |
| 置換 | ある文字を、別の文字に置き換える |
| 連結 | 文字列をつなげる |
| 分割 | 区切り文字などで、文字列を分ける |

先頭から 1 文字ずつ調べる処理の例です。

```
文字列型: s
整数型: i, c
s ← "BANANA"
c ← 0
for (i を 1 から 長さ(s) まで 1 ずつ増やす)
  if (s[i] = "A")
    c ← c + 1
  endif
endfor
```

c は 3 になります。

## 8.4 諸分野への適用

この小項目では、数理、データサイエンス、AI の分野で使う基本的な処理を、プログラムで読み書きします。計算式や手順が示されるので、**式の意味をプログラムの文と対応づけて**読みます。

### 1. 統計量の算出

**統計量**は、データの特徴を表す数です。

| 統計量 | 意味 | 求め方 |
|---|---|---|
| 平均値 | 値の合計をデータの個数で割った値 | 合計 ÷ 個数 |
| 中央値 | 小さい順に並べたときの真ん中の値 | 個数が偶数なら、真ん中の 2 つの平均 |
| 最頻値 | 最も多く出てくる値 | 値ごとの出現回数を数え、最大を選ぶ |
| 分散 | 各値と平均との差の 2 乗の平均 | 差の 2 乗の合計 ÷ 個数 |
| 標準偏差 | 分散の平方根 | データの散らばりの目安 |

データ {2, 4, 4, 4, 5, 5, 7, 9} は、平均が 5、分散が 4、標準偏差が 2 です。

### 2. データの集計と加工

**集計**は、データを数えたり、合計したりして、まとめることです。値ごとの出現回数は、値を配列の要素番号として使って数えます。

```
c[d[i]] ← c[d[i]] + 1
```

点数を 10 点刻みの階級に分けるには、点数 ÷ 10 で階級を求めます。階級の数と、配列の要素数に注意します(100 点を含めると 11 個の階級)。

**加工**は、データを使いやすい形に変えることです。たとえば、**最小最大正規化**は、値 x を (x - 最小値) ÷ (最大値 - 最小値) で、0 から 1 の範囲に変換します。

また、**移動平均**(連続する数個ずつの平均)や、**累積和**(先頭からの合計)も、データの加工の例です。累積和 s があれば、a[i] から a[j] の区間の合計は、s[j] - s[i - 1] で求められます。

### 3. 行列とベクトルの演算

**ベクトル**は、数を並べたものです。2 つのベクトルの**内積**は、対応する要素の積の和です。

u = {1, 2, 3}、v = {4, -5, 6} の内積は 1 × 4 + 2 × (-5) + 3 × 6 = 12 です。

**行列**は、数を縦横に並べたものです。行列 a と b の**積**の c[i, j] は、a の第 i 行と b の第 j 列の、対応する要素の積の和です。プログラムでは、3 重の繰返しで書きます。

```
for (i を 1 から 2 まで 1 ずつ増やす)
  for (j を 1 から 2 まで 1 ずつ増やす)
    for (k を 1 から 2 まで 1 ずつ増やす)
      c[i, j] ← c[i, j] + a[i, k] × b[k, j]
    endfor
  endfor
endfor
```

### 4. AI の分野の処理

AI(機械学習)の分野でも、基本の処理は同じです。たとえば、予測が正解と合っていた割合を**正解率**と言います。

```
正解率(%) = 当たった件数 × 100 ÷ 全体の件数
```

5 件中 3 件が合っていれば、3 × 100 ÷ 5 = 60 で、60% です。試験では、示された式や手順を、プログラムの処理と対応づけて読む力が問われます。
