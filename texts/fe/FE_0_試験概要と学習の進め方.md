# FE 0 試験概要と学習の進め方

作成: 2026-11-25
対象: 基本情報技術者試験(IPA。新しい試験制度のシラバス案 Ver.0.1 に合わせています)

基本情報技術者試験(FE)は、IT を仕事にする人が持っているとよい、基礎の知識と技能を問う国家試験です。IT パスポートより深く、計算や仕組みまで問われます。このアプリでは、科目 A(知識)を 1.0〜7.0 章、科目 B のプログラミングを 8.0 章、科目 B の情報セキュリティを 9.0 章で学びます。

## 1. 試験の概要

### 1. 試験の制度

| 項目 | 内容 |
|---|---|
| 実施する団体 | IPA(情報処理推進機構) |
| 新しい制度 | 2027 年度から新しい試験制度に移る予定です。基本情報技術者試験は 2027 年度の春ごろからです |
| 現行の制度 | 2026 年度の試験で終わる予定です |
| 実施の方法 | 通年で実施します。すべての試験区分が CBT(コンピュータを使う方式)です |
| 試験の名前 | 変わりません(基本情報技術者試験) |
| シラバス | 現行は Ver.9.2。新しい制度のシラバス案は Ver.0.1(2026 年 9 月 30 日に掲載)で、今後変わる可能性があります |

> **【要確認】** シラバス案は変更される可能性があります。受験の前に、IPA の公式のページで最新のシラバスと、受験の申し込みの方法を確認してください。

### 2. 新しい制度と現行の違い

IPA は、新しい制度での変更を「表記の変更等」と説明しており、問われる知識と技能の範囲は変わらないとしています。

| 項目 | 現行 | 新しい制度(予定) |
|---|---|---|
| 科目 A の時間と問題数 | 90 分、60 問 | 90 分、60 問 |
| 科目 B の時間と問題数 | 100 分、20 問 | 100 分、20 問 |
| 科目 A の出題範囲 | 従来の分類(テクノロジ系、マネジメント系、ストラテジ系) | 体系を変えます(大分類 1〜7。次の節) |
| 科目 B の範囲 | アルゴリズムとプログラミング、情報セキュリティ | 範囲を一部変えます(「目標とする技能」で示されます) |
| 科目 A の免除制度 | あり | 変更の予定はありません |

> **【要確認】** 新しい制度での採点の方式と合格の基準は、確認できていません。次の節の現行の基準を参考にして、IPA の発表を確認してください。

### 3. 科目 A と科目 B

| | 科目 A | 科目 B |
|---|---|---|
| 問うもの | 知識 | 技能 |
| 時間 | 90 分 | 100 分 |
| 問題数 | 60 問(現行では、評価されるのは 56 問で、残りの 4 問は今後出す問題の評価に使われます) | 20 問(同じく、評価されるのは 19 問) |
| 形式 | 四つの選択肢から 1 つを選ぶ | 多肢選択式(複数の空欄を選ぶ形も含む) |
| 内容 | 技術、開発、セキュリティ、経営、法務などの幅広い知識と計算 | 擬似言語のプログラムを読んで動きを追う、アルゴリズムを考える、情報セキュリティの事例を読んで考える |

- 科目 A と科目 B は、同じ日に続けて受けます。CBT では、科目 A が終わってから科目 B が始まるまでに、最長 10 分の休憩を取れます。
- 科目 B は、科目 A より点を取りにくいと言われます。プログラムを読み、値を追う練習が必要です。

### 4. 採点と合格の基準(現行)

現行の試験要綱(Ver.5.6)では、次のように決められています。

| 項目 | 内容 |
|---|---|
| 採点の方式 | IRT(項目応答理論)に基づいて、解答の結果から評価点を計算します |
| 配点 | 科目 A、科目 B ともに 1,000 点満点 |
| 合格の基準 | 科目 A の評価点と科目 B の評価点が、どちらも 600 点以上 |

- IRT では、正解した問題の数をそのまま点にするのではなく、問題の難しさを考えた点になります。そのため、「何問正解なら合格」とは言い切れません。
- どちらか一方でも 600 点に届かなければ、不合格です。科目 A が得意でも、科目 B を捨てることはできません。

## 3. 前提の知識

特別な資格は要りません。次のようなことを知っていると、学びやすくなります。

| 分野 | 目安 |
|---|---|
| 数学 | 中学から高校の初めの数学(割合、確率、2 乗、対数は後で説明します) |
| コンピュータ | パソコンの部品(CPU、メモリ、ストレージ)の名前を聞いたことがある |
| プログラミング | 変数、if、for(while)の意味を知っている。1 つの言語を少し触った経験があるとよい |
| 英語 | 略語(RAM、API、SLA など)が多く出ます。英語の正式名と意味を一緒に覚えます |

プログラミングの経験がなくても大丈夫です。8.0 章で、変数から順に学びます。

## 4. 学習の進め方

1. **科目 A の範囲を一通り読む**: 1.0 章から 7.0 章まで、テキストを読みます。用語を 1 つずつ、短く説明できるかを確かめます。
2. **計算の問題は手で解く**: 稼働率、クリティカルパス、2 進数、確率、損益分岐点など、基本情報の科目 A は計算が多く出ます。式を覚えるだけでなく、紙に式を書いて、①② … と順に計算します。
3. **問題を解く**: 小項目ごとに問題を解き、間違えた問題はテキストの同じ番号の節に戻ります。
4. **科目 B は早めに始める**: 8.0 章(プログラミング)は、読むだけでは身に付きません。毎日、短い擬似言語のプログラムを 1 つ追います。
5. **過去問題で時間を測る**: 仕上げに、IPA が公開している過去問題を時間を計って解きます(このアプリの問題は、すべてオリジナルです)。科目 B は 1 問に 5 分前後しかかけられないので、時間の感覚をつかみます。

| 時期 | 目安 |
|---|---|
| 最初の 1 か月 | 科目 A の範囲を一通り読む。基数の変換、論理演算、確率を毎日少しずつ |
| 次の 1 か月 | 科目 A の問題を解く。科目 B の擬似言語を毎日 1 問 |
| 最後の 2 週間 | 過去問題で、科目 A と科目 B の時間を測る |

> **【要確認】** 上の期間は、1 日に 1〜2 時間の勉強を想定した目安です。人によって変わります。

## 5. 演習の環境(科目 B の練習のしかた)

科目 B のプログラムは「擬似言語」で書かれています。擬似言語は、試験のために決められた、実在しない言語です。実行する環境はありません。そのため、頭と紙で動きを追う練習が中心になります。

### 1. 擬似言語を読む

擬似言語の書き方は、IPA の公開資料「擬似言語の記述形式」に決まりがあります。8.0 章で詳しく学びます。ここでは、練習の例として、次のような形を使います。

```
整数型: i, sum
sum ← 0
for (i を 1 から 3 まで 1 ずつ増やす)
  sum ← sum + i
endfor
```

- `←` は代入です。右側の値を、左側の変数に入れます。
- `for … endfor` は、決まった回数の繰り返しです。

### 2. トレース表で変数の値を追う

トレース表は、プログラムを 1 行ずつ動かしながら、変数の値を書き込む表です。列に変数の名前、行に実行の順番を書きます。

上の例を、次の手順で追います。

1. 紙に、列を `i`、`sum` として表を作る。
2. 最初の行に、初期値を書く(`sum` は 0、`i` はまだ決まっていないので「-」)。
3. 1 行実行するたびに、値が変わった変数だけを新しい行に書く。
4. 繰り返しが終わった時点の値が、答え。

| 実行の順番 | i | sum | メモ |
|---|---|---|---|
| 開始 | - | 0 | `sum ← 0` を実行した |
| 1 回目 | 1 | 1 | `sum ← 0 + 1` |
| 2 回目 | 2 | 3 | `sum ← 1 + 2` |
| 3 回目 | 3 | 6 | `sum ← 3 + 3` |

答えは `sum` が 6 です。

- 値が変わらない変数は、前の行の値を書き写します(書き忘れると、後で読み間違えます)。
- 配列を使うときは、`a[1]`、`a[2]` … のように、要素ごとに列を作ります。
- 繰り返しの終わりの条件(境界)で間違えやすいので、最後の回だけは特に丁寧に追います。

### 3. Python で同じ処理を書いて確かめる

トレース表の答えが合っているかは、Python で同じ処理を書くと確かめられます。Python は、パソコンに入れるか、ブラウザで使えるオンラインの実行環境で動かせます。

```python
total = 0
for i in range(1, 4):   # 1, 2, 3 (4 は含まない)
    total = total + i
    print(i, total)     # 途中の値を表示すると、トレース表と見比べられる
print(total)            # 6
```

| 擬似言語 | Python | 注意 |
|---|---|---|
| `sum ← 0` | `total = 0` | `sum` は Python の組み込みの関数の名前なので、別の名前にする |
| `for (i を 1 から 3 まで 1 ずつ増やす)` | `for i in range(1, 4):` | `range` は終わりの値を含まない |
| 配列の最初の要素 `a[1]` | `a[0]` | 試験の擬似言語は、添字が 1 から始まる前提の問題が多い(問題文で確認する) |
| 整数の割り算の商 | `a // b` | 余りは `a % b` |

- 先にトレース表で答えを出し、その後で Python を動かして確かめます。順番を逆にすると、考える力が付きません。
- 表と Python の結果が違ったら、どの行から値がずれたかを探します。このずれを探す練習が、科目 B で点になります。
- 試験では実行できません。Python は「答え合わせの道具」として使います。

### 4. その他の演習

- 2 進数や 16 進数の変換は、電卓(プログラマー電卓の機能)で確かめられます。
- 稼働率やクリティカルパスのような計算は、手で解いてから、表計算ソフトで同じ式を作ると、式の意味が分かります。
- 情報セキュリティは、自分が使っているサービスに当てはめて考えます(パスワードの管理、多要素認証の設定など)。
