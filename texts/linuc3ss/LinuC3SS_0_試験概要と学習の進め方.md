# LinuC 3SS 0 試験概要と学習の進め方

作成: 2026-11-25
対象: LinuC レベル3 3SS 試験(セキュリティスペシャリスト、Version 1.0)

LinuC レベル3 は、2025 年 12 月 1 日に 2 つの認定に変わりました。3PS(プラットフォームスペシャリスト)と 3SS(セキュリティスペシャリスト)です。3SS 試験は、アクセス制御と権限の絞り込み(ACL、SELinux、AppArmor、seccomp、ケーパビリティ)、カーネルとファイアウォールと暗号化による守り、監査、コンテナの堅牢化、TLS と DNSSEC などの安全なプロトコル、統合認証、侵入の検知と診断を扱います。Linux のサーバーを攻撃から守り、異常に気づける状態にするための試験です。

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 試験 | LinuC レベル3 3SS 試験(Version 1.0) |
| 試験時間 | 90 分(試験の後のアンケートの 5 分を含む) |
| 問題の数 | 約 60 問 |
| 形式 | 選択式と、コマンド名などを入力する問題【要確認】 |
| 受験料 | 27,500 円(税込、1 試験あたり)【要確認】 |
| 会場 | ピアソン VUE のテストセンター、またはオンライン |
| 認定の条件 | 有効な LinuC レベル2 の認定を持ち、3PS 試験か 3SS 試験のどちらか 1 つに合格する |
| 言語 | 日本語(英語版は 2026 年春に始まる予定と発表されていた)【要確認】 |

> **【要確認】** 試験時間、問題の数、受験料は、2025 年 11 月の発表の記事で確かめた値です。出題の形式は公式の資料で確かめられていません。申し込む前に、LinuC 公式のページで確認してください。

### 以前の試験との関係

以前のレベル3 は、300 試験(混在環境)、303 試験(セキュリティ)、304 試験(仮想化と高可用性)の 3 つでした。これらは 2026 年 11 月 30 日に配信を終えます。3SS は、303 試験のセキュリティに、コンテナの堅牢化、統合認証(FreeIPA、Keycloak)、セキュリティの診断を加えた範囲です。

## 2. 出題の分野と重要度

| 主題 | 重要度の合計 |
|---|---|
| 1.0 アクセスおよび権限制御の強化 | 15 |
| 2.0 システム保護と監査 | 12 |
| 3.0 堅牢なコンテナ設計 | 4 |
| 4.0 セキュアプロトコルによる各種機能の実装 | 11 |
| 5.0 認証・認可 | 8 |
| 6.0 インシデントの検知・防止 | 10 |

重要度は、小項目ごとに示された値の合計です。1.0 と 2.0 が大きいので、ここを先に固めます。小項目では、6.1(ネットワークセキュリティ)の重要度が 4 で最も大きくなっています。

## 3. 前提の知識

LinuC レベル2(201 試験と 202 試験)の範囲です。特に次のものを使います。

- ユーザーとグループ、パーミッション、sudo(LinuC 101 1.02、LinuC 102 1.08)
- systemd のユニットと journalctl(LinuC 101 1.01、LinuC 102 1.09)
- DNS、Web、メールのサーバーの設定(LinuC 202 2.08、2.09、2.10)
- PAM、LDAP、SSH、ファイアウォール、SELinux の基本(LinuC 202 2.07、2.12)
- コンテナの基本(LinuC 201 2.06)

暗号(公開鍵、証明書、ハッシュ)の考え方は、用語集の「暗号と証明書」で確かめられます。

## 4. 学習の進め方

1. **演習環境を作る**(次の章)。3SS 試験は、設定を変えて、拒否やログを実際に見る操作が多いので、壊してよい仮想マシンで手を動かします。
2. **1.0 から読む**。権限の仕組み(DAC、ACL、SELinux、ケーパビリティ)は、2.0 と 3.0 の前提になります。
3. **拒否されたら、まずログを見る習慣を付けます。** SELinux の `type=AVC`、AppArmor の `apparmor="DENIED"`、auditd の記録、seccomp の `SECCOMP` の記録です。止めて直すのではなく、ログから原因を突き止めます。
4. **4.0 は、設定を書いたら、外から確かめます。** `openssl s_client`、`dig +dnssec`、`delv` などで、相手から見える状態を確かめます。
5. **6.0 の道具は、自分の環境にだけ使います。** スキャナーや侵入検知の試験は、自分が管理する仮想マシンに対して行います。
6. **問題を解く**。入力で解くモードで、コマンドとオプションの名前を思い出す練習もします。

## 5. 演習環境の作り方

LinuC 201 と同じ仮想マシンを使います。作り方は LinuC 102 0 の「演習環境の作り方」と、LinuC 201 0 の注意を読んでください。3SS 試験に関係する注意だけをまとめます。

- **AlmaLinux 9 と Ubuntu 24.04 の 2 台を用意します。** SELinux は AlmaLinux、AppArmor は Ubuntu で既定で動いています。両方を試せます。
- **SELinux と AppArmor は止めずに試します。** permissive や complain のモードにして、ログを読む練習をします。
- **LUKS(2.3)は、空のディスクを 1 本追加して試します。** 今使っているディスクを暗号化しないでください。パスフレーズを忘れると、データは戻せません。
- **ファイアウォール(2.2)は、コンソールから入れる仮想マシンで試します。** 規則を間違えると SSH が切れます。
- **証明書(4.1)は、インターネットから届くドメインがなければ、ステージング環境か自己署名の証明書で試します。** Let's Encrypt の本番には、回数の制限があります。
- **FreeIPA と Keycloak(5.2、5.3)は、メモリを 4 GB 以上割り当てた仮想マシンで試します。** FreeIPA のサーバーには、固定の IP アドレスと完全修飾ドメイン名(例: `ipa.example.com`)が要ります。
- **ドメイン名と IP アドレスは、文書用の値を使います。** ドメイン名は `example.com`、IP アドレスは `192.0.2.0/24` などです。
- 練習の前に仮想マシンのスナップショットを取り、壊したら戻します。
