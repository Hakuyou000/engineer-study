# K8s 0 試験概要と学習の進め方

作成: 2026-11-19
対象: CKA(Certified Kubernetes Administrator)の試験範囲 + 実務の Kubernetes

このテキストは、CKA の試験範囲を網羅し、そのうえで SRE やインフラの実務で必要になる Kubernetes の知識まで扱います。どこが試験の範囲で、どこが実務の知識かを、見出しと問題のタグで見分けられるようにしています。

## 1. タグの見方

| タグ | 意味 |
|---|---|
| **〔CKA〕** / `[CKA]` | CKA の公式の試験範囲(Curriculum)に入っている内容 |
| **〔実務〕** / `[実務]` | 試験の範囲の外だが、本番の運用でよく使う内容 |

- テキストでは、見出しの最後に〔CKA〕〔実務〕を付けています。
- 問題では、問題 ID の横に `CKA` / `実務` のタグが表示されます。
- 試験の直前は〔CKA〕だけ、実務に入る前は〔実務〕も、のように使い分けます。

## 2. CKA の試験の概要

| 項目 | 内容 |
|---|---|
| 実施 | CNCF / The Linux Foundation |
| 形式 | **実技**。ブラウザの中のターミナルで、実際のクラスタを操作して課題を解く。オンラインで監督付きの受験 |
| 問題の数 | 15〜20 問ほどの作業 |
| 試験時間 | 2 時間 |
| 合格ライン | 66% |
| 受験料 | US$445 前後。再受験 1 回と、模擬試験の環境(killer.sh)2 回分が付く |
| 参照できる資料 | Kubernetes の公式ドキュメント(kubernetes.io/docs など)、Helm のドキュメント、Gateway API のドキュメント |
| 対象のバージョン | 最新のマイナーバージョンに合わせて、リリースの 4〜8 週間後に更新される(2026-11 時点は v1.37) |
| 有効期間 | 2 年 |

> **【要確認】** 受験料、対象のバージョン、参照できるサイトは変わります。申し込む前に Linux Foundation の公式のページで確認してください。

## 3. 出題の分野と配点

| 分野 | 配点 | テキスト |
|---|---|---|
| 1 クラスタのアーキテクチャ、インストール、設定 | 25% | `K8s_1.0_…` |
| 2 ワークロードとスケジューリング | 15% | `K8s_2.0_…` |
| 3 サービスとネットワーク | 20% | `K8s_3.0_…` |
| 4 ストレージ | 10% | `K8s_4.0_…` |
| 5 トラブルシューティング | **30%** | `K8s_5.0_…` |
| 6 実務の運用(試験の範囲外) | - | `K8s_6.0_…` |

2025 年 2 月の改訂で、次の項目が加わりました。古い教材には載っていないことがあります。

- Helm と Kustomize でクラスタの部品を入れる
- 拡張のインターフェース(CNI、CSI、CRI)の理解
- CRD とオペレーター
- Gateway API で外からの通信を管理する
- ワークロードのオートスケーリング

## 4. 試験は実技なので

このアプリの問題は選択式ですが、CKA は実技の試験です。問題では、試験で打つコマンドや YAML、出力の読み方を問い、手で打つときに迷わないようにしています。

| 試験で大切なこと | 対策 |
|---|---|
| 速さ | YAML を一から書かず、`kubectl create … --dry-run=client -o yaml` で下書きを作る |
| 正しいクラスタで作業する | 問題ごとに `kubectl config use-context …` が指定される。必ず実行する |
| ドキュメントを引く | 公式ドキュメントのどこに何があるか(Tasks の各ページ)を覚えておく |
| 確認 | 作ったら `kubectl get`、`describe` で動いているか確かめる |

## 5. 学習の進め方

1. **クラスタを用意する**: kind や minikube で手元に作る。CKA は kubeadm のクラスタなので、仮想マシン 2〜3 台で kubeadm のクラスタも一度は作る。
2. **分野 1〜4 を読んで手を動かす**: Pod → Deployment → Service → PVC の順に、作る・壊す・直すを繰り返す。
3. **分野 5(トラブルシューティング)を重点的に**: 配点が最も大きい。わざとノードの kubelet を止める、イメージ名を間違える、などで障害を起こして直す。
4. **問題を解く**: 〔CKA〕のタグの問題をすべて解けるようにする。
5. **模擬試験**: 受験料に付く killer.sh で、時間を計って解く。
6. **分野 6(実務)**: 合格の後、または実務に入る前に読む。
