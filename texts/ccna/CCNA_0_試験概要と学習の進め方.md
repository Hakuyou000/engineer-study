# CCNA 0 試験概要と学習の進め方

作成: 2026-11-17
対象: Implementing and Administering Cisco Solutions (200-301 CCNA) **v2.0**

CCNA は、Cisco が実施するネットワークの基礎の資格です。ネットワークの仕組みの理解に加えて、Cisco の機器を設定し、問題を見つけて直す力が問われます。

## 3. v1.1 からの変更点

市販の参考書や問題集の多くは、v1.1 以前の範囲で書かれています。違いを知ったうえで使いましょう。

| 区分 | 内容 |
|---|---|
| 追加された | DNS のレコード(A / AAAA / CNAME / MX / NS / PTR)、AAA クライアント(TACACS+ / RADIUS)の設定、SFTP / SCP、ストーム制御、RA ガード、パケットキャプチャの読み取り、IaC、OSPFv3、HSRP / VRRP の状態の読み取り、エージェント型 AI、生成 AI へのプロンプトの選び方 |
| 削除された・明記がなくなった | QoS、NTP、TFTP / FTP、REST API、JSON、Terraform、WLC の GUI での設定、TCP と UDP の比較、セキュリティプログラムの要素、パスワードポリシー、機械学習の概念 |
| 傾向 | 求められることが「説明する」から「設定する」「トラブルシュートする」「診断する」へ変わった。機器の出力を読んで原因を見つける力が必要 |

> **【注意】** 明記がなくなった項目も、前提の知識としては使います。TCP と UDP、ポート番号、NTP(ログの時刻を合わせるため)は理解しておきましょう。

## 4. 出題範囲の動詞の意味

| 動詞 | 求められること |
|---|---|
| Describe(説明する) | 概念、役割、違いを答えられる |
| Interpret(読み取る) | show コマンドの出力やメッセージの意味を答えられる |
| Diagnose / Troubleshoot(診断する) | 症状と出力から原因を見つけ、直し方を選べる |
| Configure(設定する) | コマンドを書ける。シミュレーション問題の対象になる |
| Validate(検証する) | 実際の機器の出力と資料を突き合わせ、違いを見つけられる |

## 5. 過去問について

- CCNA の過去問は公開されていません。試験の問題は、機密を守る契約の対象です。
- 「過去問」「実際の試験問題」「ダンプ」を名乗るサイトの問題は、試験問題を無断で持ち出したものです。使うと Cisco の試験の規約に違反し、認定が取り消されることがあります。正解が間違っていることも多くあります。
- このアプリの問題は、すべて公式の出題範囲に沿って作ったオリジナルです。
- 本番の形式に慣れるには、Cisco 公式の模擬試験、公式ガイド(Official Cert Guide)に付いている問題、Packet Tracer(Cisco のシミュレーター)での練習を使いましょう。

## 6. 学習の順番

| 順番 | 内容 | 理由 |
|---|---|---|
| 1 | 1.0 のうち、IPv4 のサブネットの計算、ケーブル、インターフェース | すべての分野の前提になるため |
| 2 | 2.0 の VLAN、トランク、STP、EtherChannel | 配点が 25% で、設定の問題の中心になるため |
| 3 | 3.0 のルーティングテーブル、スタティックルート、OSPF | 計算と出力の読み取りが多いため |
| 4 | 1.0 の IPv6、DHCP、無線 | 3.0 の IPv6 ルーティングの前に、IPv6 を固めるため |
| 5 | 4.0 の ACL、NAT、L2 のセキュリティ、AAA | 設定の問題が多いため |
| 6 | 5.0 の SNMP、syslog、Ansible、AI | 覚えることが中心なので、最後でよい |

- サブネットの計算は毎日解きましょう。1問 30 秒が目安です。
- 設定のコマンドは、Packet Tracer で実際に打って確かめましょう。読んだだけでは身につきません。
- 各テキストを読んだら、対応する問題を解きます。間違えた問題は、テキストの該当する節に戻って読み直します。

学習の繰り返し方を、図にまとめます。

```text
[Text] テキストを読む
   |
   v
[Quiz] 対応する問題を解く
   |
   +-- wrong --> [Text] の該当する節に戻って読み直す
   +-- right --> 次の節へ進む
```

## 8. 演習環境の作り方

### 1. Packet Tracer を入れる

Packet Tracer は、Cisco のネットワークのシミュレーターです。無料で、CCNA の設定のほとんどを試せます。

1. Cisco Networking Academy(Skills for All)のアカウントを作ります(無料)。
2. 「Getting Started with Cisco Packet Tracer」のコースに登録し、そのページからダウンロードします。2026-11 時点の版は 9.0 系です。Windows、macOS、Ubuntu の版があります。
3. 最初の起動のときに、Skills for All のアカウントでログインします。

> **【要確認】** ダウンロードの場所と版は変わることがあります。Networking Academy のページで確認してください。

### 2. Packet Tracer で試せること、試せないこと

| 試せる | 試せない、または一部だけ |
|---|---|
| VLAN、トランク、STP、EtherChannel、ポートセキュリティ | 実機のような NETCONF / RESTCONF / REST API の操作 |
| スタティックルート、OSPF、HSRP | Ansible で機器を設定すること |
| ACL、NAT、DHCP、DHCP スヌーピング、SSH、syslog、NTP、SNMP | 生成 AI やエージェント型 AI での運用(5.0 の一部) |
| IPv6 のアドレスとルーティング | 一部の新しい show コマンドの出力 |

試せないものは、テキストの出力例で読み方を覚えます。実機に近い IOS を動かしたいときは、Cisco Modeling Labs の無料版(CML-Free。動かせる機器の数に上限がある)や、Cisco DevNet のサンドボックス(予約して使う無料の実験環境)を使います。

### 3. 最初に作る構成

次の小さな構成で、ほとんどの分野を練習できます。

```text
PC1 ---- SW1 ======== SW2 ---- PC2
          |            |
          R1 -------- R2

==== はトランク(VLAN 10 と 20 を通す)
R1 と R2 は OSPF で経路を交換する
```

1. SW1 と SW2 に VLAN 10 と 20 を作り、トランクでつなぐ
2. R1 でサブインターフェース(ルーター・オン・ア・スティック)を作り、VLAN の間をルーティングする
3. R1 と R2 で OSPF を動かし、`show ip ospf neighbor` と `show ip route` を読む
4. R1 に DHCP サーバーと NAT と ACL を設定し、PC から確かめる
5. 設定は `.pkt` ファイルに保存し、壊したら開き直す

### 4. 片付け

Packet Tracer はパソコンの中だけで動くので、費用はかかりません。作った構成は分野ごとに別のファイルにすると、後で復習しやすくなります。
