## 3. v1.1 からの変更点

市販の参考書・問題集の多くは v1.1 以前の範囲で書かれている。差分を把握して使う。

| 区分 | 内容 |
|---|---|
| 追加 | DNSレコード(A/AAAA/CNAME/MX/NS/PTR)、AAAクライアント(TACACS+/RADIUS)の設定、SFTP/SCP、ストーム制御、RAガード、パケットキャプチャの読解、IaC、OSPFv3、HSRP/VRRPの状態読解、エージェント型AI、生成AIへのプロンプト選択 |
| 削除・明記なし | QoS、NTP、TFTP/FTP、REST API、JSON、Terraform、WLCのGUI設定、TCPとUDPの比較、セキュリティプログラムの要素、パスワードポリシー、機械学習の概念 |
| 傾向 | 動詞が「説明する」から「設定する」「トラブルシュートする」「診断する」へ。出力を読んで原因を特定する力が要る |

> **【注意】** 明記がなくなった項目も、前提知識としては使う。TCP/UDP、ポート番号、NTP(ログの時刻)は理解しておく。

## 4. 動詞の意味

| 動詞 | 求められること |
|---|---|
| Describe(説明する) | 概念・役割・違いを答えられる |
| Interpret(読み取る) | show 出力やメッセージの意味を答えられる |
| Diagnose / Troubleshoot | 症状と出力から原因を特定し、修正方法を選べる |
| Configure(設定する) | コマンドを書ける。シミュレーション問題の対象 |
| Validate(検証する) | 実機の出力と資料を突き合わせ、食い違いを見つけられる |

## 5. 過去問について

- CCNA の過去問は公開されていない。試験問題は機密保持契約の対象
- 「過去問」「実際の試験問題」「ダンプ」を名乗るサイトの問題は、試験問題の無断流出。利用は Cisco の試験規約違反で、認定取り消しの対象になる。正答の誤りも多い
- このプロジェクトの問題はすべて公式出題範囲に沿ったオリジナル
- 本番形式に慣れるには、Cisco 公式の模擬試験、公式ガイド(Official Cert Guide)付属の問題、Packet Tracer でのラボを使う

## 6. 学習順

| 順 | 内容 | 理由 |
|---|---|---|
| 1 | 1.0 のうち IPv4 サブネット計算、ケーブル、インターフェース | 全分野の前提 |
| 2 | 2.0 VLAN、トランク、STP、EtherChannel | 配点25%。設定問題の中心 |
| 3 | 3.0 ルーティングテーブル、スタティック、OSPF | 計算と出力読解 |
| 4 | 1.0 の IPv6、DHCP、無線 | 3.0 の IPv6 ルーティングの前に IPv6 を固める |
| 5 | 4.0 ACL、NAT、L2セキュリティ、AAA | 設定問題が多い |
| 6 | 5.0 SNMP、syslog、Ansible、AI | 暗記中心。最後でよい |

- サブネット計算は毎日解く。1問30秒が目安
- 設定コマンドは Packet Tracer で打って確認する。読んだだけでは定着しない
- 各テキストを読んだら、対応する問題ファイルを解く。間違えた問題はテキストの該当節に戻る
