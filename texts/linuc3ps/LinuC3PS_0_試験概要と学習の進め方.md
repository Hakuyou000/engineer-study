# LinuC 3PS 0 試験概要と学習の進め方

作成: 2026-11-25
対象: LinuC レベル3 3PS 試験(プラットフォームスペシャリスト、Version 1.0)

LinuC レベル3 は、2025 年 12 月 1 日に 2 つの認定に変わりました。3PS(プラットフォームスペシャリスト)と 3SS(セキュリティスペシャリスト)です。3PS 試験は、仮想化の基盤、仮想のネットワークと分散ストレージ、コンテナ、カーネルパラメーターによる最適化、高可用性の構成、構築と運用の自動化を扱います。複数のサーバーを組み合わせて、止まりにくく、作り直しやすい基盤を作るための試験です。

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 試験 | LinuC レベル3 3PS 試験(Version 1.0) |
| 試験時間 | 90 分(試験の後のアンケートの 5 分を含む) |
| 問題の数 | 約 60 問 |
| 形式 | 選択式と、コマンド名などを入力する問題【要確認】 |
| 受験料 | 27,500 円(税込、1 試験あたり)【要確認】 |
| 会場 | ピアソン VUE のテストセンター、またはオンライン |
| 認定の条件 | 有効な LinuC レベル2 の認定を持ち、3PS 試験か 3SS 試験のどちらか 1 つに合格する |
| 言語 | 日本語(英語版は 2026 年春に始まる予定と発表されていた)【要確認】 |

> **【要確認】** 試験時間、問題の数、受験料は、2025 年 11 月の発表の記事で確かめた値です。出題の形式は公式の資料で確かめられていません。申し込む前に、LinuC 公式のページで確認してください。

### 以前の試験との関係

以前のレベル3 は、300 試験(混在環境)、303 試験(セキュリティ)、304 試験(仮想化と高可用性)の 3 つでした。これらは 2026 年 11 月 30 日に配信を終えます。3PS は、304 試験の仮想化と高可用性に、コンテナ、分散ストレージ、自動化を加えた範囲です。

## 2. 出題の分野と重要度

| 主題 | 重要度の合計 |
|---|---|
| 1.0 仮想化基盤の構築 | 13 |
| 2.0 仮想化基盤のネットワークとストレージ | 10 |
| 3.0 コンテナ技術の利用 | 7 |
| 4.0 プラットフォームの最適化 | 6 |
| 5.0 高可用性プラットフォームの構築 | 10 |
| 6.0 プラットフォームの運用管理 | 14 |

重要度は、小項目ごとに示された値の合計です。6.0 と 1.0 が大きいので、ここを先に固めます。小項目では、2.1(仮想のネットワーク)、2.3(Ceph)、3.2(コンテナの操作)、5.1(ロードバランサー)の重要度が 4 で最も大きくなっています。

## 3. 前提の知識

LinuC レベル2(201 試験と 202 試験)の範囲です。特に次のものを使います。

- KVM と virsh の基本、コンテナの基本(LinuC 201 2.05、2.06)
- LVM、RAID、ファイルシステム(LinuC 201 2.02)
- ネットワークの設定とブリッジ、ボンディングの考え方(LinuC 201 2.03)
- Ansible と監視の基本(LinuC 201 2.04)
- Apache と nginx、プロキシ(LinuC 202 2.09)
- 高可用と負荷分散の考え方(LinuC 202 2.13)

Docker と Terraform のテキストも、3.0 と 6.0 の前提として役に立ちます。

## 4. 学習の進め方

1. **演習環境を作る**(次の章)。3PS 試験は、複数台のサーバーを組み合わせる構成を問うので、3 台以上の仮想マシンを用意します。
2. **1.0 と 2.0 から読む**。仮想マシン、仮想のネットワーク、ストレージは、ほかの主題の土台になります。
3. **5.0 は、設定ファイルを実際に書いて、1 台を止めて確かめます。** フェイルオーバー(片方が止まったときに、もう片方が引き継ぐこと)は、止めてみないと分かりません。
4. **4.0 は、パラメーターの名前と、上げると何が起きるかをセットで覚えます。** 名前を思い出す入力問題が出やすいところです。
5. **6.0 は、同じ構成を何度も作り直す練習をします。** Ansible、OpenTofu、cloud-init で作り、Git で管理します。
6. **問題を解く**。入力で解くモードで、ディレクティブやパラメーターの名前を思い出す練習もします。

## 5. 演習環境の作り方

LinuC 201 と同じ仮想マシンを使います。作り方は LinuC 102 0 の「演習環境の作り方」と、LinuC 201 0 の注意を読んでください。3PS 試験に関係する注意だけをまとめます。

- **入れ子の仮想化が必要です。** 1.0 の KVM、QEMU、Proxmox VE は、仮想マシンの中で動かすことになります。ホスト側で入れ子の仮想化(nested virtualization)を有効にします。用意が難しければ、Linux を直接入れた PC を使います。
- **メモリは合わせて 16 GB 以上あると楽です。** Ceph(2.3)とクラスタ(5.3)は 3 台構成が基本です。1 台あたり 2〜4 GB を割り当てます。
- **Ceph には、空のディスクを各台に 1 本ずつ追加します。** OSD(データを置く役割)が使います。
- **ネットワークは、仮想マシンだけの内部ネットワークを作ります。** VRRP(仮想の IP アドレスを複数のサーバーで受け持つ仕組み)や VLAN の練習で、家のネットワークに影響を出さないためです。
- **PCI パススルーと SR-IOV(1.1、2.1)は、仮想マシンの中では試しにくいです。** 対応した物理の機器がなければ、設定の書き方と確かめ方だけを学びます。
- **IP アドレスとドメイン名は文書用の値を使います。** IP アドレスは `192.0.2.0/24`、`198.51.100.0/24`、ドメイン名は `example.com` などです。
- 練習の前に仮想マシンのスナップショットを取り、壊したら戻します。
