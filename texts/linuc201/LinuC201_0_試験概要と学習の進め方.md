# LinuC 201 0 試験概要と学習の進め方

作成: 2026-11-25
対象: LinuC レベル2 201 試験

LinuC レベル2は、201 試験と 202 試験の両方に合格し、有効な LinuC レベル1 の認定を持っていると認定されます。201 試験は、システムの起動とカーネル、ファイルシステムと LVM、ネットワークの設定と切り分け、保守と監視、仮想マシンとコンテナを扱います。レベル1 で覚えたコマンドを、サーバーの運用の場面で使いこなす試験です。

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 試験 | LinuC レベル2 201 試験 |
| 試験時間 | 90 分 |
| 問題の数 | 60 問前後 |
| 形式 | 選択式(1 つを選ぶ、複数を選ぶ)と、コマンド名などを入力する問題 |
| 受験料 | 16,500 円(税込、1 試験あたり)【要確認】 |
| 会場 | ピアソン VUE のテストセンター、またはオンライン |
| 認定の条件 | 有効な LinuC レベル1 の認定を持ち、201 試験と 202 試験の両方に合格する(順番は問わない) |

> **【要確認】** 公式の出題範囲のページ(英語版)には、201 試験の版が書かれていません(202 試験は Version 10.0)。受験料と受験の規則も変わることがあります。申し込む前に、LinuC 公式のページで確認してください。

## 2. 出題の分野と重要度

| 主題 | 重要度の合計 |
|---|---|
| 2.01 システムの起動とLinuxカーネル | 14 |
| 2.02 ファイルシステムとストレージ管理 | 10 |
| 2.03 ネットワーク構成 | 9 |
| 2.04 システムの保守と運用管理 | 18 |
| 2.05 仮想化サーバー | 6 |
| 2.06 コンテナ | 5 |

重要度は、小項目ごとに示された値の合計です。2.04 と 2.01 が大きいので、ここを先に固めます。

2.04.2(バックアップとリストア)は、公式のページの詳しい説明が 2.04.1 と同じ文になっています。このアプリでは、以前の版(V5)の出題範囲の用語(dd、tar、mt、rsync、テープの装置ファイル、差分と増分)で問題を作っています。

## 3. 前提の知識

LinuC レベル1(101 試験と 102 試験)の範囲です。特に次のものを使います。

- ファイルとディレクトリの操作、パーミッション(LinuC 101 1.02)
- パーティションとファイルシステムの基本(LinuC 101 1.05)
- systemd と起動の流れ(LinuC 101 1.01)
- IP アドレスとサブネット、ip コマンド(LinuC 102 1.07)
- ログと journalctl(LinuC 102 1.09)

## 4. 学習の進め方

1. **演習環境を作る**(次の章)。201 試験は、設定を変えて結果を確かめる操作が多いので、壊してよい仮想マシンで手を動かします。
2. **2.01 と 2.02 から読む**。起動の流れとディスクの扱いは、ほかの主題の前提になります。
3. **2.04 は小項目が 6 つある**ので、1 日に 1〜2 個ずつ進めます。監視(2.04.5)と構成ツール(2.04.6)は、コマンドより考え方を問います。
4. **2.03 は 102 の 1.07 と続けて読む**と、切り分けの流れがつながります。
5. **問題を解く**。入力で解くモードで、コマンド名とオプションを思い出す練習もします。

## 5. 演習環境の作り方

102 試験と同じ仮想マシンを使います。作り方は LinuC 102 0 の「演習環境の作り方」を読んでください。201 試験に関係する注意だけをまとめます。

- **AlmaLinux 9 と Ubuntu 24.04 の 2 台を用意します。** GRUB の設定のコマンド(grub2-mkconfig と grub-mkconfig)やネットワークの設定ファイルの場所が、Red Hat 系と Debian 系で違います。
- **カーネルとブートローダー(2.01)は、必ず仮想マシンで試します。** 試す前にスナップショットを取ります。カーネルのコンパイルには、数 GB の空きディスクと 30 分以上の時間がかかります。
- **ディスク(2.02)は、空のディスクを 2〜3 本追加します。** LVM の物理ボリュームを複数作る練習に使います。今使っているディスクのパーティションは変えないでください。
- **ネットワーク(2.03)は、仮想マシンに NIC を 2 つ付けます。** 1 台をルーターにして、IP 転送の練習ができます。
- **仮想化(2.05)は、入れ子の仮想化が必要です。** 仮想マシンの中で KVM を動かすには、ホスト側で入れ子の仮想化(nested virtualization)を有効にします。用意が難しければ、Linux を直接入れた PC か、クラウドの入れ子の仮想化に対応したインスタンスを使います。
- **コンテナ(2.06)** は、Docker のテキストの「演習環境の作り方」で Docker を入れられます。
- **構成ツール(2.04.6)** は、2 台の仮想マシンの片方に Ansible を入れ、もう片方を SSH で操作します。
