# ITパスポート 0 試験概要と学習の進め方

作成: 2026-11-25
対象: ITパスポート試験(情報処理推進機構 IPA が実施する国家試験)

ITパスポート試験は、仕事や生活で IT を使う、すべての社会人と学生に向けた入門の試験です。IT エンジニアだけでなく、営業、企画、事務など、どんな職種の人も対象です。経営や業務の考え方、データと AI の使い方、情報セキュリティや法律のルールまで、IT を安全に使いこなすための基礎が問われます。

## 1. 試験の制度が変わります

IPA は、2027 年度から新しい試験制度に移る予定を公表しています。ITパスポート試験は、2027 年度の春ごろから新制度になる予定です。現行の制度は、2026 年度の試験で終わる予定です。

このアプリの教材は、**新しい制度のシラバス案(Ver.0.1)**に合わせて作っています。シラバスとは、試験で問われる内容を細かく書いた資料です。

> **【要確認】** シラバス案 Ver.0.1 は 2026 年 8 月 31 日に掲載されたもので、今後変わる可能性があると IPA が注記しています。申し込む前に、IPA の公式のページで最新のシラバスを確認してください。

## 2. 試験の概要

### 2.1 新しい制度(2027 年度から予定)

| 項目 | 内容 |
|---|---|
| 試験時間 | 120 分 |
| 問題の数 | 100 問 |
| 分野 | 「ビジネス」「テクノロジ」「セキュリティ・倫理」の 3 つに整理し直す |
| 新しく加わる内容 | DX(デジタルトランスフォーメーション)のマインド・スタンスと、データマネジメントの基礎 |
| 強まる内容 | AI の時代のセキュリティと倫理 |
| 実施の方法 | すべての区分を CBT(コンピューターを使った試験)で行う。通年で実施する |

試験時間と問題の数は、IPA の「情報処理技術者試験及び情報処理安全確保支援士試験の見直しの検討状況について」(https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)で確かめました。

> **【要確認】** 新制度の合格の基準と、採点の詳しい方法は、このアプリを作った時点では公表を確かめていません。IPA の公式のページで確認してください。

### 2.2 現行の制度(2026 年度の試験まで)

| 項目 | 内容 |
|---|---|
| 試験の要綱 | Ver.5.6。現行のシラバスは Ver.6.5(https://www.ipa.go.jp/shiken/syllabus/gaiyou.html で確認) |
| 試験時間 | 120 分 |
| 問題の数 | 100 問。総合評価に使うのは 92 問で、残りの 8 問は評価に使わない。分野別評価に使うのは、ストラテジ系 32 問、マネジメント系 18 問、テクノロジ系 42 問 |
| 形式 | 四肢択一(4 つの選択肢から 1 つを選ぶ) |
| 採点 | IRT(項目応答理論)。解答結果から、問題ごとの難しさなどの特性を考えて、評価点を算出する方法。正解の数をそのまま点数にする方法(素点方式)ではない |
| 合格の基準 | 総合評価点が 600 点以上(1,000 点満点)で、かつ分野別評価点(ストラテジ系、マネジメント系、テクノロジ系。それぞれ 1,000 点満点)がそれぞれ 300 点以上 |
| 分野 | ストラテジ系、マネジメント系、テクノロジ系 |

### 2.3 新旧の違い

| | 現行 | 新制度(予定) |
|---|---|---|
| 分野の分け方 | ストラテジ系、マネジメント系、テクノロジ系 | ビジネス、テクノロジ、セキュリティ・倫理 |
| 新しい内容 | | DX のマインド・スタンス、データマネジメントの基礎 |
| 強まる内容 | | AI の時代のセキュリティと倫理 |
| 実施 | 通年の CBT | 全区分を CBT で、通年で実施 |

「会社の経営の話」「システムの話」「安全に使うルール」を学ぶ点は、新旧で大きくは変わりません。ただし、AI とデータの話が、はっきり表に出てきます。

## 3. このアプリの章立て

新制度のシラバス案は、内容を「大分類」と「中分類」に分けています。このアプリでは、**大分類を章、中分類を小項目**にします。章の番号は大分類の番号と同じです。5 章(システムの開発・運用)は、基本情報技術者試験だけの分野なので、ITパスポートにはありません(欠番です)。

| 章 | 大分類 | テキスト |
|---|---|---|
| 1 | ビジネス変革 | ITパスポート テキスト 1.0 |
| 2 | データ・AI の利活用 | ITパスポート テキスト 2.0 |
| 3 | 組織活動 | ITパスポート テキスト 3.0 |
| 4 | デジタル技術 | ITパスポート テキスト 4.0 |
| 6 | セキュリティ | ITパスポート テキスト 6.0 |
| 7 | 倫理・コンプライアンス | ITパスポート テキスト 7.0 |

1 章の小項目は、次の 7 つです。

| 小項目 | 内容 |
|---|---|
| 1.1 | ビジネス変革の方法論(社会の変化、イノベーション、チェンジマネジメント) |
| 1.2 | 経営戦略・デジタル戦略 |
| 1.3 | ビジネスモデル・ビジネスプロセス(分析の手法、マーケティング、ブランディングを含む) |
| 1.4 | サービスマネジメント |
| 1.5 | プロジェクトマネジメント |
| 1.6 | デザインのアプローチ |
| 1.7 | マインド・スタンス(新しく加わった内容。アジャイルなふるまいを含む) |

## 4. 前提の知識

- 前提はありません。IT の知識がなくても学べます。
- 学ぶときは、言葉を覚えるだけで終わらせないことが大切です。「自分の仕事ならどう使うか」を、1 つ考えてみます。
- 英字の略語(SWOT、KPI、SLA など)が多く出ます。略語は、正式な名前と、日本語の意味をセットで覚えます。

## 5. この試験で問われること

ITパスポートは、深い技術よりも、**用語の意味を正しく理解し、場面に当てはめられるか**が問われます。

| よく問われる観点 | 例 |
|---|---|
| 用語の意味 | 「SWOT 分析」は何を整理する手法か |
| 似た用語の違い | プッシュ戦略とプル戦略、プロダクトイノベーションとプロセスイノベーション |
| 場面への当てはめ | 次の状況で使うのは、どの手法か |
| 簡単な計算 | 損益、確率、稼働率、アローダイアグラムの所要日数など |
| ルールと責任 | 法律の名前、誰がどんな責任を持つか |

## 6. 学習の進め方

1. **まず 0 章を読む**: 試験の全体と、新旧の違いをつかみます。
2. **章の順に読む**: 1 章から読みます。1 章は経営と業務の考え方で、あとの章の土台になります。
3. **問題を解く**: 各章の問題を解き、間違えた問題は、テキストの同じ番号の節に戻ります。
4. **用語集を使う**: 知らない用語は、用語集で調べます。
5. **公式の資料で仕上げる**: IPA の公式のページで、最新のシラバスと、公開されている過去問題に目を通します。このアプリの問題は、すべてオリジナルです。

## 7. 用語の対応

| 言葉 | このテキストでの言い方 |
|---|---|
| シラバス | 試験の出題範囲を細かく書いた資料 |
| 大分類、中分類 | このアプリでは、大分類が章、中分類が小項目 |
| 用語例 | シラバスが、各項目で挙げている用語の例 |
| IRT | 項目応答理論。解答結果から、問題ごとの難しさなどの特性を考えて評価点を算出する採点の方法。素点方式ではない |
| CBT | コンピューターを使って受ける試験の方式 |

## 8. 演習の進め方

ITパスポートは、特別な環境を作らなくても学べます。日常や仕事の場面と結び付けると、覚えやすくなります。

- **身近な会社を分析する**: 自分が使っているサービスや、勤め先を 1 つ選び、SWOT 分析(1.2)や 3C 分析(1.3)の表を、紙に書いてみます。
- **ニュースを分類する**: 新しい製品やサービスのニュースを見たら、「プロダクトイノベーションか、プロセスイノベーションか」「サブスクリプションモデルか、広告モデルか」のように分けます。
- **小さな計画を作る**: 旅行や引っ越しのような身近な予定で、作業を分け(WBS)、順番と日数を書き出し(アローダイアグラム)、いちばん長い道すじを探します。
- **アジャイルを試す**: 1 週間を 1 つのスプリントとし、やることを小さく決め、最後に 5 分、ふりかえり(KPT)をします。
- **時間を計って解く**: 試験は 120 分で 100 問です。1 問あたり、およそ 1 分 12 秒です。問題集を解くときも、時間を計ります。
