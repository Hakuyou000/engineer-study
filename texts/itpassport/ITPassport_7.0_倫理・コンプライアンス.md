# ITパスポート テキスト 7.0 倫理・コンプライアンス

情報倫理と AI 倫理、仕事に関わる法律を学びます。法律は、条文の細かいところよりも、何を守る法律か、何をすると違反になるかを押さえます。出題範囲は、2027 年度からの新しい試験制度のシラバス案(Ver.0.1)に合わせています。

## 7.1 情報倫理・AI 倫理

### 1. 情報倫理・情報モラル

| 用語 | 内容 |
|---|---|
| デジタルシティズンシップ | デジタル技術を、責任を持って、安全かつ倫理的に使い、社会に参加する考え方や能力 |
| ネチケット(ネットマナー) | インターネット上で、相手に配慮して守る礼儀や作法 |
| 撮影時・録音時・配信時の同意 | 写る人、話す人の権利にかかわる。目的と範囲を伝えて、同意を得る |
| デジタルタトゥー | 一度公開した情報が、拡散や複製によって、消えにくく、長く残ること |
| ヘイトスピーチ | 特定の人種や国籍などの人々への、差別や憎悪をあおる発言 |

**同報メールの適切な利用**です。

| 欄 | 使い方 |
|---|---|
| TO | 主な宛先。他の受信者にも見える |
| CC | 参考として写しを送る宛先。他の受信者にも見える |
| BCC | 他の受信者に見えない宛先。互いのアドレスを知られたくないときに使う |
| メーリングリスト | 登録したメンバー全員に配信する仕組み。返信が全員に届くことがある |

**メール誤送信**を防ぐには、送信前に、宛先と添付ファイルを確認します。似た名前への自動補完にも注意します。誤りに気づいたら、すぐに相手と担当部署に知らせます。

**データの不正**です。

| 用語 | 内容 |
|---|---|
| ねつ造 | 実際にはないデータや結果を、でっち上げる |
| 改ざん | 実際にあるデータを、都合よく書き換える |
| 盗用 | 他人のアイデアや文章を、出典を示さずに、自分のものとして使う |

### 2. 情報の真偽と偏り

| 用語 | 内容 |
|---|---|
| フェイクニュース | 事実と異なる、偽のニュース |
| ファクトチェック | 情報の真偽を、複数の信頼できる情報源で確かめる |
| エコーチェンバー | 似た意見の人どうしで交流するうちに、同じ意見が反響して強まる現象 |
| フィルターバブル | アルゴリズムが、好みに合う情報ばかりを表示し、異なる意見に触れにくくなる現象 |
| 偽情報(ディスインフォメーション) | 人をだます意図をもって、意図的に作られた、誤った情報 |
| 誤情報(ミスインフォメーション) | 悪意はなく、間違って広まる、誤った情報 |
| 悪意ある情報(マルインフォメーション) | 内容は事実だが、人を傷つけたり困らせたりする目的で、公開される情報(私生活の暴露など) |

### 3. 判断の難しさと、子どもの保護

- **トロッコ問題**: どちらを選んでも犠牲が出る状況で、どう判断すべきかを問う、倫理の思考実験です。自動運転車の判断の議論などで、よく例に挙がります。
- **フィルタリング**: 有害なサイトなどを閲覧できないように、閲覧できる範囲を制限する仕組みです。
- **ペアレンタルコントロール**: 保護者が、子どもの端末の利用時間や、使えるアプリを制限する機能です。

### 4. AI 倫理・AI ガバナンス

| 用語 | 内容 |
|---|---|
| 説明可能な AI(XAI) | AI の結果について、理由を人が理解できるように説明できる AI |
| ヒューマンインザループ(HITL) | AI の判断や出力の過程に、人が関わり、確認や修正をする考え方 |
| AI サービスのオプトアウトポリシー | 入力した情報を、AI の学習に使うかどうかを、利用者が拒否できるようにする方針や設定 |

### 5. AI のリスク・脅威

- **ハルシネーション**: 生成 AI が、事実ではない内容を、もっともらしく出力する現象です。
- **セキュリティ・プライバシーへの懸念**: 個人情報や社外秘の情報を入力すると、学習に使われたり、漏れたりするおそれがあります。
- **信頼性の課題**: 出力が、古い情報に基づくことがあります(古い出力情報)。根拠や出典が分からない出力もあります。同じ質問をしても、毎回同じ出力になるとは限りません(再現性・一貫性の欠如)。
- **倫理・法的リスク**: 学習したデータの偏りによる、差別的な表現や判断があります。他人の著作物に似た出力を、そのまま公開すると、著作権の侵害になるおそれもあります。
- **フロンティア AI**: 最先端の、高い能力を持つ汎用の AI です。サイバー攻撃などへの悪用や、制御の難しさなどのリスクが議論されています。
- **ディープフェイク**: AI で作った、実在する人の顔や声に似せた、偽の動画や音声です。
- **悪意ある情報**: AI は、偽の情報や、人をだます文章を、大量に作るのにも使われます。

出力は、人が確かめてから使います。

## 7.2 ビジネス関連法規

### 1. 知的財産権

**著作権法**: 著作物を創作した時点で、著作権が自動的に発生します。登録は要りません。原則として、著作者の死後 70 年まで保護されます。

- プログラム(ソースプログラム、実行形式)は、著作物です。処理の手順や解法(アルゴリズム)、プログラム言語、規約は、保護されません。
- **引用**: 公表された著作物を、公正な慣行に合わせ、引用の目的上、正当な範囲で使い、出所を明示すれば、許可なく使えます。自分の文章が主で、引用が従である必要があります。

**産業財産権**は、特許庁に出願して、登録されて発生します。

| 法律 | 保護する対象 | 期間(原則) |
|---|---|---|
| 特許法 | 自然法則を利用した、技術的に高度で新しい発明 | 出願から 20 年 |
| 実用新案法 | 物品の形状、構造、組合せに関する、小さな考案 | 出願から 10 年 |
| 意匠法 | 物品の形状、模様、色彩などの、独創的な見た目のデザイン | 出願から 25 年 |
| 商標法 | 商品やサービスの目印(文字、図形、記号など) | 登録から 10 年(更新できる) |

- **ビジネスモデル特許**: 新しいビジネスの方法が、ICT を使って実現される場合に、その仕組みが特許になるものです。
- 商標のうち、商品に付ける目印を**トレードマーク**、サービス(役務)に付ける目印を**サービスマーク**といいます。

知的財産権のうち、著作権と産業財産権の分け方を、木の形で表した図です。

```text
知的財産権
  |
  +-- 著作権(著作権法): 創作した時点で、自動的に発生する。登録は要らない
  |
  `-- 産業財産権: 特許庁に出願して、登録されて発生する
        |
        +-- 特許(特許法): 技術的に高度で新しい発明
        +-- 実用新案(実用新案法): 物品の形状、構造、組合せに関する、小さな考案
        +-- 意匠(意匠法): 独創的な見た目のデザイン
        `-- 商標(商標法): 商品やサービスの目印
```

### 2. 不正競争防止法

事業者間の公正な競争を守る法律です。不正な競争を規制します。

- **営業秘密**は、次の 3 要件を満たす情報です。顧客名簿や製造のノウハウなどが当たります。
  - 秘密管理性: 秘密として管理されている
  - 有用性: 事業活動に役立つ
  - 非公知性: 公然と知られていない
- **限定提供データ**: ID やパスワードなどで管理し、業として特定の相手に提供する、相当量が蓄積されたデータです。営業秘密に当たるものは除かれ、営業秘密とは別に保護されます(令和5年の改正で、秘密として管理していても、営業秘密に当たらなければ対象になりました)。

### 3. 労働関連法規

| 法律 | 内容 |
|---|---|
| 労働基準法 | 労働時間や賃金などの、労働条件の最低の基準を定める |
| 労働契約法 | 労働契約の基本的なルールを定める |
| 労働安全衛生法 | 職場における、労働者の安全と健康を守る |
| 労働施策総合推進法(パワハラ防止法) | 職場のパワーハラスメントを防ぐ措置を、事業主に義務付ける |
| 男女雇用機会均等法 | 雇用における性別による差別を禁止する。セクシュアルハラスメントの防止も定める |
| 育児・介護休業法 | 子どもの養育や家族の介護のための、休業を申し出られる権利を定める |
| 公益通報者保護法 | 勤務先の不正を通報した労働者を、解雇などの不利益から保護する |

**労働基準法の関連用語**です。

- **36 協定**: 法定の労働時間を超える、時間外労働と休日労働のために、使用者と労働者の代表が結び、労働基準監督署に届け出る協定です。時間外労働には上限があり、原則は、月 45 時間、年 360 時間です。
- **裁量労働制**: 仕事の進め方や時間配分を、労働者の裁量に任せ、実際の時間にかかわらず、あらかじめ決めた時間(みなし労働時間)を働いたものとみなす制度です。
- **フレックスタイム制**: 一定の期間の総労働時間を決め、その範囲で、始業と終業の時刻を、労働者が決める制度です。

**労働者派遣法の関連用語**です。

- **雇用契約**: 派遣労働者と、派遣元の間の契約です。
- **派遣契約**: 派遣元と、派遣先の間の契約です。
- **指揮命令**: 仕事の指示は、派遣先がします。
- **偽装請負**: 請負契約の形をとりながら、発注者が、請負会社の従業員に、直接指示して働かせる状態です。違法です。
- **二重派遣の禁止**: 派遣された労働者を、派遣先が、さらに別の企業に派遣することは、禁止されています。

### 4. 取引関連法規

| 法律 | 内容 |
|---|---|
| 中小受託取引適正化法(取適法) | 発注する側が、立場の弱い中小の受託事業者に、代金の減額や支払いの遅れなどの不当な扱いをすることを禁じる。下請法を改正し、名称を変えた法律 |
| 民法 | 契約などの、民事の基本のルールを定める |
| 特定商取引法 | 訪問販売、通信販売、電話勧誘販売など、トラブルが起きやすい取引を規制し、消費者を守る。クーリング・オフの制度があるが、通信販売には、ない |
| 特定デジタルプラットフォームの透明性及び公正性の向上に関する法律 | 大規模なオンラインモールやアプリストアの運営事業者に、取引条件の開示などを求める |
| 資金決済法 | 電子マネーなどの前払式支払手段、資金移動業、暗号資産の交換業などを定める |
| 景品表示法 | 実際より著しく優良だと誤認させる表示(優良誤認)や、有利だと誤認させる表示(有利誤認)、過大な景品類を規制する |

**民法の契約**です。

- **契約の基礎**: 契約は、当事者の意思が合致すれば、成立します。契約書は、成立の条件ではなく、後の争いを防ぐ証拠です。
- **売買契約の成立**: 売主と買主の意思が合致した(申込みと承諾がそろった)時点で成立します。代金の支払いや、商品の引き渡しは、成立の後の義務です。
- **請負契約**: 仕事の完成を約束し、完成した成果物に対して、報酬を受け取る契約です。成果物に不具合があれば、契約不適合責任を負います。
- **準委任契約**: 業務を行うこと自体を委託し、成果物の完成までは約束しない契約です。システム開発の要件定義などで使われます。

**企業間の取引に関わる契約**です。

| 契約 | 内容 |
|---|---|
| 外部委託契約 | 業務を外部に委託する契約。請負契約や準委任契約で結ぶ。範囲、成果物、費用、秘密の保持などを定める |
| 守秘契約(NDA) | 開示された秘密の情報を、目的以外に使わず、第三者に漏らさないことを約束する |
| ソフトウェア使用許諾契約(ライセンス契約) | 著作権者が、利用者に、使える範囲や条件を認める。購入しても、著作権は移らない |
| ボリュームライセンス契約 | 組織が、同じソフトウェアを多数の端末で使うために、まとめて結ぶ |

### 5. 環境関連法規

- **リサイクル法**: 使い終わった製品や容器などを回収し、資源として再び利用することを促す法律の総称です。
- **GX 推進法**: GX は、グリーントランスフォーメーションです。脱炭素と経済成長の両立を目指し、脱炭素成長型の経済構造への移行を進めます。

### 6. その他デジタル関連法規

| 法律 | 内容 |
|---|---|
| デジタル社会形成基本法 | デジタル社会の形成の基本理念などを定める |
| 官民データ活用推進基本法 | 国や地方公共団体、民間が持つデータの利活用を進める |
| 人工知能関連技術の研究開発及び活用の推進に関する法律(AI 基本法) | AI の研究開発と活用を推進するための、基本的な事項を定める |

## 7.3 プライバシー関連法規

### 1. 個人情報保護法

個人情報の有用性に配慮しながら、個人の権利と利益を守る法律です。個人情報を取り扱う事業者(個人情報取扱事業者)に、義務を課します。取り扱う件数が少ない事業者も対象です。所管は、個人情報保護委員会です。

| 用語 | 内容 |
|---|---|
| 個人情報 | 生存する個人に関する情報で、特定の個人を識別できるもの。氏名と住所の組など。他の情報と簡単に照らし合わせて、識別できるものも含む |
| 個人識別符号 | その情報だけで、特定の個人を識別できるとして定められたもの。運転免許証の番号、パスポートの番号、マイナンバー、指紋や顔の特徴を表すデータなど。携帯電話の番号、クレジットカードの番号、メールアドレスは、当たらない |
| 要配慮個人情報 | 人種、信条、社会的身分、病歴、犯罪の経歴、犯罪の被害を受けた事実など、不当な差別や偏見が生じるおそれのある情報。取得には、原則として、本人の同意が必要 |
| 個人データ | 検索できるように体系的に整理された個人情報(個人情報データベース等)を構成する個人情報 |
| 保有個人データ | 事業者が、本人からの開示、訂正、利用停止などの請求に応じる権限を持つ個人データ |
| 匿名加工情報 | 特定の個人を識別できないように加工し、元に戻せないようにした情報。一定のルールで、本人の同意なく、第三者に提供できる |

個人情報、個人データ、保有個人データの包含の関係を表した図です。

```text
個人情報
  |
  `-- 個人データ: 検索できるように体系的に整理された個人情報
        |
        `-- 保有個人データ: 事業者が、本人の請求に応じる権限を持つもの
```

下に進むほど、範囲が狭くなります。

事業者の主な義務です。

- 利用目的をできる限り特定し、その範囲内で取り扱います。範囲を超えて使うときは、本人の同意が必要です。
- 個人データを第三者に提供するときは、原則として、本人の同意が必要です(第三者提供)。
- 一定の漏えいなどが起きたときは、個人情報保護委員会に報告し、本人に通知します。

### 2. マイナンバー法とマイナンバー制度

- **マイナンバー制度**: 住民票のある人に、1 人 1 つ、12 桁の番号(マイナンバー)を割り当てます。年齢に関係なく、外国籍の人も、住民票があれば対象です。
- **マイナンバー法**(行政手続における特定の個人を識別するための番号の利用等に関する法律): マイナンバーを使える範囲を、法律で定めた手続に限っています。社会保障、税、災害対策の 3 分野に加えて、令和5年の改正で、国家資格の登録や自動車の登録などの行政事務にも広がりました。民間企業も、税や社会保険の手続のために、従業員のマイナンバーを取り扱います。本人の同意があっても、範囲外には使えません。

### 3. 一般データ保護規則(GDPR)

**GDPR** は、EU(欧州連合)が定めた、個人データの保護に関する規則です。EU の域外の企業でも、EU の域内の人のデータを扱う場合は、適用されることがあります。違反すると、高額の制裁金が科されることがあります。

**忘れられる権利(消去権)**は、本人が、自分の個人データの消去を求められる権利です。GDPR で定められています。

### 4. プライバシー保護の手法

| 用語 | 内容 |
|---|---|
| オプトイン | あらかじめ本人が同意した場合にだけ、メールの送信や、データの提供を行う方式 |
| オプトアウト | 本人が拒否しない限り、第三者への提供などを認める方式。個人情報保護委員会への届出が必要。要配慮個人情報には使えない |
| 第三者提供 | 個人データを、他の事業者などに渡すこと。原則として、本人の同意が必要 |
| データマスキング | 個人を識別できる部分を、別の文字に置き換えたり、伏せたりする。本番のデータをテストに使うときなど |
| 同意の取得 | 目的外の利用、第三者提供、要配慮個人情報の取得などで、本人の同意を得る |

## 7.4 セキュリティ関連法規

### 1. 不正アクセス禁止法

不正アクセス行為などを禁止し、処罰する法律です。

- **アクセス制御機能**: 利用者 ID とパスワード、生体認証などで、利用者を確かめ、許可された人だけがシステムを使えるようにする機能です。
- **不正アクセス行為**: 他人の ID とパスワードを無断で使ったり、システムの脆弱性を突いたりして、アクセス制御機能を免れ、権限のない機能を使う行為です。
- **不正アクセス行為を助長する行為**: 他人の ID とパスワードを、不正アクセスに使われると知りながら、第三者に教えるなどの行為です。また、アクセス管理者を装い、ID とパスワードの入力を求める行為(フィッシング行為)も、禁止されています。

### 2. その他のセキュリティ関連法規

| 法律 | 内容 |
|---|---|
| 刑法(不正指令電磁的記録に関する罪、ウイルス作成罪) | 正当な理由なく、他人のコンピュータで、利用者の意図に反する動作をさせる目的で、ウイルスなどを作成、提供、保管する行為を処罰する。マルウェア対策や、許可を得た検査は、正当な理由がある |
| サイバーセキュリティ基本法 | サイバーセキュリティに関する、国の戦略と、国、地方公共団体、事業者などの責務を定める |
| 特定電子メール法 | 広告や宣伝のメールを、あらかじめ受信に同意した相手にだけ送ること(オプトイン)を、原則とする。送信者の氏名または名称と、受信を拒否するための連絡先を表示する義務がある。送信元の偽装は禁止 |
| サイバー対処能力強化法 | サイバー攻撃による被害を防ぐために、官民の連携を強め、政府の対処の能力を高める法律(いわゆる能動的サイバー防御)。正式な名前は、重要電子計算機に対する不正な行為による被害の防止に関する法律(令和7年法律第42号)。施行の日付は【要確認】 |
