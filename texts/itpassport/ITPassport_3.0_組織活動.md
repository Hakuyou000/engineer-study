# ITPassport テキスト 3.0 組織活動

企業や組織が、どう動き、お金と人をどう管理し、ルールが守られていることをどう確かめるかを学びます。シラバス案 Ver.0.1 の大分類 3 に当たります。

## 3.1 経営・組織論

### 1. 組織活動と経営資源

企業は、**経営資源**(人、物、金、情報)を使って、事業を行います。

- **人的資本経営**: 人を、コストではなく、投資して価値を高める**資本**としてとらえ、能力を引き出して、企業価値の向上につなげる経営です。
- **企業の社会的責任(CSR)**: 企業が、利益だけでなく、社会や環境に対して負う責任です。
- **株主総会**: 株主が集まって、取締役の選任など、重要な事項を決める、株式会社の**最高意思決定機関**です。
- **ディスクロージャー**: 企業が、経営や財務の情報を、投資家などに**開示する**ことです。
- **グリーン IT**: IT 機器の省電力化や、IT を使った環境負荷の低減など、IT による環境への負荷を減らす取り組みです。
- **カーボンフットプリント**: 商品の原材料の調達から廃棄・リサイクルまでの全体で排出される、温室効果ガスを、二酸化炭素に換算して表示する取り組みです。

### 2. 組織形態と組織・企業の特徴

- **株式会社**: 株式を発行して資金を集める会社です。出資者は株主で、出資した額の範囲で責任を負います。
- **株式公開(IPO)**: 株式を証券取引所に上場して、広く投資家が売買できるようにすることです。
- **IR(Investor Relations)**: 投資家に向けた広報活動です。経営や業績の情報を伝えます。
- **コーポレートブランド**: 企業そのものに対する、イメージや信頼です。

### 3. 経営管理・経営組織

経営の目標を決め(**経営目標**)、それを実現するための計画を立て(**経営計画**、**事業計画**)、実行し、見直します。財務、資産、人事、情報などを管理します。

- **PDCA**: 計画(Plan)、実行(Do)、評価(Check)、改善(Act)を繰り返して、業務を改善する考え方です。
- **OODA ループ**: 観察(Observe)、状況判断(Orient)、意思決定(Decide)、行動(Act)を素早く繰り返して、状況の変化に対応する考え方です。

#### 組織の形

| 組織 | 内容 |
|---|---|
| **階層型組織(ピラミッド型組織)** | 上から下へ、指揮命令が伝わる、階層の形の組織 |
| **職能別組織** | 営業、開発、製造など、機能ごとに部門を分ける |
| **事業部制組織** | 製品別や地域別に事業部を作り、権限と利益の責任を持たせる |
| **マトリックス組織** | 職能と、プロジェクトや製品の 2 つの軸で構成する。社員は 2 人の上司から指示を受ける |
| **カンパニー制組織** | 社内を、会社のように分けて、大きな権限を与える |
| **プロジェクト組織** | 特定の目的のために、期間を決めて作るチーム |
| **持株会社** | 他の会社の株式を保有して、グループ全体の経営を管理する会社(ホールディングス) |

#### CxO

経営の役割ごとの、最高責任者の呼び方です。

| 呼び方 | 責任の分野 |
|---|---|
| **CEO**(最高経営責任者) | 経営全般 |
| **CFO**(最高財務責任者) | 財務 |
| **CIO**(最高情報責任者) | 情報システムと、情報の活用 |

### 4. ヒューマンリソースマネジメント

| 用語 | 内容 |
|---|---|
| **OJT** | 職場で、実際の仕事を通じて行う教育 |
| **Off-JT** | 職場を離れて行う教育。集合研修やセミナー |
| **コーチング** | 対話によって、本人の気付きや自発的な行動を引き出す |
| **メンタリング** | 経験のある人が、助言や支援をして、成長を助ける |
| **リスキリング** | 新しい業務や職種に必要な知識やスキルを、学び直す |
| **アダプティブラーニング** | 学ぶ人の理解度に合わせて、内容や進め方を変える学習 |
| **アルムナイ** | 卒業生、退職した元社員。つながりを保って、再雇用や紹介につなげる |
| **リファラル採用** | 社員の紹介による採用 |
| **リテンション** | 人材を、会社に定着させること |
| **タレントマネジメント** | 人材の情報を一元的に管理して、育成や配置に生かす |
| **HR テック(HRTech)** | AI やクラウドなどの技術を、人事の業務に使う |
| **目標管理制度(MBO)** | 社員が自分で目標を設定し、上司と合意して、達成度を自分で管理し、評価を受ける(Management by Objectives and self-control) |
| **ワークエンゲージメント** | 仕事に対して、活力や熱意を持って、前向きに取り組む状態 |
| **ワークシェアリング** | 1 人当たりの労働時間を短くして、仕事を分け合い、雇用を維持したり増やしたりする |
| **DE&I** | 多様性(Diversity)、公平性(Equity)、包括性(Inclusion)を大切にする |
| **ウェルビーイング(well-being)** | 心と体と社会的に、よい状態にあること |

テレワークの形態は、次の 3 つです。

- **在宅勤務**: 自宅で働く
- **モバイルワーク**: 外出先や移動中など、場所を選ばずに働く
- **サテライトオフィス勤務**: 本社とは別の場所の施設(自社のサテライトオフィスや、シェアオフィス、コワーキングスペースなど)で働く

### 5. 売上と利益の関係

| 用語 | 内容 |
|---|---|
| **売上高** | 商品やサービスを売って得た金額(販売量 × 単価) |
| **原価** | 商品を作る、または仕入れるのにかかった費用(売上原価) |
| **粗利益** | 売上高 − 売上原価 |
| **営業利益** | 粗利益 − 販売費及び一般管理費。本業での利益 |
| **固定費** | 売上や販売量に関わらず、かかる費用(家賃、正社員の給与など) |
| **変動費** | 売上や販売量に比例して、増える費用(材料費など) |

**損益分岐点**は、利益がちょうど 0 になる、売上高(または販売量)です。これを超えると、利益が出ます。

- 損益分岐点の売上高 = 固定費 ÷ (1 − 変動費率)(変動費率 = 変動費 ÷ 売上高)
- 損益分岐点の販売量 = 固定費 ÷ (1 個当たりの販売価格 − 1 個当たりの変動費)

例: 固定費 300 万円、変動費率 40% なら、300 ÷ 0.6 = 500 万円です。

### 6. 決算の仕組み

決算は、一定の期間の、会社の成績と財産の状態をまとめる作業です。

- **決算短信**: 上場企業が、決算の内容を、いち早く投資家に知らせる、速報としての書類です。
- **有価証券報告書**: 金融商品取引法に基づいて、事業年度ごとに提出する、詳しい報告書です。

### 7. 財務諸表

| 財務諸表 | 内容 |
|---|---|
| **貸借対照表**(B/S) | ある時点の、資産、負債、純資産の状態 |
| **損益計算書**(P/L) | ある期間の、収益と費用、利益 |
| **キャッシュフロー計算書** | ある期間の、資金の増減。営業活動、投資活動、財務活動の 3 つの区分 |

貸借対照表は、**資産 = 負債 + 純資産** の関係になります。

| 区分 | 内容 |
|---|---|
| **流動資産** | 現金、預金、売掛金、商品など。1 年以内に現金になるもの |
| **固定資産** | 建物、設備、土地など。長く使うもの |
| **繰延資産** | 支払った費用のうち、将来の収益に対応させるために、資産として扱うもの |
| **流動負債** | 買掛金、短期の借入金など。1 年以内に支払うもの |
| **固定負債** | 長期の借入金など。支払いが 1 年を超えるもの |
| **純資産** | 資産から負債を引いた、返済の必要がない部分 |

### 8. 代表的な財務指標

| 指標 | 式 | 意味 |
|---|---|---|
| **売上高利益率** | 利益 ÷ 売上高 | 売上のうち、利益が占める割合 |
| **資本回転率** | 売上高 ÷ 資本 | 資本が、どれだけ効率よく売上になったか(回) |
| **総資産利益率(ROA)** | 利益 ÷ 総資産 | 総資産で、どれだけ利益を上げたか |
| **自己資本利益率(ROE)** | 当期純利益 ÷ 自己資本 | 株主の資金で、どれだけ利益を上げたか |
| **投資利益率(ROI)** | 利益 ÷ 投資額 | 投資した額に対する、利益の割合 |
| **流動比率** | 流動資産 ÷ 流動負債 | 短期の支払い能力。100% を超えると、短期の負債を流動資産で払える |
| **自己資本比率** | 自己資本 ÷ 総資本 | 返済の必要がない資金の割合。高いほど安定 |

割合は、100 をかけて % で表します。例: 当期純利益 60、自己資本 500 の ROE は、60 ÷ 500 × 100 = 12% です。

## 3.2 ガバナンス・監査

### 1. コーポレートガバナンス

- **コーポレートガバナンス**: 経営者の行動を、株主や社会の利益に沿うように、監視し、統制する仕組みです。
- **コンプライアンス**: 法令だけでなく、社内の規程や、社会の規範、倫理も守ることです。
- **ビジネスと人権**: 企業が、自社だけでなく、取引先を含む事業全体で、人権(強制労働や児童労働の禁止など)への悪い影響を調べ、防ぐ、または減らす責任を持つ、という考え方です。
- **ハラスメント**: 他人に不快感を与え、尊厳を傷つける言動です。職場のパワーハラスメントは、優越的な関係を背景に、業務上必要かつ相当な範囲を超えた言動で、就業環境を害するものです。事業主には、防止のための措置が義務付けられています。

### 2. 内部統制・デジタルガバナンス

**内部統制**は、組織が、業務を適正に行い、不正や誤りを防ぐために、組織の内部に作る仕組みです。

- **内部統制報告制度(J-SOX)**: 金融商品取引法に基づいて、上場企業などが、財務報告の信頼性を確保するための内部統制を整備し、その有効性を評価して、報告する制度です。

内部統制を作るときの要素の例です。

| 要素 | 内容 |
|---|---|
| **業務プロセスの明確化** | 業務の流れや担当者を、明らかにする |
| **職務分掌** | 業務を分担して、1 人に権限が集中しないようにする。申請、承認、支払いを、別の人が行う |
| **実施ルールの設定** | 承認の基準や、金額の上限などの、ルールを決める |
| **チェック体制の確立** | 上長の確認や、内部監査などで、確かめる仕組みを作る |

- **誤謬と不正**: **誤謬**は、意図しない誤り(計算の間違いなど)です。**不正**は、意図的な行為(横領、粉飾決算など)です。
- **3 つのラインモデル(Three Lines Model)**: 組織のリスク管理と統制を、3 つの役割で考えるモデルです。

| ライン | 役割 |
|---|---|
| **第 1 線** | 事業部門。日々の業務の中で、リスクを管理する |
| **第 2 線** | リスク管理やコンプライアンスの部門。第 1 線を支援し、監視する |
| **第 3 線** | 内部監査。独立した立場で、評価する |

### 3. 監査

**監査**は、独立した立場の人が、対象が基準に沿って適切に行われているかを、証拠に基づいて点検・評価することです。

#### 監査の形態

| 監査 | 内容 |
|---|---|
| **会計監査** | 財務諸表が、適正かを確かめる |
| **業務監査** | 業務が、法令や規程に沿って、適切に行われているかを確かめる |
| **システム監査** | 情報システムに関わるリスクへの対応を、独立かつ専門的な立場で検証・評価し、保証や助言を行う |
| **情報セキュリティ監査** | 情報セキュリティの管理に絞って、確かめる |
| **法定監査** | 法律で義務付けられた監査。上場会社の財務諸表について、公認会計士または監査法人が行う監査が例 |
| **任意監査** | 法律で義務付けられておらず、自主的に行う監査 |
| **内部監査** | 組織の内部の人が行う監査 |
| **外部監査** | 組織の外部の、独立した第三者が行う監査 |

#### システム監査の目的

**システム監査基準**(経済産業省)では、システム監査の目的を、情報システムに関わるリスクに適切に対応しているかを、独立かつ専門的な立場で検証・評価し、保証や助言をして、組織の目標の達成に役立てることとしています。

- **システム監査人の権限と責任**: 必要な情報を求める権限があり、結果を正しく報告する責任を負います。
- **独立性と客観性の保持**: 監査対象から、外観上も精神上も独立して、客観的な証拠に基づいて監査します。開発に関わった人が、そのシステムを監査すると、独立性を損ないます。

#### システム監査の実施

| 段階 | 内容 |
|---|---|
| **監査計画** | 監査の目的、対象、時期、手続を決める |
| **予備調査** | 監査の対象の概要を、つかむ |
| **本調査** | **監査証拠**(文書、記録、インタビューの内容、現場での確認の結果など)を集め、評価する |
| **監査報告** | **監査報告書**に、結果をまとめて報告する |
| **フォローアップ** | 指摘や**改善提案**が、実際に改善されたかを、あとで確かめる |
