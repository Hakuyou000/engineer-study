# LinuC 101 0 試験概要と学習の進め方

作成: 2026-11-19
対象: LinuC レベル1 101 試験(Version 10.0)

LinuC レベル1は、101 試験と 102 試験の両方に合格すると認定されます。101 試験は、Linux のインストールと起動、ファイルの操作、コマンドライン、パッケージの管理、ディスクとファイルシステムを扱います。Linux を使うための土台なので、102 試験より先に学ぶのがおすすめです。

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 試験 | LinuC レベル1 101 試験(Version 10.0) |
| 試験時間 | 90 分 |
| 問題の数 | 60 問前後 |
| 形式 | 選択式(1 つを選ぶ、複数を選ぶ)と、コマンド名などを入力する問題 |
| 受験料 | 16,500 円(税込、1 試験あたり) |
| 会場 | ピアソン VUE のテストセンター、またはオンライン |
| 認定の条件 | 101 試験と 102 試験の両方に合格する(順番は問わない) |

> **【要確認】** 受験料と受験の規則は変わることがあります。申し込む前に、LinuC 公式のページで確認してください。

## 2. 出題の分野と重要度

| 主題 | 重要度の合計 |
|---|---|
| 1.01 Linux のインストールと仮想マシン・コンテナの利用 | 16 |
| 1.02 ファイル・ディレクトリの操作と管理 | 10 |
| 1.03 GNU と Unix のコマンド | 15 |
| 1.04 リポジトリとパッケージ管理 | 8 |
| 1.05 ハードウェア、ディスク、パーティション、ファイルシステム | 11 |

重要度は、小項目ごとに 1〜10 で示された値の合計です。1.01 と 1.03 が大きいので、ここを先に固めます。

## 3. 前提の知識

特にありません。パソコンでファイルやフォルダを扱ったことがあれば始められます。キーボードで文字を打つことに慣れておくと、コマンドの練習が楽になります。

## 4. 学習の進め方

1. **演習環境を作る**(次の章)。101 試験はコマンドの名前とオプションをよく問うので、手で打って覚えます。
2. **1.03 から読む**と、ほかの主題のコマンドの例が読みやすくなります。その後、1.02、1.01、1.05、1.04 の順がおすすめです。
3. **問題を解く**。入力で解くモードで、コマンド名とオプションを思い出す練習もします。
4. 学習アプリ sre-drill の**計算ドリル**で、パーミッションと umask を毎日少しずつ解きます。

## 5. 演習環境の作り方

102 試験と同じ環境を使います。作り方は LinuC 102 0 の「演習環境の作り方」を読んでください。101 試験に関係する注意だけをまとめます。

- **ディスクとパーティション(1.05)は仮想マシンで試します。** WSL では fdisk、LVM、/etc/fstab の練習ができません。仮想マシンに 1〜2 GB の空のディスクを追加し、`/dev/sdb` などとして練習します。今使っているディスクのパーティションは変えないでください。
- **起動とシングルユーザーモード(1.01.3)も仮想マシンで試します。** GRUB の画面は WSL にはありません。
- **Debian 系と Red Hat 系の両方を使います(1.04)。** apt は Ubuntu、yum / dnf は AlmaLinux で試します。
- **仮想化(1.01.2)の virsh** は、KVM の入った Linux の上で試します。手元のパソコンでの用意が難しければ、コマンドの役割を覚えるだけでも十分です。docker は Docker のテキストの「演習環境の作り方」で入れられます。
- 練習の前に仮想マシンのスナップショットを取り、壊したら戻します。取り方は LinuC 102 0 の「5. 壊してもよいようにする(スナップショット)」に書いてあります。
