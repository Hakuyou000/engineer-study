# LinuC 101 テキスト 1.03 GNU と Unix のコマンド

コマンドラインの基本、テキストを加工するコマンド(フィルタ)、リダイレクトとパイプ、正規表現と grep、vi の操作を学びます。

## 1.03.1 コマンドラインの操作 (重要度4)

### 1. パス

| 種類 | 書き方 | 例 |
|---|---|---|
| 絶対パス | `/` から書く | `/home/sato/memo.txt` |
| 相対パス | 今いるディレクトリから書く | `memo.txt`、`../etc` |
| `.` | 今のディレクトリ | `./script.sh` |
| `..` | 1 つ上のディレクトリ | `cd ..` |
| `~` | ホームディレクトリ | `cd ~`、`~sato`(sato のホーム) |

`pwd` で今のディレクトリを表示します。`cd` だけを実行するとホームに、`cd -` で 1 つ前のディレクトリに戻ります。

今のディレクトリのプログラムを実行するときは、`./script.sh` のようにパスを付けます。PATH に `.` は入っていないので、`script.sh` だけでは見つかりません。

### 2. シェル変数と環境変数

| 種類 | 作り方 | 子プロセスに |
|---|---|---|
| シェル変数 | `NAME=value`(`=` の前後に空白を入れない) | 引き継がれない |
| 環境変数 | `export NAME=value`、または作ってから `export NAME` | 引き継がれる |

シェル変数と環境変数が、子プロセスに引き継がれるかどうかを図にします。

```text
[parent shell]
   NAME=sato              シェル変数
   export EDITOR=vim      環境変数
        |
        |  子プロセスを起動する
        v
[child process]
   $EDITOR  -> vim        引き継がれる
   $NAME    -> (empty)    引き継がれない(空になる)
```


| コマンド | 動き |
|---|---|
| `echo $NAME` | 値を表示する |
| `set` | シェル変数と環境変数(と関数)をすべて表示する |
| `env`、`printenv` | 環境変数だけを表示する |
| `unset NAME` | 変数を消す |
| `env NAME=value command` | その 1 回だけ環境変数を付けてコマンドを実行する |

主な環境変数は `PATH`(コマンドを探すディレクトリ。`:` で区切る)、`HOME`、`USER`、`SHELL`、`LANG`、`PS1`(プロンプト)です。

```bash
export PATH=$PATH:/opt/tools/bin     # PATH の後ろに追加する
```

### 3. 引用符

| 書き方 | 動き | 例(NAME=sato) |
|---|---|---|
| `'…'`(シングルクォート) | 中身をそのまま扱う。変数も展開しない | `echo '$NAME'` → `$NAME` |
| `"…"`(ダブルクォート) | 変数とコマンドの置き換えは行う。空白で分けない | `echo "$NAME"` → `sato` |
| `` `…` ``、`$(…)` | コマンドの置き換え(実行した結果に置き換える) | `echo "今日は $(date +%F)"` |
| `\` | 次の 1 文字の特別な意味を消す | `echo \$NAME` → `$NAME` |

### 4. 履歴

| 操作 | 動き |
|---|---|
| `history` | 履歴の一覧(番号付き) |
| `!!` | 直前のコマンドをもう一度 |
| `!15` | 履歴の 15 番 |
| `!ls` | `ls` で始まる直近のコマンド |
| `Ctrl+R` | 履歴を探す |

履歴はログアウトのときに `~/.bash_history` に保存されます。数は `HISTSIZE`(メモリの上)と `HISTFILESIZE`(ファイル)で決まります。

### 5. マニュアル

```bash
man ls          # ls のマニュアル
man 5 passwd    # セクション 5(ファイルの書式)の passwd
man -k crontab  # キーワードで探す(apropos と同じ)
```

| セクション | 内容 |
|---|---|
| 1 | 一般のユーザーのコマンド |
| 5 | 設定ファイルの書式 |
| 8 | 管理者のコマンド |

man の中では `/文字` で探し、`q` で終わります。

## 1.03.2 フィルタを使ったテキストストリームの処理 (重要度3)

### 1. 表示と行の取り出し

| コマンド | 動き | 例 |
|---|---|---|
| `cat` | 表示、つなげる。`-n` 行番号 | `cat a.txt b.txt > all.txt` |
| `less` | 1 画面ずつ表示する。`/` で探し、`q` で終わる | `less /var/log/messages` |
| `head` | 先頭(既定は 10 行)。`-n 5` | `head -n 5 file` |
| `tail` | 末尾。`-n 5`、`-f` で追いかける | `tail -f /var/log/messages` |
| `nl` | 行番号を付ける(空の行には付けない) | `nl file` |
| `wc` | 行数(`-l`)、単語の数(`-w`)、バイト(`-c`) | `wc -l file` |
| `od` | 8 進数や 16 進数で表示する(`-x`、`-c`) | `od -c file` |

### 2. 列と並べ替え

| コマンド | 動き | 例 |
|---|---|---|
| `cut` | 列を取り出す。`-d` 区切り、`-f` 何番目、`-c` 何文字目 | `cut -d: -f1,7 /etc/passwd` |
| `sort` | 並べる。`-n` 数として、`-r` 逆、`-k 3` 3 列目で、`-t:` 区切り、`-u` 重複を除く | `sort -t: -k3 -n /etc/passwd` |
| `uniq` | **隣り合う**同じ行をまとめる。`-c` 数、`-d` 重複したものだけ | `sort access.log \| uniq -c` |
| `paste` | 2 つのファイルを行ごとに横につなげる(既定の区切りはタブ) | `paste names.txt ages.txt` |
| `join` | 共通の列で 2 つのファイルを結び付ける(両方を並べておく) | `join a.txt b.txt` |
| `split` | ファイルを分ける。`-l` 行数、`-b` 大きさ | `split -l 1000 big.log part_` |

uniq は隣り合う行しか比べないので、全体の重複を除くには先に `sort` します(`sort | uniq` は `sort -u` と同じ結果)。

### 3. 文字の変換と整形

| コマンド | 動き | 例 |
|---|---|---|
| `tr` | 文字を置き換える。`-d` 消す、`-s` 連続をまとめる。**標準入力だけ**を読む | `tr a-z A-Z < file` |
| `expand` | タブを空白にする | `expand -t 4 file` |
| `unexpand` | 空白をタブにする(`-a` で行の途中も) | `unexpand -a file` |
| `fmt` | 段落を決まった幅に整える | `fmt -w 60 file` |
| `pr` | 印刷用にページの見出しを付けて整える | `pr -l 50 file` |

### 4. sed

**sed** は、テキストを行ごとに編集して出力するコマンド(ストリームエディター)です。

```bash
sed 's/old/new/' file          # 各行の最初の old を new に
sed 's/old/new/g' file         # 各行のすべての old を new に
sed -i 's/old/new/g' file      # ファイルそのものを書き換える
sed -n '5,10p' file            # 5〜10 行目だけを表示する(-n で自動の出力をやめる)
sed '/^#/d' file               # # で始まる行を消す
sed '3d' file                  # 3 行目を消す
sed -e 's/a/b/' -e 's/c/d/' file   # 複数の命令
```

`-i` を付けないと、ファイルは変わらず、結果を画面に出すだけです。

## 1.03.3 ストリーム、パイプ、リダイレクトの使用 (重要度4)

### 1. 3 つのストリーム

| 名前 | 番号 | 既定のつながり先 |
|---|---|---|
| 標準入力(stdin) | 0 | キーボード |
| 標準出力(stdout) | 1 | 画面 |
| 標準エラー出力(stderr) | 2 | 画面 |

### 2. リダイレクト

| 書き方 | 意味 |
|---|---|
| `> file` | 標準出力をファイルに書く(上書き) |
| `>> file` | 標準出力をファイルの後ろに追記する |
| `2> file` | 標準エラー出力をファイルに書く |
| `2>> file` | 標準エラー出力を追記する |
| `> file 2>&1` | 標準出力と標準エラー出力の両方をファイルに |
| `&> file` | 上と同じ(bash) |
| `< file` | ファイルを標準入力にする |
| `<< EOF` | ヒアドキュメント(EOF の行までを標準入力にする) |
| `2> /dev/null` | エラーを捨てる |

`2>&1` は「2 番を、**今の** 1 番と同じところにつなぐ」という意味です。順番が大切です。

```bash
command > out.log 2>&1     # 両方が out.log に入る
command 2>&1 > out.log     # エラーは画面に出る(2 番をつないだ時点の 1 番は画面だったため)
```

2 つの書き方で、ストリームのつなぎ先がどう変わるかを図にします。リダイレクトは左から順に処理されます。

```text
command > out.log 2>&1
  1 (stdout) --> out.log
  2 (stderr) --> 1 と同じところ = out.log

command 2>&1 > out.log
  2 (stderr) --> 1 と同じところ = 画面
  1 (stdout) --> out.log
```


### 3. パイプ、tee、xargs

```bash
ps aux | grep nginx              # 前のコマンドの標準出力を、次の標準入力に
ls -l | tee list.txt | wc -l     # tee は画面(次のコマンド)とファイルの両方に出す(-a で追記)
find . -name "*.tmp" | xargs rm  # 標準入力の行を、コマンドの引数に並べて実行する
find . -name "*.tmp" -print0 | xargs -0 rm   # 名前に空白があっても安全
```

パイプでつながるのは標準出力だけです。エラーも渡すときは `2>&1 |`(または `|&`)と書きます。

パイプでコマンドをつなぐと、ストリームがどう流れるかを図にします。数字は、標準入力 0、標準出力 1、標準エラー出力 2 の番号です。

```text
ps aux --1--> | --0--> grep nginx --1--> | --0--> wc -l --1--> screen
  |                       |                          |
  +--2--> screen          +--2--> screen             +--2--> screen
```

標準エラー出力はパイプを通らず、画面に出ます。


## 1.03.4 正規表現を使用したテキストファイルの検索 (重要度2)

### 1. 正規表現

| 記号 | 意味 | 例 |
|---|---|---|
| `.` | 任意の 1 文字 | `a.c` → abc、a1c |
| `*` | 直前の文字の 0 回以上の繰り返し | `ab*c` → ac、abc、abbc |
| `^` | 行の先頭 | `^root` |
| `$` | 行の末尾 | `bash$` |
| `[abc]` | 中のどれか 1 文字 | `[Ll]inux` |
| `[^abc]` | 中の文字以外の 1 文字 | `[^0-9]` |
| `\` | 次の記号の特別な意味を消す | `\.` |

拡張正規表現(`grep -E`、`egrep`)では、次も使えます。

| 記号 | 意味 | 例 |
|---|---|---|
| `+` | 直前の 1 回以上 | `[0-9]+` |
| `?` | 直前の 0 回か 1 回 | `colou?r` |
| `{n,m}` | 直前の n 回以上 m 回以下 | `[0-9]{3}` |
| `\|` | または | `error\|fail` |
| `( )` | まとめる | `(ab)+` |

グロブ(1.02.2)とは意味が違います。グロブの `*` は「任意の文字列」ですが、正規表現の `*` は「直前の文字の繰り返し」です。

### 2. grep

| オプション | 意味 |
|---|---|
| `-i` | 大文字と小文字を区別しない |
| `-v` | 一致しない行を表示する |
| `-n` | 行番号を付ける |
| `-c` | 一致した行の数 |
| `-l` | 一致したファイルの名前だけ |
| `-r` | ディレクトリの中も探す |
| `-w` | 単語として一致するものだけ |
| `-E` | 拡張正規表現(`egrep` と同じ) |
| `-F` | 正規表現として扱わず、そのままの文字で探す(`fgrep` と同じ) |

```bash
grep -v '^#' /etc/ssh/sshd_config | grep -v '^$'   # コメントと空の行を除く
grep -E 'error|warn' app.log
grep -c sshd /var/log/secure
```

`egrep` と `fgrep` は古い書き方で、今は `grep -E` と `grep -F` を使います。

## 1.03.5 エディタを使った基本的なファイル編集の実行 (重要度2)

### 1. vi のモード

vi(vim)には、**コマンドモード**(起動したときの状態。カーソルの移動や削除)、**挿入モード**(文字を入力する)、**ex モード**(`:` で始める命令)があります。`ESC` でコマンドモードに戻ります。

3 つのモードの移り変わりを図にします。

```text
[command] --- i, a, o ---------> [insert]
[insert]  --- ESC -------------> [command]
[command] --- : ---------------> [ex]
[ex]      --- Enter, ESC ------> [command]
```

起動したときは、コマンドモードです。


### 2. 挿入モードに入る

| キー | 入る位置 |
|---|---|
| `i` | カーソルの前 |
| `a` | カーソルの後ろ |
| `I` / `A` | 行の先頭 / 行の末尾 |
| `o` / `O` | 下 / 上に新しい行を作って |

### 3. 移動、編集、検索

| キー | 動き |
|---|---|
| `h` `j` `k` `l` | 左、下、上、右 |
| `0` / `$` | 行の先頭 / 末尾 |
| `gg` / `G` | ファイルの先頭 / 末尾(`5G` で 5 行目) |
| `x` | 1 文字消す |
| `dd` | 1 行消す(切り取る)。`3dd` で 3 行 |
| `dw` | 単語を消す |
| `yy` | 1 行コピーする(yank) |
| `p` / `P` | カーソルの後ろ(下) / 前(上)に貼り付ける |
| `cw` | 単語を消して挿入モードに(change) |
| `u` | 取り消す |
| `/文字` / `?文字` | 下 / 上に向かって探す。`n` で次 |

### 4. 保存と終了

| 命令 | 動き |
|---|---|
| `:w` | 保存する |
| `:w!` | 強制的に保存する(読み取りだけのファイルでも、権限があれば) |
| `:q` | 終わる(変更があると終われない) |
| `:q!` | 保存せずに終わる |
| `:wq`、`:x`、`ZZ` | 保存して終わる |
| `:e!` | 変更を捨てて、最後に保存した状態を読み込み直す |
| `:set number` | 行番号を表示する |
| `:%s/old/new/g` | ファイル全体を置き換える |

### 5. ほかのエディター

- **nano**: 画面の下に操作が表示される、初心者向けのエディターです。`Ctrl+O` で保存、`Ctrl+X` で終わります。
- **emacs**: 機能の多いエディターです。`Ctrl+X Ctrl+S` で保存、`Ctrl+X Ctrl+C` で終わります。
- 環境変数 **EDITOR** で、`crontab -e` や `visudo` などが使うエディターを決めます(`export EDITOR=vim`)。
