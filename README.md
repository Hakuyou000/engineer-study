# sre-drill

資格試験(CCNA、LinuC)と SRE の基礎知識を定着させるための学習アプリ。静的 SPA で、サーバを持たない。

## 機能

- 問題演習: 4 択と複数選択。出題範囲は分野単位で選ぶ
- 間隔反復: 誤答は 10 分後、正答は 1 日 → 3 日 → 間隔 × ease で再出題(SM-2 の簡略版)
- 間違えた問題の演習: 直近で間違えた問題と、2 回以上解いて正答率が 70% 未満の問題を出題する。成績画面の小項目ごとの「解く」からも始められる
- 選択肢の並べ替え: 出題のたびに選択肢の順番を入れ替える。答えの位置で覚えるのを防ぐ
- 模擬試験: 1 問 90 秒の制限時間。提出後にまとめて採点し、解説を表示
- 計算ドリル: パーミッション(8 進と記号、chmod 記号モード、umask)、cron の次の実行日時、IPv4 サブネット、IPv6 省略表記、EUI-64。問題は毎回生成する
- テキスト: `texts/` の Markdown を閲覧する。解答後は、その問題に対応する節をその場で開ける
- 成績: 分野と小項目ごとの着手数、正答率、復習待ち
- 履歴のエクスポートとインポート(JSON)

## 必要なもの

- Node.js 22 以上
- Git

## 使い方

```
npm install
npm run dev
```

表示された URL(既定は http://localhost:5173/)をブラウザで開く。

Windows では `start.bat` をダブルクリックしても起動できる。依存パッケージの確認、開発サーバの起動、ブラウザを開くところまでを行う。終了するときは、画面右上の「終了」を押す。開発サーバが止まり、黒いウィンドウも閉じる。「終了」は開発サーバで動かしているときだけ表示される。

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバ |
| `npm test` | 単体テスト |
| `npm run lint` | ESLint |
| `npm run build` | 型検査と本番ビルド(`dist/`) |
| `npm run gen` | `content/` から `src/data/questions.json` を生成 |

`dev`、`test`、`build` は実行前に `gen` を自動で呼ぶ。

## 問題の追加

`content/<試験>/` に Markdown を置く。書式は次のとおり。合わない箇所があると `npm run gen` が失敗し、ファイル名と問番号を表示する。

````
# CCNA 問題 1.0 分野名

対象: 全2問

## 問題

### 1.1 小項目

**問1** 問題文。コードブロックと表が使える。

```
show interfaces の出力など
```

- A. 選択肢
- B. 選択肢
- C. 選択肢
- D. 選択肢

**問2** 正しいものを**2つ**選べ。

- A. 選択肢
- B. 選択肢
- C. 選択肢

## 解答・解説

| 問 | 正解 | 解説 |
|---|---|---|
| 1 | B | 解説。 |
| 2 | A、C | 解説。 |
````

- タイトル行の先頭の語が試験名、次が分野番号になる。問題 ID は `<試験名>-<分野番号>-q<問番号>`
- 問題 ID は履歴のキーになる。公開後に問番号を振り直すと、その問題の履歴が別の問題に付く
- 選択肢は出題のたびに並べ替えられる(設定で止められる)。解説では選択肢の記号(「A は…」)を使わず、内容で書く。テストで検査する

## テキストの追加

`texts/<試験>/<試験名>_<番号>_<題名>.md` の名前で置く。例: `texts/ccna/CCNA_1.0_ネットワークインフラストラクチャと接続.md`。

- 目次は `## ` 見出しから作る
- 問題との対応は、試験名と番号(問題側の分野番号)、および節番号で決まる。問題の小項目が `1.1 …` なら、テキストの `## 1.1 …` の節を開く

## 構成

```
content/            問題の正本(Markdown)
texts/              テキスト(Markdown)
scripts/            Markdown → JSON の変換
src/lib/parser.ts   問題 Markdown の解析
src/lib/srs.ts      間隔反復と出題順
src/lib/weak.ts     間違えた問題の抽出
src/lib/shuffle.ts  選択肢の並べ替え
src/lib/stats.ts    成績の集計
src/lib/texts.ts    テキストの一覧と節の切り出し
src/lib/order.ts    試験の表示順(LinuC → CCNA)
src/lib/drills/     計算ドリルの生成と採点
src/lib/db.ts       IndexedDB(解答履歴、カード、ドリル履歴)
src/components/     画面
```

## データの保存先

履歴はブラウザの IndexedDB にだけ保存する。ブラウザのサイトデータを消すと履歴も消える。別の PC やブラウザへ移すときは、成績画面のエクスポートとインポートを使う。

## CI

`.github/workflows/ci.yml` が push と pull request で lint、テスト、ビルドを実行する。
